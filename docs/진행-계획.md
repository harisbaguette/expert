## 일하는 방식

- **순서를 지킴** — 정의 → 재료 → 선택 → 시험. 앞 단계에서 확정된 것만 다음 단계로 넘김.
- **한 직무부터** — 55개 재료를 한꺼번에 채우지 않고 직무 하나를 골라 끝까지 연결해 봄.
- **근거를 남김** — 밖에서 가져온 사실·숫자는 원문을 확인하고 출처와 확인 날짜를 적음.
- **되돌아감을 허용** — 시뮬레이션에서 안 맞으면 선택으로, 조사에서 빠진 재료가 보이면 재료로 돌아감.
