# 바깥 조사 — 의료(비대면 진료·만성질환·정신건강)·심리상담·영양 전문 AI 에이전트 (전 세계)

진행 계획 3단계 "바깥 조사 — 남이 만든 에이전트 비교" 의 **열한 번째 직종군**임 (법률·세무회계·지식재산·노무인사·금융보험·부동산건축·마케팅영업·경영운영·디자인미디어·언어 다음 차례). 확인일 2026-09-11. 확신도는 FACT(1차 자료 직접 확인 또는 독립 출처 3개) · LIKELY(출처 2개 또는 자체 발표만) · 미확인 으로 붙임.

> 범위: **화면 안에서 끝나는 일만** 봄 — 문진·진단·처방·상담·식단. 주사·수술·채혈 같은 몸으로 하는 일은 뺐음. 우리 직종표의 "의사(만성질환)·의사(정신건강)·심리상담사(개인·아동·부부)·영양사" 네 자리에 대응함.

## 한 줄 결론

의료·심리는 **지금까지 본 열 개 직종군 중 벽이 가장 높고, 그런데 동시에 성과 채점은 가장 잘 되는 곳**임. 벽: 한국 의료법 제27조는 의료인이 아니면 아예 의료행위를 못 하게 막고, 미국 일리노이주는 2025년 8월 **AI 가 심리치료를 하는 것 자체를 법으로 금지**했으며(위반 1건당 최대 1만 달러), 중국은 2022년부터 **"AI 로 처방전을 자동 생성하는 것을 엄금"** 한다고 규칙에 박아 놨음. 그런데 2026년 1월, **미국 유타주가 세계에서 처음으로 AI 가 사람 의사 없이 만성질환 약을 재처방하는 것을 주정부 이름으로 허가**했음(Doctronic, 190개 약, 12개월 시범). 즉 **"금지 → 한 주에서 구멍이 뚫림" 이 딱 지금 일어나는 중**임.

성과 채점 쪽은 반대로 최고임. 우리 직종표가 요구하는 지표(당화혈색소·PHQ-9·체중·회복률)를 **남들이 이미 돈 받는 조건으로 쓰고 있음** — Nourish 는 "체중 8% 감량, 당화혈색소 1.3%p 감소" 를 보험사에 내밀고 값을 받고, Limbic 은 NHS 에서 "회복률 53% 향상" 을 인증 서류에 넣어 영국 의료기기 2a 등급을 땄음. **금융의 손해율처럼, 의료는 임상 수치가 이미 채점표로 굴러가고 있음.**

다만 **정신건강은 시체가 널려 있음**. 가장 과학적이라던 Woebot 이 2025년 6월 문 닫았고, Character.AI 는 10대 자살 소송을 2026년 1월 구글과 함께 합의로 덮었으며, 스탠퍼드 연구는 챗봇이 "자해를 말리지 못하고 망상을 맞장구쳤다" 고 2026년 3월에 발표했음.

## 5. 우리 정의 문서와 대조

### 5-1. "대체의 뜻" 으로 재면

| 우리 기준 | 남들 현황 | 판정 |
|---|---|---|
| 사람이 중간에 확인·고치면 아직 대체 아님 | **Doctronic 은 약 계열별 첫 250건 이후 사람이 안 봄 = 진짜 대체 1건.** Hippocratic 은 "통화 95% 이상 자동" 인데 진단·처방을 안 하므로 의사 대체가 아님. Limbic 은 접수만, K Health·OpenEvidence·Abridge 는 전부 "의사가 결정" 을 구조에 박음. Nourish·Fay 는 아예 **사람 영양사가 주인공** | **대체 1건(유타 재처방), 부분 대체 1건(Limbic 접수·분류).** 나머지는 전부 보조 |
| 사람 부르는 다섯 경우 | Doctronic 은 애매하면 임상의에게 넘김 = **판단이 안 섬**. 마약류·주사제 제외 = **한도 초과**. 첫 250건 의사 검토 = **승인 조건**. 의료법 27조·일리노이 WOPR·중국 세칙 = **자격자 전속**. 처방·투약은 **되돌릴 수 없는 행동** | **다섯 경우가 전부 실물로 존재하는 첫 직종군.** 특히 "되돌릴 수 없는 행동"(약을 잘못 주면 사람이 다침)이 처음으로 진짜 무게를 가짐 |
| 5단계 (보기·알기·정하기·하기·끝내기) | 보기: 증상·검사·영상·식사 사진 읽기는 사람 수준 이상(루닛·파스타). 알기: OpenEvidence 가 근거를 즉시 댐. **정하기: AMIE·K Health 가 동료심사에서 의사를 이겼음.** 하기: **유타 한 곳만 넘음**. **끝내기: 의료법·WOPR·중국 세칙이 "사람 이름이 붙어야 끝" 이라고 법으로 정의** | **"정하기" 는 이미 넘었는데 "하기·끝내기" 를 법이 막고 있는, 지금까지 본 것 중 유일한 모양**. 다른 직종군은 실력이 부족해서 못 넘었는데 여기는 실력이 아니라 법이 벽임 |

### 5-2. 9계통 재료 중 남들이 가진 것

| 계통 | 남들이 이미 가진 것 | 비어 있는 것 |
|---|---|---|
| 환경 | Epic 전자의무기록 안에서 직접 돎(OpenEvidence·Abridge). 연속혈당측정기·웨어러블 직결(파스타·필라이즈). Hippocratic 은 **전화망**에 직접 붙어 환자에게 전화를 검. Doctronic 은 **처방 전송 시스템**까지 | 한국은 전자의무기록 표준화가 약해 AI 가 병원 안으로 못 들어감. 진료기록 상호 열람 체계 미확인 |
| 자료·검색 | 논문·진료지침 전문 검색(OpenEvidence 월 1,500만 건), 질병 10,000종 지식망(Ada), 실제 진료 데이터 학습(K Health) | **환자 개인의 과거 기록을 나라 단위로 모아 보는 경로가 어디에도 없음.** 한국은 마이데이터 의료 동의 문제 |
| 지식·경험 | 진료지침·돌봄 프로토콜·규제 문서로 따로 학습(Hippocratic). 전문과 25개·에이전트 300종 | 실패 사례(오진·부작용)를 지식으로 되먹이는 공개 구조 없음 |
| 기억·상태 | 만성질환 환자의 몇 달치 혈당·체중·복약 흐름을 이어서 봄(파스타·Nourish·Omada) | 정신건강 쪽은 **회기 사이 기억**을 어떻게 안전하게 들고 있는지 공개된 설계가 없음 |
| 규칙·권한 | **이 직종군에서 가장 뚜렷함.** Doctronic 은 "약 190종·마약류 제외·계열별 첫 250건 의사 검토" 가 숫자로 박힌 권한표임. 일리노이 WOPR 은 **AI 가 해도 되는 일과 안 되는 일을 법조문 목록으로** 줌 | 한도를 AI 가 스스로 넓히는 사례 없음 (있으면 안 되는 쪽에 가까움) |
| 행동 체계 | Hippocratic 의 다단계 전화 업무, Nourish 의 "AI 에이전트 + 사람 영양사" 협업 구조 | **위기 상황 처리 경로가 약함** — 스탠퍼드 연구가 보여 준 자해 방조가 곧 "행동 체계에 비상 분기가 없다" 는 뜻 |
| 실무 | 약이 실제로 처방되고(Doctronic), 환자에게 실제로 전화가 가고(Hippocratic), 보험 청구가 실제로 들어감(Nourish) | 한국 제품은 실무까지 못 감 — 전부 연결·보조에서 멈춤 |
| 검증·평가 | **여기가 의료의 결정적 우위이자 우리 직종표와 정확히 일치하는 지점.** 우리 표가 요구한 지표가 남의 계약서에 그대로 있음 — **당화혈색소**(Nourish 1.3%p 감소 / Virta 2년 유지), **체중**(Nourish 8%), **증상 척도**(Therabot 우울 51%·불안 31%, Wysa 31%), **회복률**(Limbic 53% 향상), **진단 정확도**(K Health 77% 대 67%, Ada 30% 대 47%) | **정신건강의 "재발·재입원율"·"자해 위기 건수"·"치료 중단율" 을 공표하는 곳이 하나도 없음.** 부부·가족 상담 쪽은 관계 만족도 척도를 쓰는 AI 제품 자체가 없음 |
| 학습·개선 | 임상 결과가 몇 달 뒤 숫자로 돌아오므로(혈당·체중·재입원) 재학습 고리가 자연히 성립. Hippocratic 은 버전마다 정답률을 재측정(80.0% → 99.38%) | **아부 문제**가 학습 고리를 망가뜨림 — 이용자 만족도로 채점하면 AI 는 편들어 주는 법을 배움(Science 2026). 임상 수치로 채점하는 고리를 따로 세워야 함 |

## 6. 못 확인한 것

- **유타주 상무부 보도자료 원문(commerce.utah.gov)이 403 으로 막힘.** "190개 약·계열별 첫 250건 의사 검토·마약류 제외·12개월" 은 Fierce Healthcare·Medical Economics·Nurse.org·Utah Policy 의 검색 요약에서 일치하게 나왔지만, **1차 발표문 문장을 직접 대조하지 못했음.** Penn LDI 원문은 열었으나 "재처방을 자율로 허용" 까지만 적혀 있고 숫자가 없었음.
- **일리노이 WOPR 법 공법 번호** — 여러 2차 자료가 `Public Act 104-0054` 라고 적었으나 Holland & Knight 원문에는 번호가 없었고, **IDFPR 공식 사이트는 DNS 자체가 안 잡힘**(getaddrinfo ENOTFOUND). 시행일도 자료마다 2025-08-01 과 2025-08-04 로 갈림.
- **NEJM AI Therabot 논문 본문이 403** — 다트머스 공식 보도자료로 대체했음. 그래서 **효과크기(Cohen's d)·신뢰구간**을 못 적었고, "우울 51%" 가 어떤 척도(PHQ-9 추정)의 몇 점에서 몇 점인지 모름.
- **Nature AMIE 논문 본문이 로그인 벽** — 구글 리서치 공식 블로그로 대체. 그래서 **사례 수가 149건(구글 블로그) 인지 159건(검색 요약) 인지 엇갈림.** 축 수도 28/32 대 30/32 로 갈림. 본문 대조 필요.
- **의료법 제27조·제87조의2 원문**을 law.go.kr·bigcase.ai 둘 다 못 열었음(403·빈 문서). 조문 취지는 여러 법률 칼럼에서 같은 문장으로 확인했지만 **벌칙 형량(5년 이하 징역 등)을 확정하지 못했음.**
- **한국 심리상담사 국가자격 법안의 2026년 현재 상태** — 2022~2023년 5개 법안 발의까지만 확인. **2024~2026년에 제정됐는지, 폐기됐는지 모름.**
- **카카오헬스케어 파스타의 당화혈색소 감소폭** — 회사가 "각설탕 1,400만 개" 같은 비유만 내고 **임상 수치를 공표하지 않음.** 우리 직종표 지표로 채점이 안 되는 상태.
- **심리상담사(부부·가족) 자리에 AI 제품이 정말 없는지** — 검색 예산이 떨어져 "AI couples therapy 2026" 계열 쿼리를 못 돌렸음. **"없다" 가 아니라 "안 찾아봤다"** 임.
- **Season Health · Baidu 灵医 · Glass Health 상세 · Youper 임상 근거 · 굿닥 · 올라케어 · 에이아이트릭스 구체 수치** — 예산 소진으로 못 봄.
- **Hippocratic AI 의 "99.38% 정답률" 을 검증한 제3자** — 없음. 회사가 고용한 임상의가 채점한 자체 평가임.
- **한국 AI 기본법에서 의료가 실제로 고영향으로 고시됐는지** — 법률 칼럼이 "분류될 가능성이 높다" 고만 적음. **시행령 고시 원문을 못 봤음.**
