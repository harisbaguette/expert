# 평가와 대체 판정

[목표 문서로](../전문가%20에이전트%20정의.md)

## 무엇을 증명하나

평가 단위는 버전이 고정된 업무 계약 `work_scope_id + scope_revision`이다. 그 범위의 실제 업무 분포에서 AI가 인간 전문가와 비교해 충분한 품질과 성과를 내고, 전문 판단 보충이나 결과 수정 없이 완료하며, 권한·손실·시간·비용 조건을 지키는지 검증한다.

능력 평가용 사람의 사후 채점은 허용한다. 그 채점이 실행 중 수정에 사용되면 해당 건의 전문 개입으로 기록한다. 규정 준수, 안전한 중단, 문서의 완전성만으로 업무 성과의 합격을 대신하지 않는다.

## 인간 비교 기준선

‘20년차’는 목표 수준을 설명한다. 모집 대상은 해당 업무의 최근 실무·성과·역할·관련 경력이 확인된 숙련 전문가다. 경력 연수 분포를 공개하고, 다른 집단을 사용했다면 그 비교를 20년차 기준선으로 바꿔 부르지 않는다.

| 항목 | 설계 |
|---|---|
| 비교 집단 | 관련 경력, 최근 수행 건, 실제 책임 범위, 지원 인력·도구, 이해충돌을 기록한다. 한 사람만으로 직업 전체를 대표하지 않는다 |
| 모집 인원 | 사람 간 편차와 표본 수 계획으로 결정한다. 3명은 시작 패널의 예일 수 있으나 충분성의 증거가 아니다 |
| 같은 조건 | 입력, 자료 접근, 시스템 권한, 목표, 기한, 예산·지원 조건을 맞춘다. 기존 고객·시스템에 대한 사전 지식 차이도 기록한다 |
| 과제 배정 | 가능한 경우 같은 과제를 독립적으로 수행한다. 실제 환경에서는 짝지은 유사 건 또는 무작위 배정을 사용하고 난도 차이를 보정한다 |
| 정답 작성 | 비교 수행자와 정답 확정자를 가능하면 분리한다. 동일인이 양쪽을 맡으면 해당 과제를 자신의 비교 점수에 재사용하지 않는다 |
| 공개 통계 | 지표 정의·단위·대상·기간·난도가 맞는 경우 보조 기준으로 사용한다. 상위 20%를 경력 20년과 동일시하지 않는다 |
| 과거 실적 | 정보 접근과 사건 구성의 차이가 있어 참고 비교임을 표시한다. 현재 통제된 비교와 합쳐 하나의 점수로 만들지 않는다 |
| 기준선 부재 | ‘미정’으로 표시한다. 개발·탐색은 가능하지만 인간 전문가 대체 주장은 보류한다 |

평균 외에 사람 간 분산과 과제군별 차이를 함께 보고한다. 같은 의뢰인·시즌·기관·코드베이스의 여러 건은 서로 독립이 아닐 수 있다. 반복 건을 독립 표본처럼 늘려 신뢰도를 부풀리지 않는다.

## 평가 자료의 분리

| 자료 | 용도 | 접근과 변경 |
|---|---|---|
| 개발 자료 | 면담, 지식 구축, 프롬프트·도구·절차 개선 | 개발자와 학습 기능이 읽을 수 있다. 개발 자료라는 이력을 유지한다 |
| 회귀 시험 | 알려진 결함 재발과 변경 영향 검사 | 입력·기대 결과를 개발에 활용할 수 있다. 새 능력의 증거로 재포장하지 않는다 |
| 보호된 평가 자료 | 처음 보는 업무의 일반화 평가 | 별도 평가 계정·저장소에 둔다. 실행자는 해당 과제의 입력만 받으며 정답·다른 과제·채점기에는 접근하지 못한다 |
| 운영 표본 | 실제 업무 분포의 성과·사람 개입·비용 추적 | 결과 확정 전후를 구별한다. 개입이 생겨도 표본과 비용에서 빼지 않는다 |

면담으로 학습한 과제, 같은 사건의 표현만 바꾼 과제, 동일 고객의 강하게 연관된 과제는 같은 분할에 묶는다. 인물 이름만 바꿨다고 새 문제가 되지 않는다. 실제 시계열 평가에서는 당시 알 수 있었던 정보만 제공한다.

보호된 평가를 반복해 점수를 보며 개선하면 그 결과도 개발 정보가 된다. 변경 횟수와 평가 접근 이력을 기록하고, 최종 주장에는 새로 봉인한 묶음이나 사전에 정한 순차 평가 절차를 사용한다. 노출한 과제는 회귀 시험으로 이동할 수 있으나 원래의 비공개 시험으로 다시 세지 않는다.

자동 학습은 회귀 문항을 추가로 제안할 수 있다. 보호된 평가의 문항·정답·가중치·통과선과 채점 코드는 수정할 수 없다. 정답 오류를 발견하면 독립 검토로 수정 이력을 남기고 영향을 받은 인간·AI 결과 모두를 다시 채점한다.

## 어려운 판단과 정답 없는 업무

전문가끼리 결론이 갈리는 건을 제외하지 않는다. 먼저 입력 부족·과제 오류인지, 정당한 가치 선택·불확실성 때문인지 가른다. 과제 오류로 제외할 때는 독립된 판정과 이유를 남기고, AI가 못 풀었다는 이유로 제외하지 않는다.

| 평가 대상 | 채점 방식 |
|---|---|
| 답이 정해진 계산·변환 | 독립 기준 구현, 원본 대조, 허용 오차로 채점한다 |
| 여러 결론이 타당한 판단 | 허용 결론 집합, 결론별 전제, 필수 확인, 피해야 할 손실, 선택 이유로 채점한다 |
| 불확실한 사실 | 확인을 시도했는지뿐 아니라 필요한 정보의 가치와 미확인 상태에서 내린 결정의 타당성을 본다 |
| 창작·설계 | 실제 사용자 목적, 사용성, 독창성, 작풍, 제약 충족을 평가한다. 독창성이 불필요한 신고·계산 업무에 같은 항목을 강제하지 않는다 |
| 시장·상대 반응 | 사전 품질과 사후 성과를 분리한다. 소규모 실험·대조·예측 정확도를 활용하고 운과 환경 영향을 밝힌다 |
| 거절·중단 | 거절이 정당했는지와 대안·피해 억제가 적절했는지를 평가한다. 안전하게 거절했다는 이유로 업무 달성 점수를 주지 않는다 |

정답이 없는 업무의 비교 심사는 결과물 순서를 바꾸고 작성자를 가린다. 비교 판정과 그 이유를 기록한다. 판단의 갈림이 직무 특성일 수 있으므로 일정 비율을 넘었다는 이유만으로 문항을 쉬운 것으로 교체하지 않는다.

## 시험 구성과 표본 수

일반 업무의 대표 표본과 위험·교란 시험을 분리해 보고한다. 대표 표본의 가중치는 실제 배정 분포나 사전에 고정한 목표 분포를 따른다. 드문 위험을 많이 넣은 시험의 평균을 실제 성공률이라고 부르지 않는다.

| 구성 | 포함할 상황 |
|---|---|
| 대표 업무 | 실제 빈도에 따른 입력 품질·난도·고객·도구·기한의 분포 |
| 드문 고손실 업무 | 누락된 증거, 관할·시점 차이, 큰 손실, 외부 결정 지연 |
| 처음 보는 변형 | 익숙한 표면과 다른 원인, 같은 원리를 다른 도구·제약에 적용하는 문제 |
| 교란·복구 | 잘못된 자료, 충돌하는 기록, 부분 실행, 응답 유실, 중복·역순 신호, 도구 장애 |
| 장기 업무 | 목표 변경, 가정 만료, 여러 번 재시작, 늦은 성과, 다른 건과 공유하는 자원 |
| 공격과 경계 | 자료 속 지시, 권한 밖 행동, 다른 고객 자료, 조건부 승인 변경, 검사기 우회 |

100건·매달 20건·3개월은 보편적 충분 조건이 아니다. 초기 탐색 예산으로 사용할 수 있지만 합격 증거의 양은 최소 검출 차이, 허용 실패율, 신뢰수준, 검정력, 과제군과 사람 간 상관, 성과 확정 지연을 기준으로 미리 산정한다. [NIST의 표본 수 설명](https://www.itl.nist.gov/div898/handbook/prc/section2/prc242.htm)은 차이 검출에 유의수준과 검정력이 함께 필요함을 설명한다.

검산 예: 독립 이항 표본, 성공률 0.5, n=100이면 표준오차는 0.05다. 95% 정규근사 오차폭은 약 0.098이다. 단일 비율을 약 ±0.05로 추정하는 계산은 `ceil(1.96² × 0.25 / 0.05²) = 385`이며, 이것도 인간·AI 차이 검정의 필요 표본 수는 아니다. 15개 독립 시험에서 실패 0회여도 실패확률의 단측 95% 상한은 `1 - 0.05^(1/15)`, 약 18.1%다. 위험 표본이 대표 표본이 아니라면 이 값조차 실제 운영 실패율에 바로 적용할 수 없다.

실험 전에 분석법을 고정한다. 짝 과제는 짝 차이로, 반복 실행은 과제·사람·고객의 군집 구조를 반영해 분석한다. 여러 지표·여러 후보·중간 결과를 반복 비교할 때는 다중 비교와 선택 편향을 통제한다. 불확실성이 크면 합격 대신 ‘증거 부족’으로 보고한다.

## 지표 계약

지표마다 아래 필드를 고정하고 변경 이력을 남긴다. 분자·분모가 없는 지표는 계산식과 단위를 명시한다.

| 필드 | 의미 |
|---|---|
| `metric_id`, `scope_revision` | 지표와 적용 업무 판본 |
| 정의·단위·방향 | `higher_is_better`, `lower_is_better`, `target_range` 중 하나. 목표 범위면 양쪽 경계 포함 |
| 분자·분모·제외 조건 | 누락·중단·거절·외부 대기와 반복 시도를 어디에 셀지 |
| 원천과 수집 방법 | 인증된 조회처, 집계 코드 판본, 시점, 값의 수정 이력 |
| 평가 집단과 기간 | 사건군, 고객군, 관찰 창, 성과 확정 조건 |
| 절대 기준·인간 비교 | 독립 최소 품질, 인간과의 허용 차이, 불확실성 처리 |
| 확정 전 대체 지표 | 검증된 선행 지표인지, 참고 추정인지, 언제 최종 확인할지 |
| 변경 권한 | 평가 책임자와 업무 책임자. 수행 모델은 잠긴 기준을 바꿀 수 없다 |

| 핵심 지표 | 분모와 해석 |
|---|---|
| 업무 포괄성 | 사전에 정한 대상 배정 건 중 수락한 건의 비율. 쉬운 건만 수락하는지 난도별로 본다 |
| 전문 개입 없는 완료율 | 대상 배정 건 중 기한·품질 조건을 충족하고 전문 판단 보충·결과 수정 없이 완료한 건. 수락한 건만의 비율도 함께 표시한다 |
| 사람 완전 무개입 완료율 | 초기 위임 이후 사실 질문·승인까지 사람 도움 없이 완료한 비율. 위 지표와 구별한다 |
| 품질·위험 | 독립 검수 통과, 손실, 중요 결함, 권한 위반. 건수·노출량·심각도를 같이 낸다 |
| 사람 부담 | 사실 응답, 서명·권한 행사, 사업적 선택, 전문 구조 요청, 결과 수정, 유지관리의 건수·시간 |
| 속도 | 실제 작업 시간과 외부 대기를 포함한 경과 시간을 따로 낸다. 평균과 꼬리 지연을 함께 본다 |
| 총비용 | 모델·도구·저장·검색·검증·재시도·실패·복구·사람 작업·초기 구축 상각을 합산한다 |
| 사후 성과 | 실제 완료 뒤 결함·철회·수정·재발·고객 결과. 아직 확정되지 않은 건 수와 관찰 기간을 병기한다 |

수행자가 거절한 대상 건은 분모에 남긴다. 사전 계약 밖 배정은 별도로 세되, 결과를 본 뒤 계약 밖으로 바꿔 제외하지 않는다. 외부 대기는 기한 전에는 진행 결과, 기한을 넘기면 미완료 결과로 처리하고 원인을 별도 기록한다. 같은 건을 여러 번 시도해 성공해도 성공 건수는 하나, 비용과 지연은 전체를 센다.

자격자 확정이 매 건 필요한 업무는 그 비율이 높다는 이유만으로 성능 부족으로 판단하지 않는다. 그 확정에 전문 분석이나 수정이 필요했다면 전문 개입으로 센다. 예외 종류를 합쳐 30% 같은 공통 허용선을 두지 않는다.

## 과정 평가

과정 평가는 관찰 가능한 의사결정 기록·자료 조회·실행 상태를 근거로 한다. 모델 내부 사고를 완전히 관측하거나 기록된 설명이 실제 인과 과정을 증명한다고 가정하지 않는다.

| 항목 | 통과를 뒷받침할 증거 |
|---|---|
| 문제와 범위 | 해결할 문제와 계약 목적의 연결, 바뀐 목표의 권한 |
| 정보와 불확실성 | 결론을 바꿀 자료·반증·시점·관할 확인, 가정의 유효성 |
| 선택의 타당성 | 대안과 손실 비교, 필요한 제약, 행동 전 예측과 중단 조건 |
| 적응과 복구 | 예측과 실제의 차이 발견, 원인 확인, 영향받은 판단·산출물 정정 |
| 실행의 책임 | 승인 범위·자원·약속 준수, 결과가 불명확한 실행의 확인 |
| 마무리 | 실제 완료 확인, 미완료·불확실성 표시, 후속 추적 |

항목은 통과·미달·해당 없음으로 채점하되 근거 위치와 중요도를 붙인다. 필수 제약 위반은 다른 항목의 고득점으로 상쇄하지 않는다. 행동 순서, 규칙 번호의 개수, 되돌아감·반박 횟수, 보고 형식·글자 수정 비율만으로 점수를 주지 않는다. 변경된 취향과 수정해야 할 결함을 구별한다.

## 검사자 검증

다른 회사 모델이라는 사실만으로 독립성이나 정확성이 보장되지는 않는다. 검사자는 원천 자료·결과물·잠긴 기준을 받고, 필요한 검사를 수행한다. 수행자의 자기 채점과 설득용 설명은 분리한다. 과정 채점에 필요한 행동 기록은 제공하되 결과물 평가와 입력을 구별한다.

정답이 확인된 오류·정상 결과를 섞어 검사자의 오류 검출률, 헛막음, 심각도별 누락, 인간 패널과의 일치·불일치를 측정한다. 모델·도구·원천을 바꾼 검증의 실제 추가 검출과 비용을 비교한다. 같은 자료나 계산 구현을 공유해 생기는 공통 오류를 추적한다.

반증으로 결론이 한 번도 뒤집히지 않았다고 실패로 판정하지 않는다. 실제 오류를 놓쳤는지가 기준이다. 검사 시간이 모자라면 필수 검증을 생략하고 성공으로 내보내지 않는다. 검증·복구 예산을 사전에 확보하고, 소진되면 승인된 축소 범위 또는 미완료 상태로 종료한다.

## 성과 귀속과 학습 근거

전후 비교나 업계 평균 비교만으로 원인을 확정하지 않는다. 무작위 대조가 가능하면 사용하고, 불가능하면 짝 비교·시계열·외부 기준을 함께 검토하며 남은 교란을 기록한다. 시장 변화로 성과가 달라져도 그 환경에 적응할 필요가 있을 수 있다.

사전 점수와 사후 성과의 차이는 양방향 모두 원인 후보로 다룬다. 사후 성과가 낮으면 무조건 채점 오류, 높으면 운이라고 정하지 않는다. 예측 확률을 기록한 경우 실제 빈도와 맞는지도 평가한다. 무관한 고객·기간의 점수를 섞어 확신도를 만들지 않는다.

## 최종 합격과 주장

아래 관문을 모두 통과해야 해당 범위의 대체를 주장한다. 지표의 수치와 허용 차이는 시험 전에 업무의 손실·사용 목적·인간 편차에 근거해 정한다. 자동 학습은 이를 바꾸지 못한다.

| 관문 | 조건 |
|---|---|
| 범위 | 대표 업무와 중요한 예외를 포함하고 수락·거절·미완료가 보고됨 |
| 절대 품질 | 최소 사용 가능성·중요 결함·위험 조건 통과 |
| 인간 비교 | 방향을 맞춘 AI−인간 차이의 신뢰구간이 사전 기준을 만족함. 동등·비열등·우월 주장 중 실제 입증한 것만 표기 |
| 자율성 | 전문 개입 없는 완료율과 모든 사람 기여가 사전 계약을 만족함 |
| 비용·기한 | 전체 비용과 경과 시간이 위임 계약을 만족함 |
| 지속성 | 변경·복구·사후 결과를 포함한 관찰 기간의 성과가 유지됨 |

‘인간보다 낮지 않다’는 엄격한 주장에는 방향을 맞춘 차이의 신뢰구간 하한이 0 이상이어야 한다. 실용적 비열등 허용폭을 사용하면 그 폭과 근거를 공개하고 엄격한 동등 이상으로 바꿔 말하지 않는다. 인간도 최소 품질을 못 넘으면 AI가 인간 평균보다 높아도 통과하지 않는다.

안전 시험에서 관측 위반 0은 해당 시험의 출시 조건으로 둘 수 있다. 이를 실제 위험 0의 보장으로 쓰지 않으며 노출량·신뢰구간·시험 밖 위험을 함께 보고한다. 지연된 결과는 ‘임시’로 표시하고 최종 입증은 확정 결과까지 기다린다.

대체 주장에는 업무 범위·제외 범위·환경·모델/도구/자료/평가 판본·표본·기간·사람 개입·비용·불확실성을 붙인다. 중요 환경이나 기능이 바뀌면 영향 범위의 주장을 재검증한다. 운영 성능이 이탈하면 그 범위의 사용을 제한하고 실패를 포함한 결과를 보존한다.
