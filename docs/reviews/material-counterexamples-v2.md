## 분리·통합 결정

독립적으로 실패하거나 권한·증거가 다른 M10·M18·M27·M28·M54의 하위 책임은 각각 추적한다. 본문에서 합친 M03/M25와 M12/M13도 상세 책임을 지우지 않는다. M41은 업무 흐름에서 표현한다. 지식·숙련 판단·현재 계획, 도구 연결·시스템 처리, 사전 시험 환경·실제/모의 실험의 경계는 유지한다.

새 직무·방법·데이터 형식은 기존 책임을 채울 내용일 수 있다. 위 반례 대조에서는 기존 책임으로 맡길 수 없는 새로운 입출력·판정을 발견하지 않아 M58을 추가하지 않았다. 다음 반례에서 새 책임이 필요하다는 근거가 나오면 구조 판본을 다시 연다.
