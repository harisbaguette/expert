# 법인 간 대여와 E의 책임 — 검토 기록

대상: [법인 간 대여와 E의 책임 법적 검토 astra.md](../../법인%20간%20대여와%20E의%20책임%20법적%20검토%20astra.md)

## 이번 수정의 판단

의뢰인의 목적은 E의 법적 위험, 주의사항, 필요한 행동을 이해하는 것이다. 기존 문서는 이 목적과 회사의 세무·공시 세부 업무를 같은 순서로 배치하여 개인 책임의 결론이 묻혔다. 법적 기준의 설명과 실제 거래에 대한 판단도 충분히 구별되지 않았다.

문서는 결론 → 사건 관계 → E의 책임별 판단 → 쟁점별 이유 → 필요한 행동 → 조문별 세부 기준으로 재구성했다. 「전문가 에이전트 정의.md」의 목적·상황·스타일 요구를 이 사건의 자문에 적용하고, 「판례」 문서의 방식처럼 법률 판단과 독자를 위한 설명을 구별했다.

## 의뢰인의 추가 지적에 따른 수정

“위험이 있다”만으로는 “E가 위법한가”에 답하지 못한다는 지적을 반영했다. 결론을 **대여 구조 자체는 위법하지 않고, 두 대여 사실만으로 E의 배임이 성립하지 않는다**로 명시했다. D→B→A의 연계를 무시한 결론이 아니라, 우회지원 자체와 D에 대한 구체적 임무위반을 구별한 판단이다. E의 개별 행위까지 적법한 것으로 확인했다거나 모든 책임이 없다는 결론으로 확대하지 않았다.

쟁점표는 거래 구조·겸직·회사 빚·차입원금 과세에 대한 답을 먼저 제시하고, 실제로 있으면 책임을 발생시키는 행위를 별도로 명시했다. 배임·개인 지급책임은 각 절 첫 문장에서도 답을 먼저 읽을 수 있게 고쳤다.

## 법적 검토

- [x] **거래 전체:** E의 A 최대주주·C·D 이사 지위를 D→B→A 대여 구조에 연결했다. 우회지원 의심을 누락하거나 실제 공모가 입증된 사실로 단정하지 않았다.
- [x] **배임:** D의 독립된 이익, B의 실질 상환능력, A 의존 여부, 위험 부담을 되돌리는 약정, 부당한 이자 감면, D의 자금 여력, E의 인식·관여를 함께 다뤘다. 송금 선후관계나 자금 혼합만으로 거래 연결을 부정하지 않았다.
- [x] **공범·사기:** B 자체의 부당 대여에 E가 가담한 책임, 고의적 방치와 단순 과실의 차이, 허위 담보·상환재원 설명으로 대여를 유도한 경우의 사기를 보완했다. 대여자가 위험을 알았는지와 실제 기망·착오를 구별했다.
- [x] **민사:** 회사의 반환채무와 E의 손해배상·보증을 구별하고, 이사 감시의무, 의사록상 찬성 추정, C·D의 손해 및 중복 배상 방지를 반영했다.
- [x] **승인:** 상법 제398조상 적용 대상·사전 공개·승인·공정성, 제393조상 중요 업무집행, 각 회사의 별도 의사결정, 사후승인의 한계를 다뤘다. 이사회가 없는 법정 소규모 회사의 제383조 특례도 반영했다.
- [x] **신용공여:** 비상장 D의 직접 적용 제외와 B·C 자신의 금지된 지원을 구별했다. 상법 시행령 제35조, 자본시장법 시행령 제38조, 금융투자업규정 제3-72조의 간접거래 범위 및 법인 주요주주 지원의 예외를 유지했다.
- [x] **E 개인 과세:** 실제 소득 귀속·대표자 상여·특정법인 증여의제·제2차 납세의무를 구별했다. 국세와 지방세 과점주주 규정의 문언 차이와 책임 한도를 유지했다.
- [x] **회사 세무:** 원금과 이익의 구별, 인정이자·가중평균차입이자율·4.6% 적용 요건, 업무무관 대여, 원천징수·지방소득세, 가산세와 조세범 처벌의 차이를 세부 기준에 모았다. B의 1억 원 현금 차액을 이익으로 오인하지 않도록 했다.
- [x] **공시·회계·공정거래:** 상장시장별 공시 기준, 모·자회사 거래와 회계상 회수 위험, 부당지원 및 지정 기업집단의 추가 규제를 구별했다. E에게 회사의 모든 위반이 자동 귀속된다고 쓰지 않았다.
- [x] **보고·대표권:** 상법 제412조의2의 즉시 보고의무, 감사위원회 및 적법한 감사 미설치 회사의 보고 상대방을 추가했다. D와 E 사이 소송의 회사 대표권은 제394조·제409조 제5항·제415조의2로 구체화했다.
- [x] **이사직:** 주주총회 해임과 부당한 임기 전 해임에 대한 E의 권리, 특정경제범죄법 유죄 확정에 따른 취업제한을 보완했다. 집행유예기간도 제한에 포함되는 대법원 해석과 취업승인 절차를 반영했다.
- [x] **시정:** 실제 거래 경위의 보존, 적법한 채권 회수, 추가 대여·연장·담보 해제의 재심사, 승인·신고 오류 처리를 네 가지 행동으로 묶었다. 사후 변제가 과거 범죄를 소멸시키는 것으로 설명하지 않았다. 회수 조건의 이자 상한도 확인했다.

## 설명과 표시

- [x] 파란색은 E에 대한 법적 판단·이유·근거, 노란색은 그 내용의 쉬운 설명으로 대조했다. 노란색에만 새로운 책임 판단이 나오던 부분을 바로잡았다.
- [x] 배임·고의·과실·인과관계·신용공여·무효·소득처분·증여의제·제2차 납세의무 등을 해당 쟁점에서 설명했다. 모든 설명을 같은 질문·답변 형식으로 만들지 않았다.
- [x] 서두의 자료 부족 안내와 접힘을 넣지 않았다. 같은 문단의 중복과 원금·이자 손해 설명의 반복을 제거했다.
- [x] 기존 법령 근거 링크를 유지했고 판례 발췌 한 건은 대법원 판결문 전체 링크로 교체했다. HTML 태그 짝, 두 이미지의 실제 경로, 문단 중복을 확인했다.

검토표의 완료 표시는 문서 검토·수정에 대한 것이다. 거래자료 수령, 승인·신고의 실제 정정, 대여금 회수까지 실행했다는 표시는 아니다.
