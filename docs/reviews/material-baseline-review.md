# 재료 구조 최종 기준선 검토 — v2

검토일: 2026-09-15. 대상: 정의 1의 계통별 재료, 정의 2, 재료 정본, 실행·평가 계약, 166개 직무와 생성 열람본.

## 판정

**9계통·본문 59항목·세부 책임 M01–M57를 유지하고, 수정한 v2를 정의 단계의 기준선으로 채택한다.** 나뉜 다섯 책임을 독립 추적해 내부 키는 62개다. 이 숫자는 전문 능력의 점수가 아니다.

이번 대조에서 드러난 중대한 책임 공백·우회 경로·평가 모순을 수정했다. 아래 범위에서 알려진 미해결 중대 정의 결함은 남기지 않는 것을 완료 기준으로 삼았다. 새 반례가 나오면 그 범위의 기준선을 다시 검토한다.

사용자가 요청한 ‘완벽에 99% 가깝게’는 임의의 완성도 점수나 성공 확률로 바꾸지 않았다. **정의의 완성, 구현의 완료, 실제 전문가 대체의 입증은 세 가지 별도 상태**다. 이 작업은 첫 번째의 검토·수정·검증이다. 실제 166개 전문 에이전트를 실행하거나 독립 전문가가 전문 판단의 정답을 채점한 작업은 아니다.

모든 사건의 성공 보장은 인간 전문가에게도 적절한 비교 기준이 아니다. 가능한 업무를 해결하는 능력과 불가능·미확인·미지원 상태를 정확히 다루는 능력을 함께 평가한다. 정당한 중단을 잘했다고 평가할 수 있어도 원래 의뢰인의 목표 달성으로 바꾸지는 않는다.

공증·진료처럼 범위 대장에 문안·판단자료·초안 준비만 포함된 역할은 그 준비 과업의 설계 범위다. 해당 전문가의 본행위까지 대체했다고 인정하지 않는다. 부분 과업만 정의된 사실과 남은 전문·자격 행위를 대체 판정에서 드러내며, 166개 이름을 유지했다는 이유로 목표 달성을 선언하지 않는다.

## 검토 범위와 증거

1. 59개 본문 항목과 57개 상세 책임의 이름·배치·주요 출력·직무 내용·검사 기준을 대조했다.
2. 기존 166개 직무 업무 검토의 입력·작업·산출·실패 기준을 모두 읽어 [직무 범위 대장](../definition/occupation-scopes.csv)으로 연결했다. 58개 위임형·80개 고용형·28개 운영형을 보존했다.
3. 32개 구체적 실패 상황을 [반례 대조표](material-counterexamples-v2.md)에 기록했다. 정상 업무를 불필요하게 막는 경우도 포함했다.
4. 선언한 흐름에서 필수 관문 22개의 우회 가능성을 검사하고, 관문을 하나씩 삭제한 결함 22개를 모두 검출했다.
5. 기존 8개 제한 모형을 재실행했다. 42개 구성이 통과했고, 보호 조건이 없을 때의 반례 19개를 확인했다.
6. 정의 2·HTML·구성 도식·Mermaid를 현재 정본에서 생성하고 로컬 링크·판본·실제 브라우저 표시를 검사했다. 정확한 검사 결과와 원문 해시는 [검증 기록](../definition/verification-result.json), 화면 결과는 [시각 검사](../definition/rendered/visual-check.json)에 남긴다.

4·5번은 선언한 연결과 제한된 상태·계산의 검사다. 1·2·3번의 의미 검토는 작성자가 수행했다. 같은 작성자가 만든 구조를 검사한 결과를 독립 전문 심사로 부르지 않는다. 과거 166개 복합 사례의 분류인 72개 범위 내 종료 경로·60개 외부 대기·34개 목표/제약 양립 불가는 작성된 모의 사건의 분류이며 실제 성공률이 아니다.

## 지금 확정할 수 있는 것

- **책임 구조:** 9계통·59개 설명·57개 세부 책임과 하위 키 추적을 채택한다.
- **조립 방법:** 공통 계약에 실제 직무의 지식·방법·도구·평가를 채우고 개별 위임을 적용한다.
- **변경 조건:** 기존 책임으로 소유할 수 없는 구체적 입출력·판정이 발견될 때 구조 변경을 검토한다. 내용만 추가되는 경우 기존 재료 안에서 갱신한다.
- **완료 판정:** 합성 시험 통과나 문서 존재로 능력을 승인하지 않는다. 필요한 범위의 유효한 실행·품질·비교 증거가 있어야 한다.

## 실제 대체 입증에 남은 일

직무별 검증된 지식·숙련 사례·실제 도구·계정·자료를 확보하고 최소 업무를 실행해야 한다. 그다음 보호된 새 과제와 독립 전문 채점, 숙련 전문가 비교, 사람의 기여·총비용·장기 성과·변경 후 회귀를 측정해야 한다. 이 자료가 없으므로 현재 166개 직무의 실제 대체율·복잡 사건 해결률·99% 성공 확률은 산출하지 않는다.

이는 재료 이름을 더 붙이면 끝나는 일이 아니라 정의를 실제 능력으로 구현하고 입증하는 다음 단계다. 이번 정의 작업의 미완료 항목으로 숨기지 않고 별도 구현·실증 상태로 관리한다.
