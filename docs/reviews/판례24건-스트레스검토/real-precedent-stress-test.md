# 실제 판례 27건 스트레스 검토

검토일: 2026-09-18. 대상: 정의 2의 재료 79개, 업무 처리 흐름(PHASE_0~9), 사용 구조 1·2·3.

**결론: 재료는 모자라지 않고, 순서도의 노드 조건이 어려운 사건을 걸러내지 못한다.** 27건 중 새 재료가 필요한 사건은 0건, 흐름이 아예 끊겨 "불가"로 판정된 사건도 0건이다. 그러나 26건이 "보강 필요"였고, 막힌 자리는 KNOWN_CASE·INTAKE_CHECK·VALIDATE_DATA 세 노드에 절반 가까이 몰려 있다. 지금 상태의 에이전트가 20년차 전문가가 실제로 해낸 일을 해냈을 비율은 평균 57%이며, 형사 사건은 41%에 그친다. 20년차 전문가를 대체한다고 볼 수 없다. 빠진 것은 지식이 아니라 "규칙이 있어도 뒤집힐 수 있다", "자료가 맞아도 법정에 못 들어올 수 있다", "의뢰인·공범·가족이 서로 반대편일 수 있다"는 세 가지 의심을 흐름 안에서 강제로 묻는 조건이다.

**수행 범위:** 누리플렉스 법률 에이전트 저장소의 판례 본문 JSON 170,597개를 난이도 가중 점수로 훑어 상위 300건을 뽑고, 그중 분야·함정 유형이 겹치지 않도록 27건을 골랐다. 각 사건은 요지와 본문(15만 자 초과분은 쟁점 부분만)을 읽고, 수임 시점의 변호사 관점에서 함정을 적은 뒤 사용 구조·PHASE별 노드·재료 조건에 대입했다. 재료가 "있으니 된다"는 판정은 금지하고 조건 문장이 그 사건을 실제로 걸러내는지만 봤다. 문서상 대입이며 실제 에이전트 실행이나 성공률 측정은 아니다. 전문가 대비 %는 검토자의 추정치다. 원래 정의·재료·순서도는 수정하지 않았다.
