# 검토 기록 색인

이 폴더에는 정의 문서와 도식을 검증한 기록이 들어 있다. 파일은 주제별 하위 폴더로만 보관하며, `reviews/` 바로 아래에는 이 색인 외의 파일을 두지 않는다.

## 폴더별 보관 대상

| 폴더 | 담는 것 |
|------|---------|
| [재료](재료/) | 재료 목록 자체의 검토 — 기준선, 목표 적합성, 계통 배치, 비판 검토 |
| [직무](직무/) | 166개 직무에 재료를 대입한 검토와 동적 모형 시뮬레이션 |
| [사용구조](사용구조/) | 사용 구조 도식의 완결성·인수 기준·렌더 검사 |
| [단독흐름](단독흐름/) | 한 건을 한 전문가가 처리하는 단독 상황의 흐름 검토와 화면 증거 |

| [복합사건-스트레스검토](복합사건-스트레스검토/) | 여러 쟁점이 얽힌 복합 사건 시나리오 검토 |

## 새 기록을 넣는 규칙

1. 위 표에서 주제가 맞는 폴더를 고르고, 맞는 칸이 없을 때만 새 폴더를 만든 뒤 이 표에 한 줄을 추가한다.
2. 파일 이름은 `<주제>-<검토종류>-<날짜>.<확장자>` 형식을 따른다. 예: `solo-rule-priority-review-2026-09-22.json`.
3. 화면 증거 이미지는 대응하는 검토 기록과 같은 폴더에, 같은 주제 이름을 앞에 붙여 둔다. 예: `solo-rule-priority-detail-2026-09-22.png`.
4. 같은 검토를 다시 돌린 결과는 이전 파일을 덮어쓰지 않고 날짜를 바꾼 새 파일로 남긴다.

## 관련 위치

정의 문서 전체 목차는 `docs/README.md`, 실험 기록은 `docs/실험 결과/`, 도식 생성·검증 코드는 `docs/도식/`에 있다.
