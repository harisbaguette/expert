# 사용 구조 순서도 재검토

검토일: 2026-09-17. 이 기록은 같은 날짜의 이전 검토 수치와 완료 판정을 대체한다.

## 목적과 이전 결과의 문제

목적은 세 상황에서 **각 재료를 누가, 어떤 조건에서, 무엇과 조합하고 그 결과를 어디에 사용하는지** 확인하는 것이다. 재료명 79개를 포함했다는 사실만으로 이 목적을 달성했다고 판단한 것이 이전 검토의 가장 큰 오류였다.

- 독자 관점: 긴 우회선과 멀리 떨어진 분기 설명 때문에 다음에 무엇을 읽어야 하는지 불명확했다.
- 순서도 관점: 들어오는 선과 나가는 선이 같은 연결부를 반대 방향으로 공유하거나, 설명용 내부 구조가 실제 합류처럼 보였다.
- 시각 관점: 가로만 늘리는 좌표 변환이 도형 비율을 왜곡했다. 재료를 담은 뒤 선을 우회시키는 방식으로는 이해하기 쉬운 배치를 보장할 수 없었다.
- 오케스트레이션 관점: 각 전문가의 독립 실행과 실제 결과 회수를 분명히 구별해야 했다. 미확인·실패·보완 불가의 출구도 필요했다.
- 검증 관점: 이름 수, 도형 사각 경계, 일부 화면만 확인한 결과를 이해도 검증으로 확대해서 말해서는 안 됐다. 기존 790px·도형 76/80/84개 등의 수치는 현재 도식에 해당하지 않는다.

## 변경한 구조

- **재료 도형 하나에 정식 재료명 하나**를 둔다. 시작·종료, 조건 판단, 전문가 실행, 상태 반환 도형은 구조를 표현하는 별도 도형이다.
- 표의 재료명은 21px 굵은 글씨, 보조 문구는 17px, 상시·단계별·조건부 표시는 12px이다. 비등방 확대·축소를 제거했다.
- 직각 모서리는 곡선으로 잇는다. 공유 선은 한 번만 그리고 실제 분기·합류점에 점을 표시한다. 반대 방향 선이 같은 구간을 공유하지 않도록 입구와 출구를 분리했다.
- 구획은 옅은 점선이다. 계통을 차례로 실행하는 구획으로 만들지 않았다.
- 실무 재료는 `사용 조건 → 재료 → 결과`가 한 줄에서 읽히는 가지로 배치했다. 여러 가지를 함께 사용할 수 있으며, 검증된 결과를 다음 재료의 입력으로 보내는 반복선이 있다.
- 전 구간의 실행·분리·감시·기록·상태 유지는 점선 관계로 표시한다. 업무 지식·경험·현재 작업 정보는 AI 모델의 입력으로 합류한다.
- 규칙은 원문을 확보하고 적용 관계를 함께 대조하는 자료로 표시한다. 법적 적용 관계를 먼저 확정하고, 그 안에서 의무·기본 원칙 → 유효한 계약·필수 플랫폼 규정 → 조직 필수 규칙 → 사용자 추가 규칙 → 기본 방식·스타일 순으로 충돌을 해결한다. 충돌하지 않는 하위 조건은 유지한다.
- 단독의 ‘나눠 맡기기’는 미사용으로 명시한다.
- 오케스트레이션은 A·B의 입력·실행·반환선을 구분하고 총괄의 회수 지점에서 합류한다. 미확인 조회, 오류·이견 보완, 후속 입력 전달, 기한·한도 안에서 보완 불가한 경우의 미완료 인계를 구분한다.
- 복합 상황은 건별 총괄, 모든 건의 자원·한도, 선행 결과의 전달, 건 사이의 변경 영향과 재검증을 추가한다. 다른 전문가도 펼친 재료 조합을 자기 입력·권한·상태로 독립 사용한다.
- 학습은 결과 전달 뒤에 둔다. 원인 분석과 능력 개선은 각각의 조건에 따라 사용하며, 개선 효과와 기존 능력을 모두 시험한 것만 적용한다.

## 확인 방법과 판단 범위

1. 원문 표에서 이름과 구분을 추출하고, SVG의 실제 굵은 제목 텍스트를 별도로 읽어 대조했다. metadata에만 존재하는 이름을 포함으로 계산하지 않았다.
2. 좌표에서 연결점 외 교차와 반대 방향 중첩을 검사했다. 시작·종료 도형이 각각 하나이며 가로만 늘리는 변환이 없는지 확인했다.
3. Chromium에서 배포 SVG 세 개를 렌더링했다. 도형·글자·분기 문구의 실제 경계를 검사하고, 곡선을 따라 도형 관통 여부를 확인했다. 출발 도형도 검사 대상에 넣어 가장자리 안쪽으로 잘못 돌아가는 선을 수정했다.
4. 전문가별 분기, 규칙 위계, 조건부 재료 가지, 허용·금지·사람 개입, 미확인 대기, 결과 회수, 건 사이의 영향, 학습 화면을 직접 확인했다.
5. 처음 읽는 사람·담당 전문가·총괄의 관점에서 같은 검토자가 경로를 읽었다. 독립적인 사용자 이해도 실험을 실시한 것은 아니며, 자동 검사 통과가 모든 독자의 이해를 보장한다는 판정도 아니다.

재생성: `python3 docs/도식/사용-구조.py`

정식 명칭·도형·선 관계 검사: `python3 docs/도식/사용-구조-검증.py`

브라우저 렌더링 결과와 검증 대상 SVG의 해시는 `usage-structure-render-check-2026-09-17.json`에 기록했다. 원본 SVG는 정의 1의 각 순서도를 눌러 열 수 있다.

검토 대상은 `usage-materials-*.svg` 세 파일이다. 작업 중 별도로 추가된 상황 소개 PNG와 정의 본문의 다른 변경은 이 순서도 검토의 대상이 아니다.
