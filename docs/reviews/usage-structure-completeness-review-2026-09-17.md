# 사용 구조 재료 조합 검토

검토일: 2026-09-18. 이 문서의 이전 색상·단일 시작/종료·렌더러 수치 주장을 대체한다.

## 문제와 수정

이전 도식은 서로 다른 조건에서 쓰는 재료를 한 실행선에 묶었다. 그 결과 선택하지 않을 재료를 계속 건너뛰어야 했고, 대기·실패·완료가 큰 합류점으로 몰렸다. 이름이 모두 있다는 사실만으로 조합을 이해할 수 있다고 본 것이 잘못이었다.

- 시나리오는 단독·오케스트레이션·복합의 Mermaid 3개를 유지했다. SVG·이미지로 교체하지 않았다.
- 자료 가공, 계산·판정, 제작, 소통, 시스템 조작, 관찰·시험, 판단·답변 조합마다 시작 조건과 결과 반환을 두었다. 이 7개 조합 사이의 강제 실행선을 제거했다. 필요한 조합의 결과를 검증하고 다음 조합에 넘기는 순서는 업무 계획에서 정한다.
- 규칙 미해결, 능력 미검증, 금지·거절, 외부 처리 미확인, 배정 실패는 해당 범위의 종료 도형으로 끝난다. 다른 흐름의 정상 종료에 억지로 합치지 않는다. 여러 전문가 상황은 총괄에게 이유·미완료 범위·남은 책임을 반환한다.
- 학습은 성과·실패·후속 결과가 확인될 때 시작한다. 완료 결과와 연결되어도 반드시 같은 실행에서 바로 일어나는 절차로 그리지 않았다.
- 파랑은 진행, 빨강은 아니오·불가, 노랑은 실제 앞 단계 복귀다. 모든 화살표는 실선이다. 점선은 구간 테두리에만 사용하며, 빈 원 연결점은 없다.
- 병렬 적용·분담은 분기 막대로 표시했다. 이중 사각형은 이름이 적힌 절차를 같은 담당 범위에서 다시 사용한다. 보류와 재시도, 결과 미확인과 결과 오류를 구별했다.

## 원문과의 대조

세 상황 각각 정식 재료명 79개를 포함한다. 상시 29개·단계별 17개·조건부 33개이며, 재료 도형 한 개에는 정식 재료명 하나를 굵게 쓴다. 재등장하는 재료는 같은 명칭을 유지한다. 단독 상황의 ‘나눠 맡기기’는 사용하지 않는 이유를 표시했다.

상시 재료는 준비한 뒤 업무가 끝날 때까지 계속 적용한다. 조건별 조합은 필요한 조건에서만 시작한다. 규칙은 해당하는 조건을 함께 지키고 충돌한 조항만 원문의 위계로 결정한다. 충돌하지 않는 하위 조건은 유지한다.

재료의 사용처도 확인했다. 실시간 대화는 사람과 소통으로 이어지고, 시험 환경은 실험·시뮬레이션에 쓰인다. 설계는 검증 뒤 제작에 전달되며 설계·내용 자체로 반환되는 경우도 있다. 추가 근거의 신뢰성·버전 확인, 다음 실행의 권한·한도 재검사, 완료분 보존, 담당별 독립 입력, 건 사이 변경에 따른 재검증·재작업을 유지했다. 시험·원인 분석 조건은 원문의 조건을 빠뜨리지 않도록 다시 대조했다.

전체 도식의 도형·라벨 충돌, 연결선 교차·겹침·관통 후보는 0개였다. 전진선이 앞 단계로 돌아가거나 노란 복귀선이 다음 단계로 내려가는 좌표 불일치도 없었다. 공통 구간과 상황별 주요 분기·복귀를 실제 화면에서 확인했다. 충돌 후보 0개를 독자 이해도나 모든 화면에서의 완벽함으로 해석하지 않는다.

900px 폭에서는 보조 글자가 약 11~13px로 표시된다. 더 좁은 화면에서 확대 없이 편안한지까지 확인한 결과는 아니다. 긴 복귀선도 일부 남아 있으므로 모든 선이 짧아졌다고 보고하지 않는다. 다만 서로 무관한 조합을 연결하던 선과 전역 합류를 없애 원래의 과도한 왕복을 줄였다.

`사용 구조` 앞부분은 수정 직전 원문과 같고 기존 상황 소개 PNG 3개도 유지했다. 다른 문서·판례 작업은 변경하지 않았다.
