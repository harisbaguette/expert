# 사용 구조 — 재료 관계와 16:9 화면 검토

검토일: 2026-09-21. 이번 검토는 `전문가 에이전트 정의.md`의 `사용 구조`만 대상으로 한다. 이전 사용 구조의 수치와 판정을 대체한다. 최신 사용자 지시에 따라 세로 화면 기준을 **1920×1080, 본문 폭 1856px**로 변경했다.

## 바꾼 내용

실무 재료 22개를 회색 목록 안에 숨겨 놓았던 부분을 실제 선택·실행 경로로 펼쳤다. 이번 작업이 자료 확보·가공, 값·해석·판정, 소통, 제작·반영 중 어디에 해당하는지 고르고, 그 갈래에서 필요한 재료만 쓴다. 입력과 출력은 작은 보조 글자로 표시한다. 결과를 검증한 뒤 다음 작업의 입력으로 돌려주므로 다른 갈래를 고르거나 순서를 바꿀 수 있다. 네 갈래는 동시 실행하라는 뜻이 아니다.

상시 기반·규칙·지식은 해당 동작에 화살촉 없는 회색 실선으로 연결한다. 회색 묶음의 내부 배치는 실행 순서가 아니다. 조건부 동작은 판단 도형의 해당 조건에서 실행하며, 적용 조건을 모르면 앞의 자료 확인 경로를 거친다. 한 도형에는 정식 재료명 하나를 굵게 표시한다.

단독에서는 한 전문가가 끝까지 처리한다. ‘나눠 맡기기’는 미사용 이유를 표시한다. 오케스트레이션은 총괄의 배정 뒤 각 전문가가 자기 입력으로 별도의 재료 선택·실행·검증 경로를 따른다. 독립 작업의 분담 막대와 A의 검증된 결과를 기다리는 B의 조건을 구별한다. 결과 전달 전에 A의 보고 주체·판본도 확인한다. 복합은 전체 총괄·건별 총괄·각 건의 전문가를 구별하고 선행 결과·공유 자원·건별 및 전체 한도·변경 영향을 함께 다룬다.

접촉·설계 검증·외부 변경의 실패는 해당 실행을 멈추고 상태와 원인을 남긴다. 일부 실패와 미응답은 완료로 섞지 않는다. 보완은 완료분을 유지한 채 실제 재료 선택 경로로 돌아간다. 학습은 성과 확인 → 원인 분석 → 개선 → 시험 환경·능력 시험 → 검증한 내용의 기억 순으로 마지막에 연결된다.

세 상황 각각 상시 29개·단계별 17개·조건부 33개다. 구성 개념식의 6요소와 재료 표의 9계통은 실행 단계로 사용하지 않는다. 정확히 세 개의 연결된 Mermaid이며 별도 호출 도식이나 번호 연결점은 없다. 모든 실행 도형은 시작에서 도달하고 의미 있는 종료로 이어질 수 있다.

`python3 docs/도식/사용-구조-검증.py`는 정식 명칭·구분·한 도형 한 재료·조건 분기·동시 분담·실제 재료 경로·권한 차단·검증의 세 결과·재작업·종료를 확인한다. 79개 × 3상황의 원문 조건·담당·설명·유입·유출·적용 대상은 [재료 관계 대조 기록](usage-structure-material-trace-2026-09-21.json)에 남겼다. 이 기록은 단순 포함 목록이 아니다.

실제 SVG의 모든 도형·선·라벨을 기하 검사하고, 모든 선분의 교차·중첩과 실제 화살촉도 별도로 검사했다. 파랑 진행·빨강 아니오/차단·노랑 실제 복귀이며, 노란 화살촉은 실제 이전 동작을 가리킨다. 시작은 맨 위, 최종 종료는 맨 아래다. 긴 곡선의 표본 수 제한 경고는 숨기지 않고 렌더 기록에 보존했으며, 전체 선분 검사로 보완했다.

전체 배치는 연속 구간으로 촬영해 검토하고, 글자·분기·복귀는 1920×1080 구간 캡처로 확인했다. 보조 글자는 약 16.7–18.1px, 재료명은 약 18.2–19.7px다. Mermaid 원문만 본문에 저장했고 기본 글자 수 50,000·연결 수 500 한도를 올리지 않았다. 렌더 입력과 저장 원문의 해시가 일치하며 사용 구조 앞부분은 보존했다.

## 경로 대조

- 단독 정상 처리: 입력 확인 → 필요한 갈래·재료 선택 → 검증 → 다음 작업의 입력 또는 담당 결과 → 최종 확인·인계.
- 조건부 재료 미사용: 각 판단의 아니오 경로로 다음 조건 또는 결과 확인에 연결. 단독의 위임은 실제 실행하지 않음.
- 규칙 충돌: 법적 관계와 충돌 조항의 위계 적용 → 미해결이면 사람의 결정·주체 확인 → 다시 적용하거나 보류 종료.
- 일부 실패·이견: 완료/실패/보류 회수 → 누락·중복·이견 검증 → 담당 보완 또는 분담·방법을 다시 계획 → 해당 작업만 재실행.
- 선행 결과 미확보: A의 주체·결과·선행 조건 확인 실패 → B 미착수·보류 → 현재 상태 회수. B 실행으로 우회하지 않음.
- 도중 변경: 변경 영향과 연결된 결과 재검증 → 기준 미충족이면 보완 계획·안전 검사 → 해당 작업으로 복귀.
- 중단 후 재개: 저장된 진행 상태 복원 → 외부 처리 상태 확인 → 이미 완료한 결과 보존 → 남은 작업만 진행.

## 판정 범위

상황별 재료의 선택·적용·전달·재확인 경로와 16:9 화면에서의 가독성을 검토했다. 79개 재료를 펼친 전체 도식이므로 세로 스크롤은 남아 있다. 전체를 한 화면에 축소하거나 세로 휴대폰 폭으로 고정하지 않는다.

실제 초심자 대상 독해 시험과 모든 렌더러·모든 화면의 무결함을 검증한 것은 아니다. 이 결과를 ‘누구나 100% 이해함’ 또는 문서의 다른 부분까지 확정되었다는 근거로 사용하지 않는다. [렌더 검사 기록](usage-structure-render-check-2026-09-17.json)에 실제 환경·수치·해시·검사 한계를 남겼다.
