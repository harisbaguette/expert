# 사용 구조 Mermaid 전환 검토

검토일: 2026-09-17. 같은 날짜의 이전 SVG 검토 기록을 대체한다.

## 정본

`전문가 에이전트 정의.md`의 `## 사용 구조`에 **Mermaid 코드 블록 3개를 직접 작성**했다. 재료명·적용 구분·설명·조건·화살표·구획·스타일이 모두 Markdown 안에 있다. 외부 이미지나 별도 생성 코드를 읽어야 관계를 파악하는 구조를 제거했다.

사용하지 않는 자체 SVG 3개와 SVG 생성 코드를 제거했다. 기존 상황 소개 PNG와 앞부분의 다른 Mermaid는 이 전환의 대상이 아니다.

## 유지·확인한 내용

- 각 도식에 표의 정식 재료명 79개: 상시 29, 단계별 17, 조건부 33.
- 재료 도형 하나에 재료 하나. 구조 도형은 시작·종료·조건·담당·분기·합류를 표현한다.
- 굵은 재료명과 작은 보조 문구. 실제 렌더링에서 각각 18px/700과 14px/400을 확인했다.
- 옅은 점선 구획과 기존 업무 처리 흐름의 색 체계. 점선 규칙 관계는 적용 위계이며 실행 단계가 아니다.
- 조건부 재료의 사용 조건과 결과, 검증 후 다음 재료에 전달하는 반복, 대기·보완·미완료 경로.
- 단독의 분담 미사용, 여러 전문가의 독립 실행·회수·통합, 여러 건의 선후 관계·공동 한도·변경 영향.
- 학습은 결과 전달 뒤에 배치. 개선 효과와 기존 능력을 시험한 뒤 검증된 개선만 적용한다.
