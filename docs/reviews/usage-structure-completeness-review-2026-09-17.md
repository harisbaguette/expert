# 사용 구조 세로 배치 검증

검토일: 2026-09-17. 같은 날짜의 이전 배치 검토를 대체한다.

## 정본과 표시

`전문가 에이전트 정의.md`의 `## 사용 구조`에 Mermaid 순서도 3개를 직접 작성했다. 기존 「업무 처리 흐름」의 색·옅은 점선 구획을 참고했고, Mermaid의 ELK 배치를 세로 읽기에 맞게 조정했다.

재료명은 18px 굵게, 보조 내용은 14px로 유지했다. 글씨를 축소하는 대신 가지를 위아래로 나누고, 대기·재검사·결과 합류를 해당 구역 가까이에 배치했다. 병렬 담당은 독립된 화살표로 연결하며, 화면 배치용 숨은 연결은 실행 순서로 취급하지 않는다.

선은 파랑 진행, 회색 건너뜀·상시 입력, 보라 반복·재시도, 청록 분담·수집, 빨강 중단, 초록 시작·종료로 구별한다. 시작은 전체 도식의 맨 위, 종료는 맨 아래다.

## 내용과 흐름

- 세 상황 각각 정식 재료명 79개를 포함한다. 상시 29, 단계별 17, 조건부 33이다.
- 재료 도형 하나에는 재료 하나를 쓴다. 시작·종료·조건·담당·합류 도형은 흐름을 설명한다.
- 규칙의 점선 위계와 실행 순서를 구별한다. 조건이 맞는 재료만 사용하고, 그 결과를 다음 재료의 입력으로 보낸다.
- 실시간 대화는 소통에, 시험 환경은 실험·시뮬레이션에, 검증한 설계는 제작에 연결한다. 준비·연결만으로 결과가 완성된 것으로 취급하지 않는다.
- 완료·계속 처리·계속할 수 없음을 기록한 뒤 그 상태에 맞는 출구로 보낸다. 다음 실행은 권한·한도·안전 검사를 다시 거친다.
- 총괄은 준비된 미완료 작업만 배정하고 검증된 완료분을 보존한다. 후속 결과·판본을 넘기며, 복합 상황은 변경으로 무효가 된 결과와 그 의존 결과를 재작업 대상으로 되돌린다.
- 전달 뒤에 성과·학습을 둔다. 개선 효과와 기존 능력의 시험을 통과한 개선만 채택한다.
