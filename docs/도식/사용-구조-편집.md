# 사용 구조 편집

본문에는 상황별 하나의 전체 그림만 표시한다. 이 파일과 검증 기록은 편집·검수용이며, 그림을 이해하기 위한 추가 자료가 아니다.

- `사용-구조-생성.py`: 재료 설명, 관계, 담당, 배치와 색을 편집한다. 재료명·구분·정식 조건은 정의 문서의 표에서 읽는다.
- `사용-구조-원본.json`: 세 그림의 재료·관계·적용 범위·좌표를 보관한다. SVG 내부에도 같은 원본이 들어 있다.
- `사용-구조-렌더.cjs`: 실제 브라우저에서 그림과 글자 좌표를 확인한다. 설치된 Puppeteer가 필요하며 `PUPPETEER_MODULE`로 기존 설치 위치를 지정할 수 있다.
- `사용-구조-검증.py`: 79개 재료, 조건 분기, 연결, 화살촉 위치, 실제 글자와 도형의 겹침을 검사한다.

프로젝트 루트에서 실행한다.

```sh
python3 docs/도식/사용-구조-생성.py
node docs/도식/사용-구조-렌더.cjs /tmp/expert-usage-render
python3 docs/도식/사용-구조-검증.py --geometry /tmp/expert-usage-render
```

가로·세로 비율을 맞추는 검사는 없다. 그림의 크기는 내용과 연결 배치로 정한다. 적용 범위를 나타내는 묶음과 실제 실행 연결은 별개다. 묶음 안에 있다고 모든 재료를 순서대로 실행하는 뜻이 아니다.

자동 검사는 원문과 그림의 일치, 연결의 결함, 겹침 후보를 확인한다. 독자가 이해하는지까지 자동으로 판정하지 않는다. 배치를 바꾼 뒤에는 전체 흐름과 바뀐 구간을 실제 그림으로 확인한다.
