## 확인 결과

- 지식·규칙·도구가 공통 연결선을 거쳐 문서·계산·운영 전문가 묶음으로 들어간다. 입력 하나가 전문가 하나에만 대응하는 오해를 수정했다.
- 접수·처리·검증·전달의 순서, 경험 반영 전에 다시 검증하는 조건, 하나의 공통 기반이 표시돼 있다.
- 제목·단계·라벨·하단 문구의 한글과 방향, 인물·소품 잘림을 실제 이미지에서 확인했다.
