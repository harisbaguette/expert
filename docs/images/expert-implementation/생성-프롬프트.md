# 재료별 구현 그림 프롬프트

문서의 그림을 같은 화풍으로 다시 만들 때 사용하는 문구다. 내장 `image_gen`으로 생성하거나 기존 그림을 편집한다.

## main-model-and-review

- 파일: [main-model-and-review.png](../expert-definition/main-model-and-review.png)

```text
한국어 문서 '재료 별 구현.md'의 설명용 인포그래픽. 가로 3:2 고해상도. 부드러운 교육용 손그림, 짙은 차콜 선, 둥근 성인 업무 담당자와 검은 머리, 하늘색 옷, 단순한 문서와 도구. 불투명한 흰 배경, 옅은 하늘색과 연한 노랑, 넉넉한 여백. 크고 또렷한 한글. 제목과 지정 문구를 정확히 쓴다. 사진, 3D, 과한 그라데이션, 워터마크, 임의 날짜나 숫자 없음. 팔다리는 자연스럽게 두 개씩. 기존 이미지가 있으면 화풍을 유지하되 전체 구성을 아래 내용으로 바꾼다. 그림 속 텍스트를 빽빽하게 넣지 않고 지정 문구를 중심으로 설명한다.
제목 "판단은 주 모델, 검사는 새 대화에서"
윗부분 세 장면: "주 대화" — 주 모델이 계획과 판단을 하는 모습. "작업 분담" — 같은 주 모델의 두 작업 창에 각각 "작업 A", "작업 B". "별도 검토" — 다른 대화 창에서 같은 사실과 원문을 보고 따로 판단하는 모습. 세 장면 아래 공통 라벨 "같은 주 모델".
아래쪽 중요한 검토 순서를 왼쪽에서 오른쪽으로 네 짧은 문구와 화살표로 나타낸다.
"같은 사실과 조건 제공" → "기존 결론 없이 판단" → "두 결과 비교" → "원문과 계산으로 확인".
하단 강조문 "같은 답이 나와도 새 증거가 되지는 않는다".
작은 보조 도구 띠에는 문서 판독 그림과 검색 그림, "OCR과 검색은 판단을 돕는 도구"라고 쓴다.
주의: 중요한 판단을 검토하는 장면에 처음부터 기존 결론을 제공하는 그림을 그리지 않는다. 별도 검토에는 동의한 모델 수로 확정하는 투표나 승인 도장을 넣지 않는다.
```

### 최종 수정 문구

```text
이미지 오른쪽 아래 '4 속도' 패널 안의 하얀 3행 표만 다시 그린다. 기존 표의 모든 글자를 지우고 다음 텍스트로 완전히 교체한다. 표 밖은 전부 그대로 보존한다.
첫째 행 검정 글씨 "짧은 질문" / 주황 글씨 "첫 토큰 ≤ 1초".
둘째 행 검정 글씨 "3만 토큰 문서" / 주황 글씨 "첫 토큰 ≤ 10초".
셋째 행 검정 글씨 "출력 속도" / 주황 글씨 "초당 30토큰 이상".
핵심은 한글 '첫 토큰'이다. 글자를 정확히 '첫', 한 칸 띄고 '토', '큰'으로 쓴다. 이전 '첫 응답'이라는 문구는 완전히 제거한다. 단어를 이전대로 두지 않는다. 이 표는 답변 시작 시점인 첫 토큰 지연을 표시한다. 모든 다른 내용, 제목, 메모리, 사용 허가, 도구 호출, 인물, 화풍, 하단 문구는 유지한다.
```


### 작업 메모리 표시

```text
첨부 이미지의 왼쪽 아래 '3 메모리' 패널에서 KV 캐시가 가리키는 범위만 고친다. 파란 '모델' 칸과 노란 '작업 메모리' 칸 양쪽에 걸쳐 있는 아래 괄호선과 'KV 캐시' 라벨을 완전히 지운다. 대신 노란 '작업 메모리' 칸 안에 두 줄로 '작업 메모리'와 '(KV 캐시)'라고 쓴다. 파란 '모델' 칸과 점선 '여유 공간' 칸은 그대로 둔다. KV 캐시는 노란 작업 메모리만을 뜻하며 모델 가중치가 포함되지 않는다. 오른쪽 아래 속도 표의 '첫 토큰 ≤ 1초', '첫 토큰 ≤ 10초', '초당 30토큰 이상'을 포함해 나머지 모든 문구와 그림, 배치와 화풍은 그대로 보존한다.
```

