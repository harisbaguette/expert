Use case: infographic-diagram. 한국어 문서 「전문 판단의 신뢰성」의 도입 설명 그림을 편집한다. 입력 이미지 1은 편집 대상이다.
기존의 친근한 성인 인물, 부드러운 하늘색·연노랑과 짙은 손그림 선을 유지한다. 배경은 순백색 불투명. 기존의 큰 파란 패널과 장식선을 없애 여백을 늘린다. 가로 약 2.4:1, 선명한 고해상도. 같은 너비의 세 장면을 왼쪽에서 오른쪽으로 가는 파란 화살표로 연결한다. 큰 전체 제목은 없다. 장면 제목은 같은 크기의 굵고 읽기 쉬운 한글 고딕체다.

설명 "실행 직전 전제 확인, 바뀌면 재검토 / 고친 결론을 맡긴 사람·다음 작업에 알림 / 틀린 결론에 기댄 행동 중단"

전체 제목, 번호, 구호, 임의 소품 속 글씨는 넣지 않는다. 정해진 제목과 설명만 정확히 쓴다. 단정한 고딕 한글과 넉넉한 여백, 12개가 명확히 분리되어 읽혀야 한다.
