각 신규 삽화는 아래 공통 프롬프트에 해당 계통의 개별 프롬프트를 이어 붙여 생성했다. 참조 이미지는 `six-components.png`다.

```text
용도: infographic-diagram. 한국어 문서 '전문가 에이전트 정의.md'의 '계통별 재료' 본문 삽화.
참조 이미지의 역할: 제공된 기존 그림은 화풍·인물·색감의 기준이며 내용을 복사하거나 원본을 바꾸지 않는다. 동일한 시리즈의 새로운 설명 그림을 만든다.
화풍: 참조처럼 불투명 흰 종이 위에 살짝 불규칙한 굵은 차콜 손그림 선, 미세한 색연필 질감, 검은 짧은 머리와 점눈을 가진 친근한 성인 업무 담당자, 하늘색 셔츠나 재킷, 둥근 소품, 옅은 하늘색 타원 배경, 회색 노트북과 문서. 소량의 연노랑 소품을 허용한다. 입체 렌더링·사진·네온·복잡한 장식·워터마크·로고 금지.
가로 3:2 캔버스. 모든 글자와 인물이 잘리지 않도록 사방 흰 여백. 글자는 크고 또렷한 검은 한국어 손글씨로 정확하게. 패널 테두리 없음. 소품의 잔글씨나 임의의 설명문은 넣지 않고 문서 내용은 짧은 회색 선으로 표현. 인물마다 자연스러운 두 팔과 두 손. 배경은 모서리까지 흰 불투명이며 투명 알파나 크림색 배경 없음.
```

## 환경

- 파일: [material-environment.png](material-environment.png)
- 대체 설명: 환경은 AI 모델의 판단, 실행 제어, 필요한 현재 작업 정보, 분리된 작업 공간, 외부 도구 연결, 운영 감시·복구를 함께 제공한다. 그림은 주요 역할을 묶은 개요이며 전체 재료는 아래 표에 따른다.

### 개별 생성 프롬프트

```text
주제: AI가 실제로 업무를 수행할 수 있게 해 주는 환경. 2행 3열의 대등한 여섯 장면. 순서도가 아니므로 장면 사이 화살표·번호는 없다.
윗줄 왼쪽 "AI 모델": 성인 담당자가 자료를 보고 생각하며 말풍선 속 전구와 두 선택 카드를 비교한다.
윗줄 가운데 "실행 제어": 성인 담당자가 세 작업 상자와 분기·합류 연결이 보이는 모니터로 작업을 실행한다.
윗줄 오른쪽 "현재 작업 정보": 성인 담당자가 이번 판단에 필요한 소수의 문서 카드만 노트북 옆에 펼친다.
아랫줄 왼쪽 "분리된 작업 공간": 두 작업용 작은 책상이 낮은 칸막이로 나뉘어 각 자료가 섞이지 않는다.
아랫줄 가운데 "도구·시스템 연결": 담당자의 노트북에 문서 편집기·달력·저장소를 상징하는 세 둥근 아이콘이 선으로 연결된다.
아랫줄 오른쪽 "운영 감시·복구": 노트북과 별도의 작은 감시 화면에서 끊긴 작업 연결이 되살아나고 이어지는 모습을 담당자가 확인한다. 작은 순환 화살표 허용.
각 장면 아래 지정한 여섯 문구만 크게 표시. 긴 문구는 두 줄로. 여섯 장면은 환경의 주요 역할 요약이며 항목 수나 전체 목록이라는 문구는 쓰지 않는다.
```

### 최종 보완 프롬프트

생성된 해당 삽화를 수정 대상으로 사용했다.

```text
이 이미지를 부분 수정한다. 수정 대상은 맨 왼쪽 위 "AI 모델" 장면의 인물뿐이다. 현재 양손으로 두 카드를 든 동시에 턱을 괸 세 번째 손이 있으므로 이를 반드시 정상 두 팔·두 손으로 고친다. 턱을 괴는 팔과 손을 완전히 없애고, 인물의 두 손은 왼쪽과 오른쪽 카드 한 장씩을 들도록 한다. 나머지 다섯 장면과 여섯 제목, 소품, 전체 2행 3열 배치, 크기, 화풍, 흰 배경은 그대로 유지한다. 다른 글자나 장면은 변경하지 않는다.
```

## 자료·검색

- 파일: [material-sources.png](material-sources.png)
- 대체 설명: 필요한 자료를 찾고 출처·판본·적용 시점을 확인해 해석한 뒤 원문과 연결한다. 검색에서 못 찾은 자료를 곧바로 없다고 단정하지 않는다.

### 개별 생성 프롬프트

```text
주제: 업무 자료를 찾은 뒤 근거로 쓸 수 있게 확인하는 과정. 가로 한 줄에 같은 너비의 네 장면, 하늘색 짧은 화살표로 연결.
첫 장면 "찾기": 담당자가 돋보기로 내부 자료함과 검색 화면에서 문서를 찾는다.
둘째 "출처·시점 확인": 담당자가 원문 문서, 작은 달력, 두 판본을 대조한다. 판본에는 글자 대신 겹친 문서 아이콘만.
셋째 "내용 이해": 담당자가 문서·표·사진 카드의 관련 부분을 연결해 읽는다.
넷째 "근거 연결": 담당자가 정리한 지식 노트의 한 문장과 원문 문서의 해당 부분을 연결선으로 되짚는다.
장면 아래 중앙에 작은 별도 설명 삽화: 돋보기 옆 빈 검색 화면과 물음표. 옆에 큰 한 줄 문구 "못 찾음 ≠ 없음". 이는 검색의 한계를 뜻하며 문서를 쓰레기통에 버리지 않는다.
글자는 "찾기", "출처·시점 확인", "내용 이해", "근거 연결", "못 찾음 ≠ 없음" 다섯 문구만. 네 인물과 텍스트가 겹치지 않도록 충분히 분리.
```

## 지식·경험

- 파일: [material-knowledge.png](material-knowledge.png)
- 대체 설명: 전문 지식의 개념·원리·방법과 실전 경험의 단서·예외를 함께 살펴 이번 업무의 조건에 맞는 방법을 고른다. 지식은 근거와 적용 조건을 연결해 유지한다.

### 개별 생성 프롬프트

```text
주제: 전문 지식과 실전 경험을 함께 써서 상황에 맞는 방법을 고르기. 세 장면.
왼쪽 "전문 지식": 담당자가 펼친 전문서적과 개념 관계 노트를 읽는다. 아래 작은 문구 "개념·원리·방법".
가운데 "실전 경험": 담당자가 과거 사례 카드에서 반복된 단서와 예외를 짚는다. 아래 작은 문구 "단서·조건·예외".
오른쪽 "상황에 맞게 적용": 담당자가 이번 업무 파일 옆에서 세 방법 카드를 비교해 조건에 맞는 하나를 선택한다.
이들은 일렬 순서가 아니다. 왼쪽 전문 지식과 가운데 실전 경험에서 각각 출발한 얇은 하늘색 연결선이 아래에서 합류하여 오른쪽 적용 장면으로 향하도록 연결. 연결선은 글자와 인물을 침범하지 않는다.
오른쪽 아래 작은 원문 문서와 지식 노트가 연결된 소품, 옆 문구 "근거와 조건을 함께".
텍스트는 지정한 여섯 문구만 크게. 과거 성공을 무조건 복사하거나 증거 없이 뇌에서 지식이 생성되는 그림 금지.
```

## 규칙·권한

- 파일: [material-rules.png](material-rules.png)
- 대체 설명: 적용되는 규칙을 맞추고 현재 업무 권한과 한도를 확인한다. 안전장치는 허용된 실행만 통과시키며 위반은 차단하고 확인할 수 없는 실행은 보류한다.

### 개별 생성 프롬프트

```text
주제: 규칙·권한·한도와 실행 안전장치의 관계. 왼쪽 절반에는 위아래 세 묶음의 자료, 중앙에는 하늘색 셔츠 담당자와 큰 방패형 검사 문, 오른쪽에는 실행 결과 갈림.
왼쪽 위 "적용 규칙": 여러 규정 문서와 합의 문서를 담당자가 나란히 맞추는 작은 장면.
왼쪽 가운데 "현재 권한": 열쇠와 유효한 업무 허용 카드.
왼쪽 아래 "비용·위험 한도": 속도계처럼 남은 여유를 보이는 간단한 계기와 시계.
위 세 요소의 선이 중앙의 한 방패형 문으로 모인다. 중앙의 큰 문구 "안전장치". 문 앞 담당자는 실행 요청 카드 하나를 기준에 맞춰 확인한다.
문 오른쪽 세 갈래 짧은 선: 위는 파란 체크와 정상 작동 노트북 "허용 → 실행"; 가운데는 진한 회색 정지 표시와 닫힌 문 "위반 → 차단"; 아래는 모래시계와 확인 대기 카드 "확인 불가 → 보류".
중앙 아래 한 줄 "실행 직전 다시 확인".
검사 대상은 실행 요청이고 사람의 매번 승인 의무를 뜻하지 않는다. 세 결과는 동일 선상에서 모두 통과하는 순서도가 아니다. 정확한 지정 문구 8개 외 텍스트 없음. 글자보다 도형이 복잡해지지 않도록 여유 있게.
```

## 행동 체계

- 파일: [material-action.png](material-action.png)
- 대체 설명: 요청의 뜻을 파악해 목표와 완료 조건을 정하고, 대안을 비교한 뒤 작업·담당·일정으로 실행 계획을 구체화한다. 변화가 생기면 재판단하고 필요한 판단·작업은 사람에게 연결한다.

### 개별 생성 프롬프트

```text
주제: 할 일과 완료 기준, 방법과 계획을 정하는 행동 체계. 네 장면을 가로 한 줄에 배치하고 하늘색 오른쪽 화살표 세 개로 연결.
첫 "의도 파악": 두 사람이 작은 대화 말풍선과 목표 그림을 통해 원하는 결과를 함께 확인.
둘째 "목표·완료 조건": 하늘색 셔츠 담당자가 목표 과녁과 체크할 항목이 있는 계획서를 연결.
셋째 "대안 비교": 담당자가 비용과 시간 아이콘이 놓인 두 경로를 비교해 적합한 방법을 고름.
넷째 "실행 계획": 담당자가 일정판에 작업 카드, 담당자 얼굴 아이콘, 선후 관계와 병렬 두 갈래를 배열.
그림 아래에는 두 개의 작은 보조 장면을 넉넉히 떨어뜨려 배치.
왼쪽 보조 "변화 발견·재판단": 새 알림 카드를 보고 계획으로 되돌리는 짧은 곡선 화살표.
오른쪽 보조 "필요한 일은 사람에게": 전문가에게 판단 요청 자료를 건네고 회신 카드를 받는 모습. 모든 단계를 사람에게 넘기는 모습은 금지.
텍스트는 위 여섯 문구만. 본 업무 네 장면의 시각적 비중은 보조 장면보다 크게.
```

### 최종 보완 프롬프트

생성된 해당 삽화를 수정 대상으로 사용했다.

```text
첨부 삽화의 구성과 내용을 그대로 보존하되, 전체 도상과 글씨를 약 90%로 균등 축소하고 가운데 정렬해 좌우에 흰 여백을 충분히 만든다. 현재 오른쪽 가장자리 "실행 계획" 인물의 머리·어깨와 왼쪽 첫 인물이 경계에 너무 붙어 있으므로 완전히 보이게 보완한다. 동일한 가로 3:2 불투명 흰색 캔버스. 기존 여섯 문구를 한 글자도 바꾸지 않는다. 윗줄 네 장면·아랫줄 두 장면·화살표·옷·얼굴·손그림 선을 유지. 새 요소 추가 금지. 모든 인물과 소품을 가장자리에서 45픽셀 이상 떨어뜨린다.
```

## 실무

- 파일: [material-practice.png](material-practice.png)
- 대체 설명: 실무의 여덟 묶음. 진행·후속 관리를 유지하면서 자료 가공, 계산·분석·판정, 구상·표현·제작, 대화·협의, 업무 시스템 조작, 납품·인계, 관찰·시험·연습을 업무에 맞게 조합한다.

### 개별 생성 프롬프트

```text
주제: 실무의 여덟 묶음. 가로 3:2 캔버스에 정확히 2행 4열의 여덟 독립 장면. 순서가 아니라 조합하는 업무 능력이므로 숫자·장면 간 화살표 금지. 상단에 중간 크기 문구 "업무에 맞춰 조합".
각 장면에 동일한 검은 머리 성인 하늘색 셔츠 전문가. 각 장면 아래 큰 검은 손글씨 제목을 두 줄까지 허용.
윗줄 1 "진행·후속 관리": 체크·진행·대기 상태 카드와 달력을 함께 살피는 담당자.
윗줄 2 "자료 가공": 여러 문서를 분류함에 나누고 표로 정리.
윗줄 3 "계산·분석·판정": 계산기와 그래프, 기준 체크리스트로 결과를 대조.
윗줄 4 "구상·표현·제작": 화면의 스케치와 문서 시안을 실제 결과물로 완성.
아랫줄 1 "대화·협의": 두 사람이 마주 앉아 서로의 조건 카드를 조정.
아랫줄 2 "업무 시스템 조작": 노트북 화면에 기록·신청·설정·게시를 상징하는 네 단순 아이콘. 실제 처리 결과 체크 표시.
아랫줄 3 "납품·인계": 완성 자료와 사용 설명 파일을 상대에게 건네고 수령 체크.
아랫줄 4 "관찰·시험·연습": 두 시험 화면을 비교하고 측정 기록을 남기는 담당자.
상단 문구와 여덟 제목 총 아홉 문구 외 글자 없음. 각각 그림은 같은 크기, 여백 충분히, 얼굴·손·글씨 겹침 없음. 전체 항목 상세 대신 여덟 묶음의 역할을 보여 주기.
```

## 검증·평가

- 파일: [material-verification.png](material-verification.png)
- 대체 설명: 작업 결과를 근거와 대조하고, 과정과 품질을 평가하며, 실제 성과를 추적하고 맡길 수 있는 업무 능력을 시험한다. 입력이나 조건이 바뀌면 영향을 받는 결과를 다시 확인한다.

### 개별 생성 프롬프트

```text
주제: 검증·평가에서 서로 다른 네 가지 확인. 2행 2열, 정확히 네 장면. 순서가 아니므로 장면 사이 화살표·번호 없음.
윗줄 왼쪽 큰 문구 "결과 검증": 담당자가 원천 문서와 결과물을 나란히 놓고 누락이나 오류를 대조. 작은 되돌림 화살표가 변경 시 재검증을 상징한다.
윗줄 오른쪽 "과정·품질 평가": 담당자가 작업 기록과 실제 납품물을 펼쳐 방법·순서와 사용 편의성을 함께 살핀다.
아랫줄 왼쪽 "성과 추적": 담당자가 달력과 시간에 따른 실제 성과 그래프를 확인. 그래프는 개선·악화가 혼재하고 무조건 상승하는 광고 그래프 금지.
아랫줄 오른쪽 "업무 능력 시험": 담당자가 분리된 시험용 화면에서 평소 작업과 예외·중단 후 재개 상황을 시험. 체크·물음표가 함께 있는 시험 기록.
중앙 하단 여백에 작은 문서와 연결고리 아이콘, 문구 "판단·실행·근거를 연결해 기록".
지정한 다섯 문구만 사용. 네 역할 모두 같은 크기. 검증을 단순 체크 도장이나 성공 보장으로 표현하지 않는다.
```

### 최종 보완 프롬프트

생성된 해당 삽화를 수정 대상으로 사용했다.

```text
이 그림의 오른쪽 위 "과정·품질 평가" 장면 인물만 해부학적으로 수정한다. 현재 두 자료를 쥔 두 손과 턱을 괸 손까지 총 세 손이 있으므로, 턱을 괸 팔과 손을 완전히 지운다. 인물은 정상적인 두 팔과 두 손만 가지며 양손으로 "작업 기록" 노트와 "실제 납품물" 서류를 하나씩 쥔다. 나머지 세 장면·글자·여백·모든 소품·색·스타일·크기는 정확히 유지한다. 이 한 가지 오류만 수정. 불투명 흰 배경 유지.
```

## 확인

- 9개 계통에 삽화가 각각 한 번씩 배치됐고 모든 이미지 경로가 프로젝트 안의 실제 파일을 가리킨다.
