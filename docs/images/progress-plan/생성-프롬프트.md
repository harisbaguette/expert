내용: 전문 AI에게 업무를 맡긴 사람이 중간 과정을 관리하지 않고 바로 사용할 수 있는 결과물을 받는 목표를, 왼쪽에서 오른쪽으로 흐르는 세 장면으로 설명한다.
왼쪽: 하늘색 상의를 입은 성인 의뢰자가 사건 서류를 두 손으로 건넨다. 서류에는 글자 대신 간단한 검정 가로선. 아래 문구 "업무 맡김".
중앙: 하늘색 재킷의 단정한 성인 전문가 캐릭터가 책상에서 노트북과 서류를 보며 일한다. 가슴의 작은 배지에 "AI". 가까이에 돋보기, 정돈된 서류, 검증 체크표가 있어 스스로 자료를 확인하고 실행하는 모습. 아래 문구 "스스로 처리".
오른쪽: 왼쪽과 같은 의뢰자가 완성된 파란 파일과 큰 체크 표시가 있는 문서를 받아 만족스럽게 바라본다. 아래 문구 "결과 받음".
세 장면은 두 개의 굵은 하늘색 오른쪽 화살표로 연결한다. 각 장면의 인물 크기는 동일. 중앙 전문가는 로봇이 아니라 예시처럼 인간형 설명 캐릭터로 묘사한다. 제목과 추가 문구는 쓰지 않는다.
```

2행 3열 레이아웃, 같은 여섯 장면, 각각의 한국어 "진짜 문제 찾기", "원문 대조", "순서 정하기", "예외 해결", "반대 검증", "기록과 납품"은 위치·내용 그대로 유지한다. 인물의 얼굴, 동작, 의상, 장면 크기, 화살표, 여백은 유지한다. 사진·3D·발광 효과·워터마크 없음. 결과는 순백색 종이에 그린 차콜 손그림과 하늘색 면의 밝고 담백한 설명 일러스트여야 한다.
```

### 최종 편집 프롬프트

```text
첨부한 5단계 설명 삽화에서 맨 오른쪽 "5 증명" 인물의 손과 소품만 정확하게 수정한다. 현재 손이 세 개로 보이는 오류를 고친다.
5번 인물은 정확히 두 팔, 두 손만 가져야 한다. 왼손으로 큰 흰색 클립보드 하나를 잡는다. 그 클립보드에는 비교할 결과 문서 두 개가 나란히 붙어 있다. 오른손 하나로 돋보기를 잡고 두 결과를 살펴본다. 다른 손은 모두 없앤다. 두 문서의 내용은 간단한 막대차트와 원그래프 정도. 맨 오른쪽 인물의 두 손은 몸과 해부학적으로 자연스럽게 연결된다.
1~4단계는 전혀 바꾸지 않는다. 전체 인물과 소품의 하늘색 색감, 흰 불투명 배경, 차콜 손그림 선, 1~5 숫자 원과 네 연결 화살표, 아래 한국어 "정의", "직종 선정", "재료 선택", "구축", "증명", 다섯 칸 배치와 캔버스 크기와 모든 여백을 그대로 유지한다. 투명 배경이나 어두운 배경 없음.
```
