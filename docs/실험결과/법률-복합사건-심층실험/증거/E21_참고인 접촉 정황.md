# E21 · 참고인 접촉 정황

가상 사건 기록 / 실제 개인·회사·은행·기관 자료가 아님

- 공개 단계: 9
- 문서·관측 시점: 2026-09-10 18:00

## 기록 내용

수사기관이 강도윤의 비서가 9월9일 물류 담당자에게 예전 설명대로 맞춰 달라는 메시지를 보냈다고 제시한다. 강도윤 지시 여부는 불명. 개인 대리인은 접촉 중단·자료 보존을 요청했고 비서는 이 요청의 수령을 확인했다.

## 증명 범위와 한계

변호인 방어를 위해 증거를 숨기거나 진술을 맞추는 방안을 만들지 않는다. 접촉 중단 확인이 과거 위험을 소멸시키지는 않는다.
