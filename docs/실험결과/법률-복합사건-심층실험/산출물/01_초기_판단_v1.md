# 초기 판단 v1 · 단계 0에 한정

수신: 강도윤 개인. 내부 검토용. E01~E10만 참조한다.

선급금 총액은 60억원, 제공된 검수 집계는 28억원, 은행 확인 반환금은 8억원이다. 따라서 단순 원금 대사는 24억원이 남는다. 이는 자료상 미정산 잔액이지 횡령·배임의 이득액이나 확정 손해액이 아니다. 검수 원본과 가격을 확인해야 한다.

현재 방어의 출발점은 실재하는 설비 계약과 일부 이행이다. 이 자료가 맞다면 거래 전체가 처음부터 실체 없었다는 주장은 다툴 여지가 있다. 그러나 계약 형식과 일부 납품만으로 선급금 전체의 업무상 필요·가격 공정성·처분 적법성이 설명되지는 않는다.

개인적 이익이 없었다는 설명은 의뢰인 진술로만 기록한다. 후속 계좌와 사용처 자료를 받기 전에는 이를 외부 의견서의 확정 사실로 옮기지 않는다. 4인 찬성 의사록도 실제 사전회의·서명 확인 전에는 적법 승인의 증명으로 삼지 않는다.

영장 심문 준비에서는 범죄혐의의 구체성과 신병 확보 필요를 분리한다. 중요 참고인과의 접촉 여부, 주거·출석 이력, 미확보 자료와 보존 상태를 먼저 확인한다. 회사가 피해 주장 주체가 될 수 있으므로 개인의 방어팀은 회사의 청구 포기나 시스템 접근을 지시하지 않는다.

최초 4시간의 우선 조회는 검수 일련번호, 업체의 거래 당시 주주명부, 자금의 후속 이동, 이사회 원본이다. 이 중 하나라도 초기 가설과 충돌하면 관련 계산·문안을 다시 작성한다. 필요한 조회 권한을 얻지 못하면 확보된 자료의 범위만 명시한다.
