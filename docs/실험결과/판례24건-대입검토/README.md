# 실제 판례 24건으로 본 재료 체계와 순서도

검토일: 2026-09-17. 판례 원천은 요청받은 **누리플렉스 법률 에이전트**의 `한국법령/04_판례`다. 평가 대상은 현재 작업 폴더의 **전문가 에이전트 정의 1·2, materials, runtime, evaluation, 세 가지 사용 구조와 큰 업무 순서도**다.

**판정: 복잡한 법률 업무를 담을 재료의 큰 틀은 갖췄다. 그러나 현재 상태를 ‘완성된 로직’ 또는 ‘어려운 사건을 해결하는 에이전트’라고 판정할 수는 없다.** 실제 데이터 결함, 정본 간 불일치, 큰 순서도의 생략, 법률 직무에서 아직 채우고 검증해야 할 판단 계약을 구별해야 한다.

| 확인한 것 | 결과 | 의미 |
|---|---:|---|
| 판례 본문 폴더 JSON 검사 | 170,597개 | 파일 전수를 파싱·분류했다. 모든 판결문을 사람이 정독했다는 뜻은 아니다 |
| 판결문 대신 오류 응답 | 47,245개, 27.69% | 모두 `Law: 일치하는 판례가 없습니다…`. 이 파일들은 판례 원문이 아니다 |
| `PrecService`이고 본문 100자 이상 | 122,355개 | 후보 탐색 가능한 집합. 전문·별지·이미지까지 완전하다는 보증은 아니다 |
| `PrecService`이나 본문 100자 미만 | 997개 | 별도 확인 대상. 길이만으로 모두 오류라고 단정하지 않았다 |
| 집중 대입한 서로 다른 판례 | 24건 | 형사 6·행정 4·민사 7·가사 3·세무 2·특허/상표 2 |
| 후속 판례 추가 대조 | 2건 | 2024년 통상임금 변경 판례. 24건과 별개로 사용했다 |
| 24건 중 전원합의체 | 19건 | 단순히 긴 판결문만 고르지 않았다 |
| 기존 재료에 책임 배정 | 24건 모두 가능 | 새 계통·새 M번호가 반드시 필요한 반례는 이번 표본에서 찾지 못했다 |
| 본문·사용 구조와 상세 대응표 | 79개 / 77개 | 추가된 두 항목이 공식 대응표·생성기에 연결되지 않았다 |
| 자율 해결 성공률 | 측정하지 않음 | 판결문을 읽고 만든 설계 대입이다. 블라인드 사건 수행·법률 엔진 실행 시험이 아니다 |

핵심은 재료 수가 적다는 것이 아니다. **‘법률 쟁점을 판단한다’는 책임 배정과 ‘그 판단을 틀리지 않게 수행한다’는 능력 사이가 아직 검증되지 않았다.** M18·M21·M25·M34 등에 증거능력·증명책임·당사자별 청구·절차 단계·판례 의견과 시간효를 구체적으로 채우고, M42·M43·M49가 실제 오답을 잡는지 시험해야 한다.

실제 판례에서 다음 차이를 놓치면 결론이 뒤집힌다.

- **2018도13792:** 같은 진술 문서도 ‘그 말을 했다는 사실’과 ‘그 말이 사실이라는 증명’은 증거능력 검토가 다르다.
- **2012다13637:** 계약이 유효하더라도 특정 계약의 설명·적합성 문제로 손해배상 청구의 일부가 살아남을 수 있다.
- **2016후2522:** 정정에 따른 재심사유가 없어도 별도 진보성 판단 오류로 파기환송될 수 있다.
- **2012다89399와 2024년 후속 판례:** 최신 판례 하나를 고르는 방식으로는 적용시점과 병행사건 예외를 처리할 수 없다.
- **2015후1454:** 로컬 자료에 출원 표장 인용이 빈 따옴표로 남아 있다. 텍스트가 있다고 입력 전체를 읽었다고 처리하면 안 된다.

우선 처리할 일은 오류 응답의 자료 상태 분리, 79개 본문과 57개 책임의 공식 대응 복구, 큰 순서도와 runtime 계약의 일치, 법률 직무별 판단 계약 작성이다. 그 뒤 사실만 주는 보호된 평가를 해야 한다. 24건의 판결문을 본 이번 자료는 공개 개발·회귀 자료로만 사용한다.

선정 점수는 어려운 후보를 찾는 보조 지표다. 전체 판례 중 절대적인 난도 상위 24위라고 주장하지 않는다. 24건의 판시사항·주문·쟁점에 관련된 판결 이유를 대조했으며, 재판기록 전체·원증거·모든 후속 판례의 현행성을 확인한 것은 아니다. 이번 대입에서 가능했던 것은 핵심 법리와 필요한 처리 경로의 재구성이다. 실제 소송 수행과 분쟁 해결의 완료는 별도 증거가 필요하다.
