# 선정 방법과 자료 품질

## 범위와 판본

요청받은 외부 프로젝트에서 판례를 읽고, 현재 정의 저장소의 재료·순서도에 대입했다. 외부 프로젝트의 검색 서버·색인 DB·모델 호출·소송 제출 기능은 실행하지 않았다. 따라서 아래 원문 결함이 실제 검색 결과에 노출되는지, 기존 수집기가 이미 이를 제외하는지는 별도 확인 사항이다.

검토한 정의는 [판본 해시 목록](재현/definition_manifest.json)과 [보존 사본](재현/검토정의/)에 남겼다. 검토 중 정의 1의 사용 구조·정의 2의 모델 검사 설명·사용 구조 검사기가 변경되어 보존 판본, 중간 실패, 최종 재확인 결과를 나눠 보관했다. 최종 사용 구조 검사는 통과했다. 큰 업무 순서도와 계통별 재료표는 보존 판본과 동일함을 확인했다. 이 보고서의 기본 분석은 보존 판본 기준이며 변경된 부분의 재확인 결과는 [구조 검토](03_구조결함과_보완안.md)에 구분했다.

## 후보를 고른 방법

본문 폴더의 JSON 170,597개를 모두 열어 `PrecService` 유무와 본문 상태를 검사했다. `PrecService` 123,352개에 대해 사건번호·법원·선고일·판시사항 번호 수·참조 판례 수·본문 길이·의견 신호·전원합의체 여부를 추출했다.

후보 점수는 `min(log2(본문 글자수),18) + 2×min(판시사항 번호 수,15) + min(참조 사건번호 수,30)/3 + 6×의견 신호 + 4×전원합의체`다. 의견 신호는 본문에 반대의견 또는 별개의견이라는 표현이 나타나는지다. 인용된 다른 판례의 의견도 잡힐 수 있으므로 이 값을 법적 난도의 자동 판정으로 쓰지 않았다.

전체 점수 상위 80개와 사건종류별 상위 8개를 합쳐 ID 중복을 제거한 후보는 123개였다. 후보의 쟁점과 주문을 확인하면서 동일 사건의 중복 레코드와 비슷한 문제의 편중을 줄였다. 조약·환송판결·여러 의견 구조를 시험하기 위해 자동 후보 밖의 **2013다61381**을 목적 표집으로 추가했다. 통상임금의 변경 적용을 검증하려고 **2020다247190·2023다302838**도 후속 대조 자료로 읽었다.

선정된 24건은 서로 다른 사건키(법원·선고일·사건번호)를 가지며 19건이 전원합의체다. 원문 본문 길이 합계는 HTML 표지를 제거한 문자열 기준 959,288자다. 이 수치는 확보한 자료량이고 모든 글자를 정독한 분량이라는 뜻은 아니다. 판시사항·주문·핵심 쟁점의 판결 이유를 중심으로 대조했다.

법률 의미와 필요 분기는 검토자가 읽고 작성했다. 정규식은 사건 식별·숫자·문서 구조 추출과 후보 탐색에만 사용했다. 형사 사건이 길다는 이유로 모두 상위에 넣거나, 반대의견이 없다는 이유로 쉬운 사건으로 분류하지 않았다.

## 실제로 발견한 데이터 문제

| 문제 | 확인한 근거 | 처리상 의미 |
|---|---|---|
| 오류를 본문 파일로 저장 | 47,245개가 `{"Law":"일치하는 판례가 없습니다.  판례명을 확인하여 주십시오."}` | `파일 있음`·`JSON 파싱 성공`과 `판례 원문 확보`를 분리해야 함 |

| 메타 수와 파일 수 차이 | `_meta.json`의 총건수 170,734, 본문 파일 170,597 | 137개 차이. 목록의 중복·판본·다운로드 누락을 대조하기 전 ‘정확히 137개 미수집’으로 단정할 수 없음 |

| 표장 입력 손실 | C24 `2015후1454`의 판시사항·요지에 `“”로 구성된 서비스표` | 원본 표장을 실제 읽었다고 인정할 수 없음. 수집 이전 원천 손실인지 수집기 손실인지는 미확인 |
| 별지·원증거 의존 | C02·C11 등의 주문은 별지와 당사자별 범위를 참조함 | 판결문 본문만으로 모든 사람·거래의 결론과 손해액을 완결했다고 할 수 없음 |

위 오류 47,245개가 법률 검색 색인에 실제로 들어갔다는 주장은 하지 않는다. 이번에 확인한 것은 **본문 저장소 품질**이다. 조회 결과가 없을 때 이 저장 상태를 모르고 ‘그런 판례가 없다’고 말하는 것이 특히 위험하다. 새 본문 재료인 ‘못 찾음·없음 구분’이 바로 이 상황에 필요하다.

자료 상태는 적어도 `원문확보 / 요약만확보 / 입력손실 / 조회실패 / 미수집 / 재확인대기`를 구분하고, 출처·시점·원래 응답·재시도 내역과 연결해야 한다. 이는 새 계통을 추가하는 일이 아니라 M07·M18·M19·M52의 입력 계약을 채우는 일이다.

## 원문과 외부 확인

24건의 원본 경로와 SHA-256은 [선정 목록](재현/selected_cases.json)에 있다. 원본 JSON을 gzip으로 보존했고 [읽기용 텍스트](재현/원문/)는 HTML 태그를 제거한 파생물이다. 파생물만으로 이미지·표·별지 보존을 주장하지 않는다.

이번 웹 확인은 일부 쟁점에 대한 공식 출처 대조다. 24건 전부의 현재 유효성 검증은 아니다.
