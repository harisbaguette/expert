# 재료별 구현 — 기술 선택과 원문 대조

검토일: 2026-10-19. 환경 독립성·제품 구성 재검토: 2026-10-20. 대상: [확정 재료 설계](<../../../전문가 에이전트 정의 1.md>). 기준: [정의 1](<../../../전문가 에이전트 정의 1.md>)과 [전문 판단의 신뢰성](<../../../전문 판단의 신뢰성.md>).

## 이번 개정의 범위

환경과 1번 AI 모델, 50번 계산은 별도 확정 문서에 보존한다. 현재 결정은 PC 한 대에 먼저 구현하고, 이후 사내 서버와 DGX Spark 환경을 추가하는 것이다. 2026-10-20에는 미확정 77개를 전부 대조해 특정 OS·장비·설치된 프로그램에 기대던 구현을 고쳤다. 확정 문서와 두 기준 문서, 그림은 수정하지 않았다.

변환, 판독, 제작, 재사용 자료, 스타일과 재구성을 먼저 배치했다. 각 재료의 첫 문장에서 추천 방법을 밝히고 뒤에 사용 조건과 검사 기준을 적었다. 번호는 원래 번호를 유지하며, 기존 기능과 통과 기준을 환경 변경 때문에 삭제하지 않았다.

이전 기록의 공개·가상 자료 한정, 음성·실제 외부 연결 제외, SQLite 한정과 대기열 제외는 현재 구현 결정이 아니다. 140회 실행, 20% 오류, 약 320문장 중복처럼 집계 근거가 없는 과거 수치도 기술 선택의 근거로 사용하지 않았다.

## 독립 대조에서 고친 내용

신뢰성 대조에서 지적한 21개 누락을 보완한 뒤 같은 기준으로 재확인했다. 요건의 네 가지 판정값, 원문 전체를 사용하는 독립 검토, 통계 셀 인원, 모델 응답 원문, 검증 범위 밖 실행 차단과 고정 입출력 재생 등이 여기에 포함된다.

기존 초안 대조에서는 대상 모집단 확인, 중복 방지 키 만료, 버전 이전, 고객 간 결론 비교, 편집 형식의 수식 보존과 Decision Model 역할 범위를 고쳤다. 과거 초안의 일괄 심층 재작성·두 사람 승인은 현재 신뢰성 문서와 사용자 결정에 맞지 않아 복원하지 않았다. 최신 원문의 실행 승인과 전문 검토 구분을 따랐다.
