## 4. 지시 밖에서 본 것 (보고만)

- 옛 앞부분에만 있던 결정 셋이 재료 절에 없음. 재료 절 보강이 필요함: 원문 자르기가 실패하면 원본만 남기고 다음 날 다시 자르며 옛 카드는 두어 빈 날이 없게 함(변경 감시·반영), 관할을 나라 > 광역 > 기초 계층 부호로 적어 위 계층 법까지 한 번에 거름(규칙·기준 원문), 그림을 만들기 전에 남의 얼굴 등 권리를 확인하고 한 줄 남김(결과물 만들기·수정).
- 실행 엔진 이름 Temporal: 공통 지시는 "이름을 적지 않는다"지만 재료 절 실행 제어 정답과 같아 코디네이터 결정으로 그대로 둠.
- 정의 1 머리는 "재료별 구현", 정의 2는 "재료별 구상"으로 절 이름이 갈림.

- 재사용 자료 절 ①: "그림·영상 등 큰 원본 → 직종 공통 폴더". 직종 공통 폴더는 git 저장소 안이라 큰 파일이 쌓이면 저장소 크기 한도(권장 1GB, 5GB에서 막힘)에 걸림. 큰 원본은 git 기록 밖에 두는 규칙이 필요한지 재사용 자료 절 검토 필요.
- 초안의 "②·③ 기반 부품은 바깥 서비스 없이" 기준은 웹 검색 API(네이버·Brave) 같은 자료 원천에는 걸지 않음. 자료 원천은 정보·자료 찾기 절이 고름.
