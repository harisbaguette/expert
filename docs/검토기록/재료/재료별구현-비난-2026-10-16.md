## 사용자 결정이 필요한 것

1. 구독 한도와 약관: 한 건에 하네스 실행이 약 140번 필요함. Codex Business는 5시간에 5~45메시지, Claude 좌석은 채팅과 한도를 나눔. Anthropic은 구독 로그인을 보통 사용용으로 두고 서비스는 API 키로 쓰라고 함(code.claude.com/docs/en/legal-and-compliance). 추천: 업무 실행은 API 키 계정으로 바꾸고 건당 실행 수와 토큰 상한을 둠.
2. 회사 밖으로 못 내보내는 자료: 제3자 개인정보를 늘 다루는 직종(소송, 세무, 인사, 회계)은 개인정보 보호법 제28조의8 국외 이전 근거가 없어 하네스 환경으로 맡을 길이 없음. 추천: 직종마다 맡음/못 맡음을 표로 정하고, 못 맡는 직종은 사내 모델 환경이 돌아올 때까지 뺌.
3. 사람 개입: 제출과 발송이 모두 되돌릴 수 없는 행동이라 승인으로 가고, 승인자는 자격자가 결론을 먼저 쓰고 두 사람이 승인함. 사람 개입률이 사실상 100%가 되어 "맡기고 결과만 받음"과 부딪힘. 추천: 승인은 보여 준 대상과 값에 예/아니오로, 결론 먼저 쓰기와 함정 시험 건은 무작위 표본 감사로만. 신뢰성 문서의 확정 규칙을 바꾸는 일임.
4. 하네스 둘: Codex는 검사 실패 시 막는 설정과 압축 끄는 설정이 없고 메시지 한도가 작음. 추천: Claude Code 하나만 운영.
5. 되풀이: 약 320문장(26%)이 신뢰성 문서의 확정 문장을 옮긴 것임(91f1227, d9e234f, f119c0a, 0ec5119에서 일부러 옮김). 추천: 걷어 내고 규칙마다 무엇이 지키게 하는지만 남김.
