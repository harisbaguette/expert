# 13번 규칙·기준 원문 전면 검토

**이전 문안은 종류의 이름을 많이 적었지만, 그것들을 어떤 관계로 수집·저장해야 하는지 설명하지 못했다. ‘몇 가지만 보완하면 충분하다’고 평가하기에는 핵심 설계가 비어 있었다.**

2026-10-21에 공식 법령·판결·기관 설명과 API 명세를 대조했다. 본문은 `재료 별 구현.md`의 13번만 고쳤다. 확정 문서와 정의 1, 전문 판단의 신뢰성은 변경하지 않았다.

## 직접 확인한 API 동작

공식 명세의 공개 예시인 `target=lsDelegated`, `ID=000900`, `type=JSON`, `OC=test`를 조회했다. 인증이 필요한 서비스의 운영 권한을 얻었다는 뜻은 아니다. [공식 예시가 있는 명세](https://open.law.go.kr/LSO/openApi/guideResult.do?htmlName=lsDelegated)

- 응답은 HTTP 200, JSON 파싱에 성공했다.
- `위임구분`에서 `시행령`, `시행규칙`, `위임자치법규`, `위임행정규칙`, `인용법령`을 확인했다.
- 출발 조항, 연결 대상의 일련번호, 연결 문구와 조문 위치를 확인했다.
- 따라서 ‘API 이름이 위임 조회이므로 반환된 모든 연결은 위임이다’라는 구현은 틀린다.
- 과거 판본의 모든 관계, 개별 첨부 파일의 완전성, 제공처별 운영 인증·호출량은 이번 예시 조회로 검증되지 않았다.
