# 정의 2 전체 최종 손질 — 문서에서 뺀 이유 문장과 결정 근거 (2026-09-30)

정의 2 본문에는 기준·정답·규칙만 남기고, 아래 이유 문장은 여기로 옮겼다.

| 자리 | 뺀 이유 문장 |
|---|---|
| AI 모델 — 모델을 하나만 쓰는 이유 | 일을 등급별 모델에 나누면 넘길 때마다 앞뒤 사정이 빠지고 다시 설명하느라 토큰이 더 든다. ①은 구독 계정, ②·③은 사 둔 장비라 부를 때마다 드는 돈이 없어 싼 모델로 아낄 몫이 없다 |
| AI 모델 — AA 지수를 쓰는 이유 | 제3자가 모든 모델을 같은 설정으로 재고, 점수 대부분이 사무·도구 사용·긴 문서 읽기 과제라 우리 일과 닮았으며, 아는 척한 답을 깎고, 다시 재도 거의 안 움직인다. 그래서 후보마다 우리 시험지를 돌리지 않아도 된다 |
| 실행 제어 — 조회 12시간 | 상대가 요청 번호를 기억하는 기간(짧은 곳이 24시간, Stripe)보다 짧게 잡은 값이다 |
| 실행 제어 — 모델 호출을 흐름 밖으로 | 모델은 부를 때마다 답이 달라 흐름 안에서 다시 돌리면 결과가 바뀐다(Temporal 재생 제약) |
| 업무 지식 — 미세 조정 | 미세 조정으로 가르친 지식은 판본을 대 보거나 고칠 수 없어 쓰지 않는다 |
| 실전 경험·감각 — 지식과 같은 곳에 | 나눠 두면 같은 조건의 지식과 요령이 따로 낡는다 |
| 일하는 과정 평가 — 결과를 가리고 평가 | 결과를 알고 보면 그때 알 수 없던 것까지 잘못으로 재단한다 |
