# 재료 구조 기준선 검토

## 검토 범위와 통과 기준

현재 9계통의 재료, 본문과 세부 책임, 실행·평가 계약을 대상으로 한다. 온라인·컴퓨터 안에서 끝나는 업무의 구조를 검토하며, 현장 직접 수행이나 모든 미래 상황의 성공을 보증하지 않는다. 기존 166개 직무 검토와 계산 모델은 반례의 입력으로 사용하며 실무 성능 증거로 전용하지 않는다.

보완 전에 정한 통과 기준은 다음과 같다.

1. 모든 재료에 주된 출력·책임, 입력, 실패 시 담당과 재개 조건이 연결된다.
2. 일반 업무와 복합 반례에서 판단·권한·실행·복구·검증·완료의 담당이 빠지지 않는다.
3. 외부 상태를 바꾸는 실무와 에이전트 자체의 운영 장애에 담당 재료가 있다.
4. 새 직무·법령·도구는 기존 구조의 어떤 내용·설정으로 들어가는지 설명할 수 있다. 단순히 학습 재료가 알아서 한다고 넘기지 않는다.
5. 정의의 대응과 상태 모형을 검사하되, 문서 검사·합성 시험·실제 전문 수행을 서로 다른 증거로 기록한다.
6. 수정한 본문·세부 정의·실행·평가·생성 그림이 같은 재료와 책임을 참조한다. 과거 실험은 당시 판본을 보존한다.

## 초기 발견

| 항목 | 발견 | 처리 목표 |
|---|---|---|
| 시스템 처리·실행 | M10의 도구 연결과 실무 내용 사이에 거래·접수·설정 변경의 소유자가 불명확함 | 실무 책임 M56을 추가하고 입력·실행·대사·보상·재검증을 연결 |
| 운영 감시·복구 | 실행 계약은 외부 감시를 요구하지만 재료 표에는 그 담당이 없음 | 환경 책임 M57을 추가하고 감시·수신 보존·격리·복구·재개 승인을 연결 |
| 수행 가능성 | 지식·모델·도구 항목의 존재만으로 실제 업무 지원을 주장할 수 있음 | 업무별 수행 범위와 필요 능력의 검사·보완 경로를 확정 |
| 복합 실패 | 개별 기능의 검사만으로 조합의 상태·순서·손실을 보장할 수 없음 | 정상 경로와 실패·취소·지연·복구의 연결을 시나리오별 대조 |
| 미지의 문제 | 모델의 자기 확신만으로 모르는 범위를 판정할 수 없음 | 반대 증거·예상 밖 관측·외부 오류·보호된 새 과제의 독립된 신호를 연결 |
