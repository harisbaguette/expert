# 로컬 모델 속도 기준의 비교 근거 (2026-10-01 확인)

정의 1의 로컬 모델 조건 '속도'에 쓴 숫자의 근거다.

| 숫자 | 근거 |
|------|------|
| 사람이 한국어를 읽는 속도 1초에 약 10자 | 성인 평균 분당 550~650자(리딩아이 학년별 독서 속도 비교표, 업체 자료). 대한안과학회지 2016;57(4) 묵독 연구의 202 어절/분에 어절당 약 2.9음절을 곱하면 분당 약 590자로 같은 범위다(환산은 직접 계산) |
| 한글 1자 ≈ 토큰 약 1개 | Claude 토크나이저로 잰 한국어는 100자에 약 106토큰(Synthorai). Qwen 토크나이저는 직접 잰 값을 못 찾았고 한글 음절 1자당 1토큰 안팎으로 본다. 모델마다 다르므로 실제 모델로 재 보면 된다 |
| 1초·10초 | Jakob Nielsen, Response Times: The 3 Important Limits (NN/G). 0.1초는 즉각, 1초는 생각의 흐름이 끊기지 않는 한계, 10초는 주의를 붙들어 두는 한계다 |
| 3만 토큰 | 한 건의 문서 분량으로 정한 값이다. 한글 3만 자는 사람이 읽는 데 약 50분 걸린다 |
| 4만 토큰 ÷ 30 = 약 22분 | 계산 |

DGX Spark에서 입력 처리 속도는 모델 크기에 따라 초당 약 800~8,000토큰으로 재어진 사례가 있다(LMSYS, 2025-10-13). 이 값이면 3만 토큰 입력의 첫 토큰은 4~40초가 걸려 10초 기준이 모델을 가른다. ③의 주 모델은 실제로 올려 재어야 한다.
