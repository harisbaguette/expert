## 이미 잘 된 점(여러 관점이 공통으로 짚음)

- 파일과 DB 사이 틈을 '받는 중' 선등록과 고아 검사로 막음.
- 외부 행동은 AI가 제안만 하고 사전 기록→실행→실제 결과 대조. 이중 신고·송금을 구조로 막음.
- 삭제를 PC 밖 보호 이력으로 남겨 복원 뒤 다시 적용함(파일).
- 적용 시점이 쟁점이면 후보 시점마다 판본과 경과조치를 넘김. 위헌·상급심 파기 표시.
- 상태 변경과 작업 등록을 한 트랜잭션에 묶음(`enqueue_in_transaction`, 실제 API 확인).
- 공장의 해결책 1–28 배치와 재료 79개 배정은 신뢰성 문서·정의 1과 빠짐·중복 없이 맞음.
