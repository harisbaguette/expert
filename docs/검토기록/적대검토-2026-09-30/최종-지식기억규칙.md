## 🔴 (모두 고침)

### R1. 직업 윤리·의무 ① 정보 경계 — 하위 에이전트로는 당사자를 막지 못함

- 위치: 환경별 정답 "정보 경계 | 당사자마다 건 폴더와 하위 에이전트를 따로 둔다. … 셸 명령은 샌드박스의 읽기 범위로 막고", 합격 조건 "당사자 A의 하위 에이전트가 B의 폴더를 읽으려 하면 막히고"
- 무엇이 틀렸나: Claude Code 하위 에이전트의 설정 칸에는 샌드박스나 경로 권한을 따로 줄 칸이 없다. 하위 에이전트는 주 대화와 같은 샌드박스를 쓰므로, A 쪽 하위 에이전트의 셸 명령이 B 폴더를 읽는 것을 막을 수 없다. Codex는 분리 실행 재료가 적은 대로 읽기 범위를 폴더 단위로 좁히는 설정이 시험 기능이다. 그대로 만들면 합격 조건을 통과할 수 없고, 같은 건 안 두 당사자의 비밀이 섞인다.
- 고친 것: 당사자마다 따로 만든 운영체제 사용자나 컨테이너에서 하네스를 따로 돌리고, 한 대화의 하위 에이전트로 당사자를 나누지 않는다. 합격 조건도 "A 쪽으로 돌린 하네스가 셸 명령으로도, 파일 도구로도 B 폴더를 읽으려 하면 막힌다"로 바꿈.
- 근거: https://code.claude.com/docs/en/sub-agents (지원 칸 목록에 샌드박스·경로 권한 칸 없음), 정의 2 분리 실행 ① "고객 자료" 줄.

### R2. 계약·합의 조건 ① — 한도 검사에 쓰는 조항 파일을 모델이 고칠 수 있음

- 위치: "조항 목록 | 건 폴더에 조항 파일과 계약서 원문 카드를 둔다. 건 폴더는 … 모델이 그 건을 읽고 쓰는 자리다", "금액, 범위, 기한을 넘는 실행 막기 | … 이 건의 값만 … OPA에 입력으로 함께 넘긴다"
- 무엇이 틀렸나: 연결부가 OPA에 넘기는 금액·범위·기한을 모델이 쓸 수 있는 파일에서 읽으면, 자료 속 숨긴 지시에 넘어간 모델이 값을 올려 한도 검사를 비켜 갈 수 있다. 현재 진행 상태가 건 파일을 "모델 계정이 쓰지 못하는 하위 폴더"에 두는 까닭과 같은 구멍이다.
- 고친 것: 조항 파일과 계약서 원문 카드는 기록 서비스가 건 파일과 같은 하위 폴더에 둔다. 연결부는 이 값을 그 조항 파일과 기억 폴더의 기본 계약에서 읽는다.

### R3. 조직 규칙 ① — 승인자를 정하는 전결 규정 사본을 모델이 고칠 수 있음

- 위치: "전결 규정과 조직도 받기 | … 저장소 안에서 그 건을 읽고 쓰는 건 폴더에 사본을 둔다. 승인을 요청하기 전에 연결부가 이 사본의 승인자 칸을 … OPA에 입력으로 넘겨 승인자를 정한다"
- 무엇이 틀렸나: R2와 같은 뿌리. 모델이 사본의 승인자 칸을 바꾸면 승인 요청이 권한 없는 사람에게 가고, 그 사람의 승인으로 실행된다.
- 고친 것: 사본은 기록 서비스가 건 파일과 같은 하위 폴더(모델 계정이 쓰지 못함)에 둔다.
- 같은 뿌리 전수: 이 구간에서 연결부·OPA가 읽는 값을 두는 곳은 건 파일(보호됨), 기억 폴더(장기 기억이 보호), 직종 공통 폴더(읽기만), 기록 보관 폴더(기록 서비스만)와 위 두 곳이다. 두 곳만 모델이 쓸 수 있는 자리였고 둘 다 고침.

### R4. 직업 윤리·의무 같은 사람 찾기 — 주민등록번호를 이해충돌 대조에 씀

- 위치: "법인등록번호나 주민등록번호처럼 … 개인사업자는 그 사람의 주민등록번호로 다시 맞춰 보고 … 주민등록번호는 법이 처리를 허락한 업무에서 이미 받은 것만 대조에 쓴다"
- 무엇이 틀렸나: 개인정보 보호법 제24조의2 제1항은 법령이 "구체적으로 주민등록번호의 처리를 요구하거나 허용한 경우" 등이 아니면 주민등록번호를 처리할 수 없게 한다. 처리에는 이용이 든다. 어떤 업무에서 법이 허락해 받은 번호라도, 이해충돌 대조라는 다른 쓰임을 허락한 법령은 없다. 위반은 제75조 제2항 제7호 3천만원 이하 과태료다. 정의 2 다른 재료("업무에 필요 없는 개인정보 (주민등록번호, 계좌번호 등) | 받을 때부터 담지 않는다")와도 어긋난다.
- 고친 것: 주민등록번호는 법이 처리를 허락한 업무에서 받은 번호라도 대조에 쓰지 않는다. 법인은 법인등록번호로, 개인사업자는 사업자등록번호가 달라도 대표자 이름이 같으면 같은 사람으로 본다(이해충돌은 넓게 잡는다는 기존 원칙 그대로).
- 근거: 개인정보 보호법 제24조의2, 제75조 제2항 제7호(법률 제21445호, 시행 2026-09-11). https://www.law.go.kr/법령/개인정보보호법/제24조의2
