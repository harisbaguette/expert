## 🔴 고침

### R1. 법정 보존 중인 자료의 열쇠를 먼저 파기함

- 위치: 보관 기간과 지우기. 표 2행 "법정 보존 기간이 남았으면 열쇠를 먼저 파기하고, 그 기간이 끝날 때까지 둔다", 본문 "그동안 고객 열쇠를 파기해 개인정보를 못 읽게 하고", 순서도 P 노드.
- 무엇이 틀렸나: 법이 보존하라고 한 자료를 못 읽게 만들면 보존 의무를 지키지 못한다. 세무 조사나 분쟁 때 꺼내 보여 줄 수 없다. 개인정보 보호법은 보존해야 하는 개인정보를 파기하지 말고 다른 개인정보와 분리해 저장·관리하라고 정한다. 전자 보관은 내용을 열람할 수 있어야 보관으로 인정된다. 또 같은 고객 열쇠로 잠긴 자료 가운데 일부만 남길 방법이 없었다.
- 근거:
  - 개인정보 보호법 제21조 ①단서·③ (시행 2026-09-11). https://www.law.go.kr/법령/개인정보보호법/제21조
  - 전자금융거래법 제22조, 시행령 제12조 ④ (전자문서법 제5조 요건 준수). https://www.law.go.kr/법령/전자금융거래법시행령/제12조
  - 전자문서 및 전자거래 기본법 제5조 ①, 제4조의2 (열람할 수 있을 것). https://www.law.go.kr/법령/전자문서및전자거래기본법/제5조
  - 국세기본법 제85조의3 ② 장부·증거서류 법정신고기한부터 5년(역외 7년). https://www.law.go.kr/법령/국세기본법/제85조의3
- 고친 것: 의무가 남은 자료는 다른 자료와 나눠 다른 열쇠로 잠가 따로 두고, 법이 정한 쓰임 말고는 열지 않으며, 기간이 끝나면 그 열쇠도 파기한다. 표 1·2행과 순서도 P 노드를 같은 뜻으로 맞췄다. 순서도는 mermaid-cli로 다시 그려 깨지지 않는 것을 확인했다.

### R2. 해시 창고 잠금을 S3 밖의 길로 우회할 수 있음

- 위치: ②·③ 부품 표의 SeaweedFS 행, 자료가 사는 자리 Object Lock 줄, 합격 기준 "잠긴 원본을 관리자 계정으로 지우려 하면 거부된다".
- 무엇이 틀렸나: SeaweedFS의 Object Lock은 S3 접속에서만 검사한다. 같은 창고의 파일 서버 HTTP API는 `DELETE`로 파일을 지우며, 잠금 검사에 대한 말이 없다. 합격 시험을 S3 경로로만 하면 통과해도 우회 길이 열려 있다. 2026-09-15에는 COMPLIANCE 잠금이 S3 삭제에서도 먹히지 않는다는 이슈가 다시 올라왔다. 관리자는 최신 코드에서 재현하지 못했다며 회귀 시험만 더했다.
- 근거:
  - SeaweedFS S3 Object Lock 문서(모드 설명, S3 API 기준). https://github.com/seaweedfs/seaweedfs/wiki/S3-Object-Lock-and-Retention
  - Filer Server API `curl -X DELETE http://localhost:8888/path/to/file`. https://github.com/seaweedfs/seaweedfs/wiki/Filer-Server-API
  - 이슈 #11333(2026-09-15, 닫힘), PR #11335. https://github.com/seaweedfs/seaweedfs/issues/11333 , https://github.com/seaweedfs/seaweedfs/pull/11335
- 고친 것: 창고에는 S3 접속으로만 닿게 하고 파일 서버·관리 명령으로 바로 지우는 길은 막는다는 줄을 넣었다. 합격 기준은 두 경로 모두에서 거부되는지 보게 바꿨다. S3 접속이 무엇인지 한 문장으로 풀었다.

### R3. 시점 복구 뒤 바깥 행동을 대조하지 않고 다시 켬

- 위치: 저장한 것이 어긋나거나 깨졌을 때 → 데이터베이스가 깨졌다. "그다음 창고와 대조하고 색인을 다시 만든다", "대조에서 끊긴 것이 0개면 다시 켠다".
- 무엇이 틀렸나: 과거 시각으로 되살리면 그 뒤에 적은 요청 번호와 실행 기록이 사라진다. 그 사이 송금·발송·제출이 나갔다면, 다시 켰을 때 같은 행동이 새 번호로 또 나간다. 같은 구간의 "운영에서 계속 확인할 것"은 "바깥 상태와 대조한 뒤 다시 시작한다"고 정해 두었는데, 이 절차에는 그 대조가 빠져 있었다.
- 고친 것: 되살린 시각 뒤에 나갔을 수 있는 행동은 결과 불명으로 보고 상대 쪽에 조회해 맞춘다. 모두 확인하거나 사람에게 넘긴 뒤에 다시 켠다.
