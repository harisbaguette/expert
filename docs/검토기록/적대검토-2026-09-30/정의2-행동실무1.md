## 확인했고 맞는 것

- DuckDB excel 확장: xlsx 읽기·쓰기, xls는 지원하지 않음, 핵심 확장으로 자동 적재(duckdb.org/docs/current/core_extensions/excel.html). 옛 엑셀을 LibreOffice로 바꾸는 규칙이 맞다.
- Splink: DuckDB가 기본 백엔드이고 쌍마다 일치 확률을 낸다. 지금 판은 Splink 5(moj-analytical-services.github.io/splink).
- Codex Remote: ChatGPT 데스크톱 앱이 켜진 컴퓨터가 있어야 한다(learn.chatgpt.com/docs/remote).
- Claude Code 질문 도구는 한 번에 1~4개 물음을 받는다. "물음은 넷까지"와 맞다(code.claude.com/docs/en/hooks AskUserQuestion).
- 공공데이터포털 특일 정보는 한국천문연구원이 낸다(data.go.kr/data/15012690).
