# 전문 판단의 신뢰성 — 3차 시뮬레이션과 비난(문서 전체)

2차에서 고친 문장이 새로 연 틈과 남은 구멍을 다섯 관점(새 직종, 공격자, 추적과 일관성, 직업윤리와 법, 검토자와 만드는 AI와 고객)으로 봤다.

## 고친 것

| 묶음 | 고친 곳 |
|---|---|
| 그대로 믿고 써도 되는 결론을 고르는 기준이 없음 | 결론 행에 기준과 합친 결론은 가장 약한 쪽을 따르게 하고, 검사 코드가 본문 표시와 맞춰 봄 |
| 위험 범위가 비면 세 기준이 비어 있음 | 잴 수 있는 값으로 받고, 없으면 업무 종류별 기본값을 쓰고 알림. 문서 전체를 '이번 일의 위험 범위'로 맞춤 |
| 업무 종류마다 정해 둘 것의 주인이 없음 | 운영하는 쪽이 맡기 전에 정하고 만드는 쪽은 읽기만 함. 목록을 한곳에 모음 |
| 별도 검토의 계기와 방법이 곳마다 다름 | 모든 결과물은 검사 코드와 품질 대조, 다시 판단할 대상은 다른 계열 모델이 답을 보지 않고 재판단. 물음은 실행 제어가 만들고, 갈리면 사람에게 넘김 |
| 뺀 자료 재판단이 모든 판단에 걸림 | 다시 판단할 대상만 재판단하고, 나머지는 처음부터 가린 자료로 판단 |
| 주 모델로 보내는 자료가 전달 검사에서 빠짐 | 밖에서 운영하는 모든 모델로 보내는 것을 전달로 보고 권한 표에 넣음 |
| 정보를 준 '사람' 보호가 상대방까지 덮음 | 고객의 정보로 좁히고 이번 업무 밖의 불리한 사용만 막음 |
| 비밀 예외 문구 | 거의 확실한 큰 해, 소송과 고소와 징계와 감독기관 조사의 방어로 고치고, 후기와 언론 대응은 뺌. 법 요구는 공식 연락처로 확인 |
| 이해 충돌 확인 범위와 명부 | 운영하는 쪽의 모든 건, 자기 결과물 검토, 동의로 못 푸는 충돌, 예전 고객과 상담만 한 사람의 동의를 넣음. 명부는 충돌 여부만 에이전트에, 겹친 건은 책임자만 봄 |
| 공동 의뢰와 조직 담당자 | 일부 맡기의 조건, 담당자에게 알림, 윗선이 없을 때, 고용형에서 조직과 맞서는 사람에게 알림 |
| 쟁점별 결론 목록이 고객과 계획을 드러냄 | 일반 문장으로만 쓰고 짐작되면 남기지 않으며, 판본과 날짜를 남김 |
| 처리 건수 장치를 분모와 흐린 말로 피함 | 대상 목록은 실행 제어가 센 전체로, 범위 표현 금지 |
| 스크립트 속 변경이 대조에서 빠짐 | 원본 시스템의 변경 기록과도 대조하고, 셸과 SQL은 미리 돌려 본 대상으로 검사 |
| 링크 검사 우회와 허용된 받는 사람에게 섞여 나감 | 최종 파일의 모든 주소, 주소 전체 허용, 값의 출처 추적 |
| 숨긴 글 찾기가 문서에만 걸림 | 대비와 크기를 재고, 문서가 아닌 자료에도 적용. 평가받는 쪽 자료는 도구 없는 별도 모델이 항목만 뽑음 |
| 미리 허락을 목적 이름으로 넓힘 | 실제 대상과 내용이 허락에 맞는지 보고, 목적은 허락의 구분으로, 진행 중인 몫도 합침 |
| 쏠림 확인 | 직무 필요 근거, 빠진 건수와 대리 기준, 두 번 이어지면 시험 자료 |
| 주장 결과물 | 업무 종류마다 지정, 고객 진술은 남은 곳과 자료 대조, 오해를 낳는 생략과 법이 내라는 근거는 넣음, 다투지 않은 주장, 광고는 실증 자료만 |
| 대외 결과물과 법정 서식 | 서식대로 내고 표시는 검토표로 |
| 결과를 받은 시스템이 되돌릴 수 없는 처리를 이어 함 | 되돌릴 수 없는 행동으로 봄 |
| 사람 재검토와 자격자 검토 | 자동 판단 거부를 넣고 한 사람이 볼 양을 정함 |
| 생명 조치의 사칭 | 미리 정한 곳에 위치와 위험만 알림 |
| 맡을 때 묻기가 흩어짐 | 한 번에 모아 묻는 목록 |
| 변경 감시의 구현 | 색인 갱신일, 공식 출처 조회, 감시 목록과 주기 |
| 기억 단위 사실 오류 | Claude Code는 저장소와 사용자 단위, Codex는 사용자 단위로 고침 |
| 앞 단계 기록 보호와 보관 뒤 삭제 | 작업 폴더 밖 덧붙이기, 기한 뒤 개인정보 기록 삭제 |
| 순서도 | 계산 뒤 초안, 맡을 때 업무 가리기, 전달 전 권한 검사와 양쪽 대조 |
| 수식 | 규칙·기준 원문, 못 찾음·없음 구분, 계약·합의 조건, 전달·인수 확인, 보고 주체 확인을 넣음 |
| 이름 | '실행 프로그램'을 정의 1의 '실행 제어'로, '하네스'를 'Claude Code나 Codex'로 바꿈. 겹치는 문단을 지움 |
