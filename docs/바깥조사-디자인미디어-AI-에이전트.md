# 바깥 조사 — 디자인·영상·미디어 AI 에이전트

진행 계획 3단계 '바깥 조사 — 남이 만든 에이전트 비교' 의 두 번째 직종군임 (첫 번째는 법률). 확인일 2026-09-11.
다루는 직종: UI/UX·제품 디자인 / 그래픽 / 브랜드 / 모션 / 편집 디자인 / 제품(산업) 디자인 / PD / 방송 작가 / 에디터 / 영상 편집자 / 영상 제작자(광고·홍보) / 작곡가 / 일러스트레이터.
촬영·현장 연출처럼 밖에 나가서 하는 일은 빼고, **화면 안에서 끝나는 일만** 봤음.
확신도는 FACT(독립 출처 3개 이상) · LIKELY(출처 2개) · LIKELY(자체)(회사 스스로 발표한 것만) · 미확인 으로 붙임.

## 한 줄 결론

디자인·영상·미디어 쪽은 법률과 정반대임. **만드는 일은 AI가 이미 혼자 끝까지 해냄** — 그림도, 광고 영상도, 노래도, UI 화면도 사람 손 없이 나옴. 그런데 **끝내기(검수·승인·책임)를 아무도 기계에 맡기지 않음**. 막는 것은 자격증이 아니라 세 가지임: ① 저작권이 사람 창작자에게만 붙는다는 법 (미국 대법원이 2026-03-02 확정), ② 광고를 AI로 만들면 소비자가 브랜드를 덜 믿는다는 실측 결과, ③ 노조·작가·독자의 거부. 그래서 여기 제품들은 "사람을 대체했다" 고 말하지 않고 "빨리 만들어 준다" 고만 말함. **성과 지표(전환율·시안 채택률·수정 횟수·완주율)로 스스로를 재는 제품은 한 곳도 확인하지 못했음.**

## 5. 우리 정의와 대조

### 5-1. 다섯 경우와 5단계

| 우리 기준 | 남들 현황 | 판정 |
|---|---|---|
| 되돌릴 수 없는 행동 | 광고 집행·방송 송출·곡 발표가 여기 해당함. 맥도날드·일본 화장품 브랜드처럼 **내보낸 뒤 내리는 사고**가 실제로 남 | 사람이 껴야 하는 게 맞음 — 우리 정의와 일치 |
| 승인 조건 | 브랜드 검수, 초상권 동의, 저작권 정리 — 전부 사람 승인 | 남들도 여기서 멈춤 |
| 판단이 서지 않는 것 | "이 시안이 브랜드에 맞나"를 기계가 판단하지 못함. 판단 기준 자체가 문서로 없음 | **남들은 이 칸을 아예 비워 둠** |
| 한도 초과 | 광고비 한도·제작비 한도로 멈추는 장치를 확인하지 못했음 | 비어 있음 |
| 자격자 전속 행위 | 디자인·영상에는 자격증이 없음. 대신 **저작권법(사람만 저작자)**과 **노조 계약(SAG-AFTRA)**이 같은 구실을 함 | 우리 정의의 '자격자 전속'을 이 직종에서는 '권리·동의'로 바꿔 읽어야 함 |
| 보기(현황 파악) | 상품 링크·브리프를 읽어 오는 것까지는 함 (브이캣) | 일부 가능 |
| 알기(자료 찾기) | 브랜드 가이드·과거 시안을 찾아 읽는 기능은 확인하지 못했음 | 비어 있음 |
| 정하기(결정) | 어떤 시안을 쓸지 기계가 정하지 않음. 사람에게 여러 개를 보여 주고 고르게 함 | **핵심이 비어 있음** |
| 하기(실행) | **여기만 완성돼 있음.** 그림·영상·음악·화면을 실제로 만들어 냄 | 남들의 유일한 강점 |
| 끝내기(마무리·검수) | 기계가 스스로 "됐다"고 판정하는 장치가 없음. 광고 사고가 계속 나는 이유 | 비어 있음 |

## 6. 못 확인한 것 (솔직히)

이번 조사는 **검색 도구가 거의 다 막힌 상태에서 진행됐음**. 구체적으로:
- WebSearch는 세션 전체 한도(200회)를 다른 조사 일꾼들이 이미 다 써서 **한 번도 쓰지 못했음**.
