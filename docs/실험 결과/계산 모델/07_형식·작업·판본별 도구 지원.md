# 형식·작업·판본별 도구 지원

연결 직무: 050 · 058 · 090 · 123 · 157

## 가정

가상 도구 대장이다. 어떤 상용 프로그램이나 API의 실제 지원을 주장하지 않는다.

## 결과

- 실행 구성: 6개
- 계약 검사: 열거한 가상 구성에서 통과
- 계약 생략 비교군의 반례: 3개
- 비교군에서 생략한 계약: 같은 형식이 한 번 됐으면 모든 작업·판본도 된다고 가정

아래는 계산 코드의 실제 출력입니다. 합성 조건에 한정된 검사이며 실제 제품·전문가의 성적이 아닙니다.

## 구성별 출력

### 구성 1

```json
{
  "request": [
    "pptx",
    "create",
    "v1"
  ],
  "supported": true,
  "next": "execute"
}
```
