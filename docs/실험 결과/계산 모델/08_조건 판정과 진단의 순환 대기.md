# 조건 판정과 진단의 순환 대기

연결 직무: 034 · 097 · 112 · 129 · 135

## 가정

진단 관측과 본 실행의 권한은 독립. 허용한 관측도 불명 결과를 낼 수 있다. 대상 조건은 처음에 미확인이다.

## 결과

- 실행 구성: 12개
- 계약 검사: 열거한 가상 구성에서 통과
- 계약 생략 비교군의 반례: 4개
- 비교군에서 생략한 계약: 불명 조건을 무조건 대기시켜 그 조건을 판별할 진단도 시작하지 않음

아래는 계산 코드의 실제 출력입니다. 합성 조건에 한정된 검사이며 실제 제품·전문가의 성적이 아닙니다.
