# 공동 전문가·설비 일정

연결 직무: 032 · 059 · 096 · 128

## 가정

두 작업자, 각 8·8·10시간의 분할 불가 작업 세 개. 중단·분할·외주 불허.

## 결과

- 실행 구성: 3개
- 계약 검사: 열거한 가상 구성에서 통과
- 계약 생략 비교군의 반례: 1개
- 비교군에서 생략한 계약: 전체 시간 합계만 비교하고 작업별 배치를 생략

아래는 계산 코드의 실제 출력입니다. 합성 조건에 한정된 검사이며 실제 제품·전문가의 성적이 아닙니다.

## 구성별 출력

### 구성 1

```json
{
  "capacity_per_person": 8,
  "total_work": 26,
  "feasible": false,
  "witness": [],
  "aggregate_only_says_feasible": false
}
```

### 구성 2

```json
{
  "capacity_per_person": 13,
  "total_work": 26,
  "feasible": false,
  "witness": [],
  "aggregate_only_says_feasible": true
}
```

### 구성 3

```json
{
  "capacity_per_person": 16,
  "total_work": 26,
  "feasible": true,
  "witness": [
    {
      "assignment": [
        0,
        0,
        1
      ],
      "loads": [
        16,
        10
      ]
    }
  ],
  "aggregate_only_says_feasible": true
}
```
