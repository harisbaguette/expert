# 은행 응답 유실

연결 직무: 067 · 074 · 104 · 164

## 가정

조회가 성공하면 외부 실행 여부를 확정한다. 조회 불가를 실패 확정으로 간주하지 않는다.

## 결과

- 실행 구성: 4개
- 계약 검사: 열거한 가상 구성에서 통과
- 계약 생략 비교군의 반례: 2개
- 비교군에서 생략한 계약: 결과 불명과 확정 실패를 합쳐 재전송

아래는 계산 코드의 실제 출력입니다. 합성 조건에 한정된 검사이며 실제 제품·전문가의 성적이 아닙니다.

## 구성별 출력

### 구성 1

```json
{
  "initially_committed": false,
  "query_available": false,
  "action": "query pending; do not resend",
  "state": "unresolved",
  "payments": 0
}
```

### 구성 2

```json
{
  "initially_committed": false,
  "query_available": true,
  "action": "execute after confirmed nonexecution",
  "state": "confirmed",
  "payments": 1
}
```

### 구성 3

```json
{
  "initially_committed": true,
  "query_available": false,
  "action": "query pending; do not resend",
  "state": "unresolved",
  "payments": 1
}
```

### 구성 4

```json
{
  "initially_committed": true,
  "query_available": true,
  "action": "reuse confirmed receipt",
  "state": "confirmed",
  "payments": 1
}
```
