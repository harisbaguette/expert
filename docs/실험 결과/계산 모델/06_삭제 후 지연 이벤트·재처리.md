# 삭제 후 지연 이벤트·재처리

연결 직무: 086 · 109 · 112 · 114

## 가정

삭제 범위는 고객 A의 이 두 과거 기록이며 재수집 동의·보존 예외가 없다. B는 삭제 대상 밖이다.

## 결과

- 실행 구성: 6개
- 계약 검사: 열거한 가상 구성에서 통과
- 계약 생략 비교군의 반례: 4개
- 비교군에서 생략한 계약: 삭제 시점 데이터만 지우고 후속 재처리를 통제하지 않음

아래는 계산 코드의 실제 출력입니다. 합성 조건에 한정된 검사이며 실제 제품·전문가의 성적이 아닙니다.
