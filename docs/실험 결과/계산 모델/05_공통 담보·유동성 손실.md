# 공통 담보·유동성 손실

연결 직무: 070 · 072 · 077 · 153 · 166

## 가정

공동 충격에서는 직접 손실 6에 추가 현금 필요 4가 동시에 발생한다. 확률은 부여하지 않는다.

## 결과

- 실행 구성: 3개
- 계약 검사: 열거한 가상 구성에서 통과
- 계약 생략 비교군의 반례: 1개
- 비교군에서 생략한 계약: 직접 손실만 더하고 연쇄 현금 필요를 생략

아래는 계산 코드의 실제 출력입니다. 합성 조건에 한정된 검사이며 실제 제품·전문가의 성적이 아닙니다.

## 구성별 출력

### 구성 1

```json
{
  "shock": "none",
  "direct_loss": 0,
  "linked_liquidity_need": 0,
  "total_need": 0,
  "limit": 8,
  "within_limit": true
}
```

### 구성 2

```json
{
  "shock": "one_position",
  "direct_loss": 3,
  "linked_liquidity_need": 0,
  "total_need": 3,
  "limit": 8,
  "within_limit": true
}
```

### 구성 3

```json
{
  "shock": "shared_collateral",
  "direct_loss": 6,
  "linked_liquidity_need": 4,
  "total_need": 10,
  "limit": 8,
  "within_limit": false
}
```
