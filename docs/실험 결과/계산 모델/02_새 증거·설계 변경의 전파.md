# 새 증거·설계 변경의 전파

연결 직무: 002 · 031 · 065 · 122 · 138

## 가정

의존 그래프는 명시된 여섯 객체이며 제출된 외부 사본은 소급 삭제할 수 없다.

## 결과

- 실행 구성: 4개
- 계약 검사: 열거한 가상 구성에서 통과
- 계약 생략 비교군의 반례: 3개
- 비교군에서 생략한 계약: 바뀐 원본만 수정하고 파생 판단·파일의 합격을 유지

아래는 계산 코드의 실제 출력입니다. 합성 조건에 한정된 검사이며 실제 제품·전문가의 성적이 아닙니다.

## 구성별 출력

### 구성 1

```json
{
  "changed": "fact",
  "invalidated": [
    "brief",
    "calc",
    "drawing",
    "fact",
    "model",
    "pdf"
  ],
  "submitted_artifact": {
    "version": 1,
    "external_copy_preserved": true,
    "correction_required": true
  }
}
```

### 구성 2

```json
{
  "changed": "calc",
  "invalidated": [
    "brief",
    "calc",
    "pdf"
  ],
  "submitted_artifact": {
    "version": 1,
    "external_copy_preserved": true,
    "correction_required": true
  }
}
```

### 구성 3

```json
{
  "changed": "model",
  "invalidated": [
    "drawing",
    "model"
  ],
  "submitted_artifact": {
    "version": 1,
    "external_copy_preserved": true,
    "correction_required": false
  }
}
```

### 구성 4

```json
{
  "changed": "none",
  "invalidated": [],
  "submitted_artifact": {
    "version": 1,
    "external_copy_preserved": true,
    "correction_required": false
  }
}
```
