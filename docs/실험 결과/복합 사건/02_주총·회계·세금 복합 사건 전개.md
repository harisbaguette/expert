# 주총·회계·세금 복합 사건 전개

사건·수치·기관 반응을 가정한 탁상 모의입니다. 실제 사건의 법률·세무 결론이나 결과 예측이 아닙니다.

| 단계 | 들어온 사실·제약 | 선택과 상태 변화 |
|---|---|---|
| 접수 | 정관 변경·이사 선임·재편·배당·현금 목표가 얽힘 | 의안별 유효 권한·선행조건·회계/세무 전제·필요 증거를 구분 |
| 주주 반발 | 위임장·의결권 일부가 다투어지고 안건 변경 요구 | 결의가 성립했다고 가정하지 않고 진행안·대체안·기록·사후 조치를 조건별 구성 |
| 회계 수정 | 감사 근거가 바뀌어 재편 계산의 입력도 달라짐 | M18·M25·M53으로 세액·자금·공시·주총 자료까지 영향 전파 |
| 해석 갈림 | 유리한 해석과 불리한 해석에서 세액·현금이 달라짐 | 유리한 숫자만 선택하지 않고 양쪽에서 지켜야 할 한도와 미확정 조건 유지 |
| 계산 | 현금 10, 최소 운영 여유 4. 대안 A는 세액 1/6·기타 지급 5, B는 세액 3/3·기타 지급 2 | A의 잔여 현금은 4/−1로 불리한 경우 실패. B는 5/5로 조건 충족. 금액은 실제 세법과 무관한 가정 |
| 상대 거부 | 주주가 필요한 의안·배당 조정에 동의하지 않는 분기 | B가 계산상 가능해도 실행 선행조건 미충족. 합의·절차·대체 전략을 이어가며 성사 보장으로 바꾸지 않음 |
