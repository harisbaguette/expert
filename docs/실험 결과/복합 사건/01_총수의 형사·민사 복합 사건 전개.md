# 총수의 형사·민사 복합 사건 전개

사건·수치·기관 반응을 가정한 탁상 모의입니다. 실제 사건의 법률·세무 결론이나 결과 예측이 아닙니다.

아래 사건 번호·시간·금액은 모의 조건이다. 적용 법·실제 재판 결과를 예측한 것이 아니다.

| 단계 | 들어온 사실·제약 | 선택과 상태 변화 |
|---|---|---|
| 접수 | 형사 쟁점 30개·민사 쟁점 8개, 회사와 개인의 위임·비밀은 별개 | M25로 쟁점·증거·당사자 관계를 연결하고 M04로 공동 검토·제출 책임을 구분 |
| 증거 변경 | E12 원본이 F04·F11·F23의 기존 사실 전제에 반대됨 | 해당 주장·계산·서면의 기존 합격을 무효화. 관계없는 쟁점은 계속 처리. 불리한 근거를 삭제하지 않음 |
| 주장 충돌 | 회사 서면과 개인 서면이 같은 행위를 다르게 서술 | 동일 사실의 양립 불가 단정인지, 다른 법적 평가·조건부 주장인지 구분. 자동 다수결·문자열 일치로 판단하지 않음 |
| 관계 변경 | 회사 대표권이 다투어지고 개인 변호팀 자료 공유 범위가 축소됨 | 권한·접근·파생물·공동 작업을 재검토. 이미 제출된 외부 사본은 삭제한 것으로 처리하지 않음 |
| 긴급 일정 | 구속 관련 준비와 민사 제출이 겹쳐 공동 전문가 가용시간 부족 | 반드시 할 작업·담당·필수 검증을 재배정. 자원이 부족하면 지연·지원·범위 선택을 보고하며 필수 검증을 생략하지 않음 |
| 전략 선택 | 세액·합의 지급·운영 현금이 서로 영향을 줌 | 계산 모델의 A–D를 두 가정으로 비교. 가장 낮은 세액이 전체 최선이라는 선택을 배제 |
| 도달 | 공소사실 대조·증거표·전략 대안·신문사항·서면 구성·일정이 연결됨 | 준비·진행 경로가 존재. 구속 여부·심증·승소·합의·자격 수행 결과는 미확정이므로 사건 전체 해결로 세지 않음 |
