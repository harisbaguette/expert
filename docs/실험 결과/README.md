# 실험 결과

[법률 실험 상세 보고서·55개 재료 사용 기록](법률%20복합사건%20심층%20실험/06_테스트_상세결과와_재료_사용기록.md)

166개 직무에 변화 2개씩을 넣은 탁상 모의와 8개 계산 모델의 결과입니다. 각 파일에 해당 실험의 조건·전개·판정을 담았습니다.

| 최종 판정 | 직무 수 |
|---|---:|
| 범위 내 종결 경로 | 72 |
| 외부 결과·관측 대기 | 60 |
| 목표·조건 조정 필요 | 34 |

탁상 모의의 자료·도구 응답은 가정이며 실제 에이전트 성능이나 성공률을 뜻하지 않습니다. 계산 모델은 42개 구성을 실행했고, 계약을 생략한 비교군에서 19개 반례가 나왔습니다.

보완: 조건을 판정할 진단의 의존과 본 실행의 의존을 분리했습니다. 034·097·112·129·135는 보완 후 재전개를 포함합니다.
