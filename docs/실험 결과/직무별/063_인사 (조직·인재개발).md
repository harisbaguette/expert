# 063. 인사 (조직·인재개발)

유형: 고용형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 외부 결과·관측 대기**

## 초기 복합 사건

관리자 교육 만족도는 높지만 현장 행동은 바뀌지 않고 조직 개편 뒤 책임 공백과 핵심인재 이탈이 늘어남

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 교육 수료자는 늘었지만 업무 승인 병목 때문에 행동 변화 없음 |
| 선택 1·재료 | M18·M34: 역량 문제와 조직 권한·보상 문제를 분리 |
| 변화 2 | 관리자가 새 역할을 수용하나 현장 적용 기간은 아직 없음 |
| 선택 2·재료 | M35·M38·M51: 교육·조직 조치와 행동 관찰을 묶음 |
| 첫 도달 상태 | 개선안 준비 가능, 실제 조직 행동·유지 효과는 추적 필요 |
| 첫 판정 | 외부 결과·관측 대기 |
