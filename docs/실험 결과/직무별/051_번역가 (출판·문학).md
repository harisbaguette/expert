# 051. 번역가 (출판·문학)

유형: 위임형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 범위 내 종결 경로**

## 초기 복합 사건

화자별 말투와 장기 복선이 있는 소설에서 후반 원고가 바뀌고 시대어를 현대어로 바꾸면 인물관계가 달라짐

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 후반 반전이 바뀌어 앞부분 화자 말투가 복선을 노출 |
| 선택 1·재료 | M23·M25: 인물·화자·복선 관련 구간만 재검토 |
| 변화 2 | 모의 독자·편집 의견이 의미 보존과 리듬 개선안에 일치 |
| 선택 2·재료 | M22·M46: 전권 일관성·읽기 경험·판본 검수 |
| 첫 도달 상태 | 제공된 독자 피드백 아래 번역·교정 종결 경로 있음 |
| 첫 판정 | 범위 내 종결 경로 |
