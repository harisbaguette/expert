# 080. 법무 (소송·분쟁)

유형: 고용형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 외부 결과·관측 대기**

## 초기 복합 사건

고객 손해배상 소송과 임직원 형사 사건에 같은 이메일이 쓰이고 외부로펌마다 다른 전략·자료 요청을 보냄

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 한 이메일이 민사와 형사에서 다른 전제로 사용됨 |
| 선택 1·재료 | M18·M25·M43: 공통 사실·절차별 주장·반대 근거를 분리 |
| 변화 2 | 회사·임원 사이 이해충돌과 공유 제한 발생 |
| 선택 2·재료 | M27·M31·M04: 담당·자료 접근·기존 파생물·제출 전략 재검토 |
| 첫 도달 상태 | 전략·자료 관리 가능, 소송 결과·전문 수행은 외부 의존 |
| 첫 판정 | 외부 결과·관측 대기 |
