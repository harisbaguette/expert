# 077. 리스크 관리

유형: 고용형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 목표·조건 조정 필요**

## 초기 복합 사건

여러 부서가 각자 한도 안이지만 같은 담보와 거래상대에 노출돼 공통 충격 때 손실·증거금이 동시에 증가함

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 같은 담보를 세 부서가 서로 독립 자산처럼 계산 |
| 선택 1·재료 | M25·M53: 공동 담보·충격·증거금 수요로 재통합 |
| 변화 2 | 개별 한도는 모두 통과하지만 통합 현금 한도 초과 |
| 선택 2·재료 | M33·M34: 신규 노출·담보 이전·축소 대안 제시 |
| 첫 도달 상태 | 현재 전사 한도로 모든 포지션 유지 불가 |
| 첫 판정 | 목표·조건 조정 필요 |
