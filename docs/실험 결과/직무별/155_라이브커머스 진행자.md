# 155. 라이브커머스 진행자

유형: 운영형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 범위 내 종결 경로**

## 초기 복합 사건

방송 중 가격·쿠폰·재고가 바뀌고 시연 결과가 기대와 달라 잘못된 효능·수량을 말할 위험이 생김

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 방송 중 쿠폰 종료·품절·시연 결과 변화 |
| 선택 1·재료 | M08·M18·M38: 현재 가격·재고·효익 사실을 즉시 재확인 |
| 변화 2 | 모의 판매 시스템·시연 입력이 변경 사실을 확인 |
| 선택 2·재료 | M10·M42: 잘못된 안내 정정·혜택·주문 인계 대조 |
| 첫 도달 상태 | 제공된 실시간 입력 아래 판매 안내·정정 경로 있음 |
| 첫 판정 | 범위 내 종결 경로 |
