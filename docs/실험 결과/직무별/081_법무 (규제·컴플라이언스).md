# 081. 법무 (규제·컴플라이언스)

유형: 고용형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 범위 내 종결 경로**

## 초기 복합 사건

해외 서비스 출시에서 데이터 이전·소비자 고지·파트너 계약 조건이 달라 한 국가의 표준 약관을 복제할 수 없음

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 해외팀의 실제 데이터 흐름이 법무가 본 설계와 다름 |
| 선택 1·재료 | M07·M25·M26: 행위·국가·수신자별 적용 조건 다시 연결 |
| 변화 2 | 가상 요건표에서 한정 배포와 데이터 지역 분리가 허용됨 |
| 선택 2·재료 | M35·M42: 출시 조건·통제·미확인 해석을 구분해 인계 |
| 첫 도달 상태 | 주어진 요건·환경에서 한정 출시 검토안 종결 경로 있음 |
| 첫 판정 | 범위 내 종결 경로 |
