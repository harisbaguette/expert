# 021. 회계사 (자문·실사)

유형: 위임형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 범위 내 종결 경로**

## 초기 복합 사건

인수 대상의 EBITDA에 일회성 보조금이 포함되고 매출채권 회수와 재고 가치가 부풀려져 정상 운전자본이 다툼이 됨

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 반복매출로 분류한 계약에 일회성 설치비와 취소분이 섞임 |
| 선택 1·재료 | M52·M53: 수익의 질·정상화 EBITDA·운전자금 재작성 |
| 변화 2 | 매도자가 자료 수정을 인정하고 가상 원장 대사도 일치 |
| 선택 2·재료 | M25·M42: 발견사항을 가격 조정·계약 인계에 반영 |
| 첫 도달 상태 | 재무실사·가격 조정 근거 패키지 종결 경로 있음 |
| 첫 판정 | 범위 내 종결 경로 |
