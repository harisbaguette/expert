# 020. 회계사 (감사)

유형: 위임형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 외부 결과·관측 대기**

## 초기 복합 사건

재고 실사 차이가 크고 기말 매출이 급증했는데 결산 후 반품이 늘고 외부조회 회신도 부족함

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 실사 재고와 장부가 다르고 기말 매출의 검수도 미완료 |
| 선택 1·재료 | M18·M35: 감사 주장별 추가 절차·추정·정정 영향 연결 |
| 변화 2 | 경영진이 외부조회와 핵심 자료 제공을 제한 |
| 선택 2·재료 | M27·M39·M43: 증거 제한·의견 판단을 구분하고 자격자의 책임·기여 기록 |
| 첫 도달 상태 | 미확인 영역을 숨기지 않는 경로는 있으나 감사의견 확정은 외부 의존 |
| 첫 판정 | 외부 결과·관측 대기 |
