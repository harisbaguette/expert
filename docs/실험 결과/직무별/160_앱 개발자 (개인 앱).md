# 160. 앱 개발자 (개인 앱)

유형: 운영형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 범위 내 종결 경로**

## 초기 복합 사건

OS 업데이트와 결제 복원 오류가 겹쳐 기존 구독자가 기능을 잃고 스토어 설명·개인정보·현금 흐름까지 수정해야 함

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | OS 갱신 후 구독 복원·기존 계정 기능 접근 오류 |
| 선택 1·재료 | M25·M31·M35: 구매·계정·권한·복원 상태 분리 |
| 변화 2 | 모의 기존 설치·재설치·해지·복원 시험 통과 |
| 선택 2·재료 | M10·M42·M40: 앱·스토어 설명·지원·기존 고객 인수 연결 |
| 첫 도달 상태 | 제공된 스토어·기기 응답 아래 앱 수정 경로 있음 |
| 첫 판정 | 범위 내 종결 경로 |
