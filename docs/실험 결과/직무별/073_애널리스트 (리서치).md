# 073. 애널리스트 (리서치)

유형: 고용형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 범위 내 종결 경로**

## 초기 복합 사건

기업은 수주 급증을 발표했지만 선수금·취소·납기 자료가 달라 매출 전환과 마진 추정이 바뀜

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 수주 중 취소 가능분과 저마진 물량이 추가 확인 |
| 선택 1·재료 | M18·M53: 매출 전환·마진·평가 가정 수정 |
| 변화 2 | 회사의 추가 설명과 공시 원문이 일치하는 범위 확인 |
| 선택 2·재료 | M43·M47: 반대 시나리오·근거·변경 이유를 보고서에 반영 |
| 첫 도달 상태 | 주어진 자료에서 리서치 보고서 종결 경로 있음 |
| 첫 판정 | 범위 내 종결 경로 |
