# 119. 그래픽

유형: 고용형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 범위 내 종결 경로**

## 초기 복합 사건

한 키비주얼을 옥외·모바일·인쇄로 펼치는데 작은 글자·색역·이미지 권리·재단 조건이 충돌함

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 모바일에서는 읽히지만 옥외·인쇄에서 작은 글자와 색이 깨짐 |
| 선택 1·재료 | M09·M35: 매체별 위계·크기·색·재단 변형 |
| 변화 2 | 모의 실크기·출력 검수가 수정본과 편집 원본 통과 |
| 선택 2·재료 | M42·M40: 연결 자산·권리·매체별 납품 검수 |
| 첫 도달 상태 | 제공된 출력 조건 아래 그래픽 납품 경로 있음 |
| 첫 판정 | 범위 내 종결 경로 |
