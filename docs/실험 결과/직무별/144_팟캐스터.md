# 144. 팟캐스터

유형: 운영형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 범위 내 종결 경로**

## 초기 복합 사건

원격 인터뷰 음질이 깨지고 게스트 발언을 줄이면 맥락이 달라져 분량·사실·청취 경험·협찬 조건을 조정해야 함

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 원격 인터뷰 녹음의 핵심 발언 일부가 손실 |
| 선택 1·재료 | M07·M18: 복원 가능한 음질 문제와 사라진 발언 구분 |
| 변화 2 | 재녹음은 불가하나 해당 구간 제외·쇼노트 보완에 출연자 동의 |
| 선택 2·재료 | M09·M42·M40: 맥락·청취·전사·피드 검수 |
| 첫 도달 상태 | 축소된 합의 범위에서 에피소드 납품 경로 있음 |
| 첫 판정 | 범위 내 종결 경로 |
