# 058. 영상 제작자 (광고·홍보)

유형: 위임형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 범위 내 종결 경로**

## 초기 복합 사건

제품 광고 촬영 후 핵심 기능이 변경되고 재촬영 예산은 없는데 가로·세로 버전과 자막·권리 조건을 모두 맞춰야 함

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 촬영된 제품 기능이 변경되어 기존 컷의 표현이 사실과 다름 |
| 선택 1·재료 | M18·M25: 광고 주장과 컷·자막·음성을 함께 무효화 |
| 변화 2 | 재촬영 없이도 사실에 맞는 편집안이 있고 매체별 모의 재생 통과 |
| 선택 2·재료 | M09·M42·M40: 가로·세로·자막·권리·원본 묶음 검수 |
| 첫 도달 상태 | 주어진 소스·재생 응답 아래 광고 영상 납품 경로 있음 |
| 첫 판정 | 범위 내 종결 경로 |
