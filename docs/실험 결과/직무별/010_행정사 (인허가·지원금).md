# 010. 행정사 (인허가·지원금)

유형: 위임형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 외부 결과·관측 대기**

## 초기 복합 사건

임차 공장에 새 공정을 들이려는데 토지·건축 용도와 환경 관련 조건이 맞지 않고 지원금 신청서에는 설치 완료를 전제로 씀

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 공장 신청 도면과 실제 용도가 다르고 지원사업 전제도 달라짐 |
| 선택 1·재료 | M07·M12·M35: 허가·지원 조건과 도면·공정의 연결을 재검토 |
| 변화 2 | 지자체의 현장 보완 요구와 지원 마감이 겹침 |
| 선택 2·재료 | M35·M39: 현장 수행·보완·신청 순서를 조정하고 미충족 조건 표시 |
| 첫 도달 상태 | 신청 묶음은 정리되나 현장·기관 판단 없이 승인 완료 불가 |
| 첫 판정 | 외부 결과·관측 대기 |
