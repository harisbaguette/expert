# 096. PMO

유형: 고용형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 목표·조건 조정 필요**

## 초기 복합 사건

세 프로젝트가 같은 전문가·공급사를 쓰며 각 일정표는 정상인데 통합 출시일과 규제 마감은 동시에 달성 불가함
