# 133. SCM 계획 (수요예측·S&OP)

유형: 고용형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 목표·조건 조정 필요**

## 초기 복합 사건

영업의 낙관 예측·판촉·장기 조달·생산 능력·현금 부족이 충돌하고 품절로 관측 수요 자체가 낮게 잡힘

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 품절로 수요가 낮게 관측되고 판촉 예측은 과대 |
| 선택 1·재료 | M52·M53: 검열 수요·편향·공급·현금 제약 통합 |
| 변화 2 | 서비스 목표·재고 상한·예산을 고정하면 공급 계획에 해가 없음 |
| 선택 2·재료 | M04·M38: 부서별 목표의 교환과 조정 선택 제시 |
| 첫 도달 상태 | 고정된 S&OP 목표의 동시 실행 불가능 |
| 첫 판정 | 목표·조건 조정 필요 |
