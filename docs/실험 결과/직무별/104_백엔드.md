# 104. 백엔드

유형: 고용형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 범위 내 종결 경로**

## 초기 복합 사건

결제 응답 유실·동시 취소·메시지 재전송이 겹쳐 결제사와 주문·재고 상태가 서로 달라짐

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 외부 결제 성공과 주문 실패가 동시에 확인 |
| 선택 1·재료 | M10·M25: 부분 성공으로 기록하고 재결제 금지 |
| 변화 2 | 외부 조회에서 성공 영수증·재고 미차감이 확인 |
| 선택 2·재료 | M35·M42: 보상 또는 주문 복원 경로를 선택해 불변조건 대사 |
| 첫 도달 상태 | 주어진 조회·보상 응답 아래 거래 일관성 복구 경로 있음 |
| 첫 판정 | 범위 내 종결 경로 |
