# 069. 세무 (사내)

유형: 고용형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 외부 결과·관측 대기**

## 초기 복합 사건

해외 자회사 수수료·이전가격·배당·조직재편을 동시에 검토하며 회계처리와 세무상 설명이 다르고 주총 분쟁도 있음

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 절세 재편안의 회계 설명과 주총 자료가 다른 거래 전제를 사용 |
| 선택 1·재료 | M18·M25·M53: 법인·기간·해석별 모델과 공통 사실을 분리 |
| 변화 2 | 주주 반발로 안건·배당이 바뀌고 과세 해석은 확정되지 않음 |
| 선택 2·재료 | M04·M34·M38: 재편·세후 현금·공시·의안의 교차 영향을 재비교 |
| 첫 도달 상태 | 전략·계산·문서 묶음 가능, 결의·해석·후속 요건은 외부 의존 |
| 첫 판정 | 외부 결과·관측 대기 |
