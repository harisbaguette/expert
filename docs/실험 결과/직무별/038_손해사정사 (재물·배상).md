# 038. 손해사정사 (재물·배상)

유형: 위임형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 외부 결과·관측 대기**

## 초기 복합 사건

공장 화재 후 소실 재고와 기존 불량이 섞이고 휴업기간 중 주문 취소가 화재 때문인지 경기 악화 때문인지 다툼

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 누수 원인 설명과 손상 시점 기록이 어긋남 |
| 선택 1·재료 | M18·M53: 인과·손해액·보상 해석을 별도 유지 |
| 변화 2 | 현장 접근이 제한되고 수리 후 원상 관측 불가 |
| 선택 2·재료 | M07·M39·M47: 남은 원본·대체 근거·미확인 범위 보존 |
| 첫 도달 상태 | 산정 대안 가능, 실제 원인·최종 손해 확정은 외부 의존 |
| 첫 판정 | 외부 결과·관측 대기 |
