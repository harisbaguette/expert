# 050. 번역가 (산업·법률 문서)

유형: 위임형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 범위 내 종결 경로**

## 초기 복합 사건

설비 계약서와 부속 기술사양의 동일 용어가 다르게 쓰이고 원문 수치·면책 문장이 모호함

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 원문 부정어와 정의된 용어가 번역에서 반대로 연결된 것을 발견 |
| 선택 1·재료 | M21·M25·M43: 해당 조항과 참조 전체의 번역을 수정 |
| 변화 2 | 원문 모호성에 대해 발주자가 해석을 덧붙이지 말라고 확정 |
| 선택 2·재료 | M09·M42: 모호성 보존·수치·참조·변경추적을 검수 |
| 첫 도달 상태 | 주어진 원문·지침 아래 번역 납품 경로 있음 |
| 첫 판정 | 범위 내 종결 경로 |
