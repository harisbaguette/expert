# 047. 심리상담사 (아동·청소년)

유형: 위임형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 외부 결과·관측 대기**

## 초기 복합 사건

등교 거부 아동의 행동이 학교와 집에서 다르고 부모가 서로 다른 원인을 주장하며 아이는 상담 자체를 거부함

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 보호자와 아동이 서로 다른 상담 목표·정보 공유를 요청 |
| 선택 1·재료 | M31·M38: 동의·비밀·발달 맥락을 구분 |
| 변화 2 | 학교 관찰과 직접 놀이·상호작용 자료 미확보 |
| 선택 2·재료 | M07·M39: 자료 취득·관계 개입·평가 주체를 연결 |
| 첫 도달 상태 | 상담 설계 가능, 아동 관찰·실제 효과 대기 |
| 첫 판정 | 외부 결과·관측 대기 |
