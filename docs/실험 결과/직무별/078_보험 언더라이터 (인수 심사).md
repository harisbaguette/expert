# 078. 보험 언더라이터 (인수 심사)

유형: 고용형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 목표·조건 조정 필요**

## 초기 복합 사건

대형 사업장의 저렴한 갱신을 영업이 요구하지만 손해이력과 설비 상태가 악화됐고 같은 지역 누적 노출이 큼

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 새 시설 결함이 손해빈도·지역 누적노출을 높임 |
| 선택 1·재료 | M18·M33·M53: 위험 사실·모형·조건별 가격 재검토 |
| 변화 2 | 고객·영업은 무제한 담보와 기존 보험료를 고수 |
| 선택 2·재료 | M34·M38: 인수 가능 조건과 금지 노출을 비교 |
| 첫 도달 상태 | 고정 인수 한도에서 요구 조건 충족 불가 |
| 첫 판정 | 목표·조건 조정 필요 |
