# 006. 변호사 (기업 자문)

유형: 위임형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 외부 결과·관측 대기**

## 초기 복합 사건

이사 선임과 정관 변경을 추진하는 주총에서 위임장 진위·특수관계 거래·대표권이 다투어지고 총수와 회사의 이익이 갈림

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 위임장 중복과 대표권 다툼 발견 |
| 선택 1·재료 | M27·M31·M35: 표결 대상·유효 권한을 재확인하고 의안별 절차 분리 |
| 변화 2 | 회사와 총수가 서로 다른 의사록 기재 요구 |
| 선택 2·재료 | M18·M25·M43: 실제 진행 기록과 각 요청을 대조하고 허위 기재를 배제 |
| 첫 도달 상태 | 진행안·조건별 의사록 준비, 실제 결의·대표권 확인은 외부 의존 |
| 첫 판정 | 외부 결과·관측 대기 |
