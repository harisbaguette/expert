# 148. 웹툰 작가

유형: 운영형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 범위 내 종결 경로**

## 초기 복합 사건

액션 회차의 연출을 바꾸면 배경 3D·인물 위치·말풍선·스크롤 리듬·보조작가 일정이 연쇄 수정됨

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 액션 수정으로 3D 배경·인물 위치·말풍선 충돌 |
| 선택 1·재료 | M04·M25·M09: 콘티·작화·배경·스크롤 변경을 함께 전파 |
| 변화 2 | 모의 모바일 읽기·작화 검수에서 연속성·가독성 통과 |
| 선택 2·재료 | M42·M40: 레이어 원본·회차·에셋 인계 확인 |
| 첫 도달 상태 | 제공된 검수 아래 웹툰 회차 인수 경로 있음 |
| 첫 판정 | 범위 내 종결 경로 |
