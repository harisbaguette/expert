# 150. 인플루언서 (패션·뷰티·라이프)

유형: 운영형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 목표·조건 조정 필요**

## 초기 복합 사건

경쟁 브랜드 계약과 광고 일정이 겹치고 실제 사용 경험과 광고 문구가 달라 팬 신뢰·계약·콘텐츠 정체성이 충돌함

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 경쟁 브랜드 독점 약정 기간이 겹침 |
| 선택 1·재료 | M25·M27: 콘텐츠·행위·기간별 약속과 이해관계 대조 |
| 변화 2 | 두 브랜드 모두 일정·범위 변경을 거부 |
| 선택 2·재료 | M33·M38: 위반 없이 두 계약을 이행할 수 없음을 확인 |
| 첫 도달 상태 | 기존 두 협업의 동시 이행 불가능 |
| 첫 판정 | 목표·조건 조정 필요 |
