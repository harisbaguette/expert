# 138. 견적·적산

유형: 고용형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 범위 내 종결 경로**

## 초기 복합 사건

도면 판본과 시방이 달라 누락·중복 수량이 생기고 공법 변경·물가·현장 조건으로 단가와 공기가 함께 바뀜

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 도면 판본과 시방이 달라 물량 누락·중복 발생 |
| 선택 1·재료 | M07·M25·M53: 객체·범위·공법별 수량·단가 재산정 |
| 변화 2 | 모의 발주자 질의 회신이 적용 판본·공법을 확정 |
| 선택 2·재료 | M42·M40: 내역·산출근거·변경비·공기 영향을 일치시킴 |
| 첫 도달 상태 | 제공된 확정 자료 아래 견적·적산 패키지 종결 경로 있음 |
| 첫 판정 | 범위 내 종결 경로 |
