# 057. 외주 개발 (시스템 구축·SI)

유형: 위임형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 범위 내 종결 경로**

## 초기 복합 사건

기존 ERP의 고객·상품 코드가 서로 달라 이관 후 매출·재고·회계 잔액이 맞지 않고 양 시스템이 동시에 쓰임

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 시험 이관 건수는 같지만 코드 매핑으로 재고·회계 잔액 불일치 |
| 선택 1·재료 | M52·M42: 의미·코드·금액·권한 기준으로 대사·수정 |
| 변화 2 | 모의 cutover에서 쓰기 차단·증분 이관·복구·업무 검수 통과 |
| 선택 2·재료 | M03·M35·M40: 전환 판본·인수·복구 결과 연결 |
| 첫 도달 상태 | 명시한 전환 환경 아래 SI 인수 경로 있음 |
| 첫 판정 | 범위 내 종결 경로 |
