# 102. 풀스택

유형: 고용형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 범위 내 종결 경로**

## 초기 복합 사건

결제·권한·화면을 함께 바꾸는 출시에서 구버전 클라이언트와 데이터 이전이 겹쳐 중복 결제와 정보 노출이 발생할 수 있음

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 구버전 요청이 새 스키마와 충돌하고 중복 결제 재현 |
| 선택 1·재료 | M25·M35: 호환·멱등·전환 단계를 분리 |
| 변화 2 | 모의 통합시험에서 구버전·동시 취소·복구가 수정 후 통과 |
| 선택 2·재료 | M10·M42·M40: 코드·전환·배포·인수 증거 연결 |
| 첫 도달 상태 | 제공된 시험 응답 아래 통합 출시 경로 있음 |
| 첫 판정 | 범위 내 종결 경로 |
