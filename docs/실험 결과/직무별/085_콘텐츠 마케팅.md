# 085. 콘텐츠 마케팅

유형: 고용형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 범위 내 종결 경로**

## 초기 복합 사건

유입이 많은 글들이 같은 초급 주제를 반복하고 상담 고객은 구매에 필요한 비교·도입 질문에 답을 못 얻음

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 유입은 높은데 구매 비교 질문에 답할 자료가 없음 |
| 선택 1·재료 | M18·M34: 고객 여정·반복 주제·필수 비교 정보 재정의 |
| 변화 2 | 영업 확인 자료가 들어와 도입·비용·한계 콘텐츠 작성 가능 |
| 선택 2·재료 | M09·M25·M42: 중복 글 통합·근거·다음 행동 검수 |
| 첫 도달 상태 | 제공된 자료 아래 콘텐츠 재편·납품 경로 있음 |
| 첫 판정 | 범위 내 종결 경로 |
