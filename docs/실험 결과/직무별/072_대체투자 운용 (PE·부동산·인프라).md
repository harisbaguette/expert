# 072. 대체투자 운용 (PE·부동산·인프라)

유형: 고용형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 외부 결과·관측 대기**

## 초기 복합 사건

PE 투자기업의 실적이 꺾여 약정 위반 우려가 생기고 추가출자·대출 연장·자산 매각의 이해관계가 충돌함

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 투자기업 약정 위반과 추가출자 요구가 동시에 발생 |
| 선택 1·재료 | M25·M33·M53: 출자·차환·매각의 연결 손실 재산정 |
| 변화 2 | 대주·주주가 서로 선행 양보를 요구 |
| 선택 2·재료 | M38·M35: 조건부 합의·동시 충족 증거·결렬 대안 구성 |
| 첫 도달 상태 | 구조조정 대안 가능, 당사자 합의·외부 실행은 미정 |
| 첫 판정 | 외부 결과·관측 대기 |
