# 008. 법무사 (등기)

유형: 위임형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 외부 결과·관측 대기**

## 초기 복합 사건

법인의 이사 교체와 본점 이전 등기 접수 직전에 의사록·정관·등기부의 인적사항과 대표권 자료가 불일치함

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 접수 직전 담보 순위가 바뀌고 대리권 증빙 유효성에 의문 |
| 선택 1·재료 | M18·M31: 이전 열람·위임 확인을 무효화하고 최신 원본 조회 |
| 변화 2 | 외부 등기 조회가 중단되어 현재 순위 확인 불가 |
| 선택 2·재료 | M10·M35·M39: 기한·대체 확인 경로를 추적하고 미확인 상태 제출 차단 |
| 첫 도달 상태 | 서류 작성은 가능하지만 권리 확인·접수 완료는 대기 |
| 첫 판정 | 외부 결과·관측 대기 |
