# 026. 공인중개사 (주거)

유형: 위임형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 외부 결과·관측 대기**

## 초기 복합 사건

임대인이 대리인에게 계약을 맡겼는데 선순위 권리와 임차보증금 설명이 다르고 잔금 전 새 담보가 설정됨

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 잔금 직전 새 권리와 점유 변경 신호 도착 |
| 선택 1·재료 | M18·M31·M35: 기존 확인·잔금 선행조건을 재검토 |
| 변화 2 | 매도자가 즉시 송금을 요구하지만 현장 인도 확인 불가 |
| 선택 2·재료 | M33·M39·M40: 대체 확인·일정 조정·미실행 효과를 비교 |
| 첫 도달 상태 | 계약·잔금 계획 가능, 권리·인도 확인 없이 거래 완료 불가 |
| 첫 판정 | 외부 결과·관측 대기 |
