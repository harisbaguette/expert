# 052. 번역가 (영상·게임 현지화)

유형: 위임형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 범위 내 종결 경로**

## 초기 복합 사건

게임의 성별·선택지에 따라 다른 대사가 한 문자열을 공유하고 화면 폭·음성 길이가 언어별로 달라 오류가 생김

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 공유 문자열이 다른 성별·장면에서 어긋나고 버튼 폭 초과 |
| 선택 1·재료 | M07·M25: 키·분기·변수와 장면을 구분해 번역 분리 |
| 변화 2 | 모의 빌드가 분기·자막 싱크·레이아웃 수정 통과를 반환 |
| 선택 2·재료 | M10·M42: 실제 사용 조건별 검수 결과와 번역판본 연결 |
| 첫 도달 상태 | 주어진 빌드 응답 아래 현지화 인수 경로 있음 |
| 첫 판정 | 범위 내 종결 경로 |
