# 062. 인사 (평가·보상)

유형: 고용형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 범위 내 종결 경로**

## 초기 복합 사건

영업 실적이 반품 전 매출로 평가돼 성과급이 부풀고 지원부서는 성과가 인정되지 않아 이의가 제기됨

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 반품과 지원부서 공동 기여를 반영하면 성과급 순위가 바뀜 |
| 선택 1·재료 | M52·M53: 성과 귀속·산정 규칙·소급 영향 분리 |
| 변화 2 | 권한 있는 기구가 수정 규칙·이의절차를 확정 |
| 선택 2·재료 | M25·M42: 대상자별 재계산·설명·이의 기록 연결 |
| 첫 도달 상태 | 주어진 확정 규칙 아래 평가·보상 정정 경로 있음 |
| 첫 판정 | 범위 내 종결 경로 |
