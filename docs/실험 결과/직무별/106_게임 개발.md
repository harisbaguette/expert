# 106. 게임 개발

유형: 고용형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 범위 내 종결 경로**

## 초기 복합 사건

네트워크 지연 중 아이템 거래와 전투 보상이 겹쳐 복제가 생기고 패치가 기존 저장과 저사양 성능을 깨뜨림

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 지연 재전송으로 아이템 복제와 저장 이전 오류 발견 |
| 선택 1·재료 | M25·M35: 권위 상태·거래·저장 형식 수정 |
| 변화 2 | 모의 지연·재접속·구세이브·실플레이 검수 통과 |
| 선택 2·재료 | M54·M42: 경제·성능·호환 영향과 패치 검증 |
| 첫 도달 상태 | 제공된 게임 시험 아래 패치 인수 경로 있음 |
| 첫 판정 | 범위 내 종결 경로 |
