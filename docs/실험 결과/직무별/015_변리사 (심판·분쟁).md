# 015. 변리사 (심판·분쟁)

유형: 위임형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 외부 결과·관측 대기**

## 초기 복합 사건

상대 제품의 비공개 공정 때문에 구성요소 충족이 불명확한데 소송·무효심판·라이선스 협상이 동시에 진행됨

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 분해 실측이 도면과 달라 기존 구성요소 대응표가 뒤집힘 |
| 선택 1·재료 | M07·M18·M25: 추정 구성을 실측과 분리하고 주장·증거표 갱신 |
| 변화 2 | 상대가 일부 실시품 제공을 거절하고 합의 범위 확대 요구 |
| 선택 2·재료 | M34·M38·M43: 입증 한계와 합의 파급을 반영해 전략 분기 |
| 첫 도달 상태 | 기술 분석·심판 자료 가능, 증거 접근·판정·합의는 미정 |
| 첫 판정 | 외부 결과·관측 대기 |
