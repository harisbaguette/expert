# 162. 오픈소스 메인테이너

유형: 운영형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 범위 내 종결 경로**

## 초기 복합 사건

핵심 의존 취약점과 호환성 파괴가 겹치고 유지보수자는 부족한데 이용 조직은 빠른 패치를 요구함

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 취약 의존 패치가 기존 API 호환을 깨뜨림 |
| 선택 1·재료 | M25·M35·M43: 보안 영향·지원 버전·비공개 수정·이전 경로 분리 |
| 변화 2 | 모의 유지버전·신규버전 회귀·패키지 검증 통과 |
| 선택 2·재료 | M31·M42·M40: 공개 일정·릴리스·권고·이전 문서 인계 |
| 첫 도달 상태 | 제공된 검증 아래 패치·릴리스 준비 경로 있음 |
| 첫 판정 | 범위 내 종결 경로 |
