# 132. 재고·자재

유형: 고용형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 범위 내 종결 경로**

## 초기 복합 사건

장부상 재고는 충분하지만 불량 격리·위탁·예약·유통기한·로트 위치 때문에 실제 생산에 쓸 수 없는 자재가 많음

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 장부 재고에 불량·예약·위탁·만료분이 혼재 |
| 선택 1·재료 | M25·M52: 소유·수량·위치·가용 상태로 분해 |
| 변화 2 | 모의 실사와 수불 대사가 가용 재고를 확인 |
| 선택 2·재료 | M53·M42: 보충·이동·처분·생산 인계 갱신 |
| 첫 도달 상태 | 제공된 실사 아래 재고 정정·운영 경로 있음 |
| 첫 판정 | 범위 내 종결 경로 |
