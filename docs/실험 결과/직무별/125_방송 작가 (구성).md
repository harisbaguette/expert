# 125. 방송 작가 (구성)

유형: 고용형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 범위 내 종결 경로**

## 초기 복합 사건

인터뷰 내용이 기획 가설을 뒤집고 방송 분량은 줄었는데 재미를 위해 발언 맥락을 자를 압력이 생김

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 새 인터뷰가 기존 원고의 인과 설명을 뒤집음 |
| 선택 1·재료 | M18·M22: 이야기 중심·질문·내레이션 수정 |
| 변화 2 | 분량 축소 후에도 모의 편집 검수에서 발언 맥락 보존 확인 |
| 선택 2·재료 | M09·M42: 원본 타임코드·인용·대본 길이 대조 |
| 첫 도달 상태 | 제공된 원본·편성 조건 아래 방송 구성안 종결 경로 있음 |
| 첫 판정 | 범위 내 종결 경로 |
