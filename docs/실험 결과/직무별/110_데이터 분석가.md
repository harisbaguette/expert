# 110. 데이터 분석가

유형: 고용형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 범위 내 종결 경로**

## 초기 복합 사건

매출 감소 원인이 가격 변경처럼 보이나 추적 누락·채널구성·환불 시점이 바뀌어 집계마다 반대 결론이 나옴

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 매출 하락 구간에서 계측 누락과 환불 시점 변경 확인 |
| 선택 1·재료 | M18·M52: 지표 분모·원천 대사·시간 기준 정정 |
| 변화 2 | 모의 재분석에서 가격 효과와 채널 효과의 일부는 구별 불가 |
| 선택 2·재료 | M53·M54: 확정 가능한 분해와 추가 실험 가설만 제시 |
| 첫 도달 상태 | 불확실성을 포함한 분석 보고서는 종결 가능; 단일 원인 확정은 제외 |
| 첫 판정 | 범위 내 종결 경로 |
