# 042. 대출상담사 (주택·개인)

유형: 위임형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 외부 결과·관측 대기**

## 초기 복합 사건

이직 직후 차주가 잔금대출을 신청하지만 소득 인정자료와 기존 대출 만기·담보평가가 맞지 않음

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 잔금 전 신용·고용 정보가 바뀌어 기존 한도 조회 무효 |
| 선택 1·재료 | M13·M25·M53: 대출 조건·상환·잔금 차액 재비교 |
| 변화 2 | 은행이 추가 서류와 재심사를 요구 |
| 선택 2·재료 | M35·M39: 보완·기한·대체 금융 가능 범위 연결 |
| 첫 도달 상태 | 신청·비교 자료 가능, 승인·실행 결과 대기 |
| 첫 판정 | 외부 결과·관측 대기 |
