# 032. 건축사 (대형·공공 건축)

유형: 위임형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 목표·조건 조정 필요**

## 초기 복합 사건

병원 증축 설계에서 피난동선·덕트·보·장비 반입공간이 충돌하고 발주처가 운영 중 공사를 요구함

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 구조·설비·피난 변경이 같은 공간을 요구 |
| 선택 1·재료 | M04·M25·M53: 분야별 제약을 공동 모델에서 대조 |
| 변화 2 | 건물 외형·정원·예산·기간은 모두 고정, 모의 해석에서 가능한 배치 없음 |
| 선택 2·재료 | M34·M35·M43: 각자의 부분 합격 대신 통합 불가능성을 보고 |
| 첫 도달 상태 | 설계 요구 중 최소 하나의 조정 필요 |
| 첫 판정 | 목표·조건 조정 필요 |
