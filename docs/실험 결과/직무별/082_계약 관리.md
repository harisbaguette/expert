# 082. 계약 관리

유형: 고용형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 범위 내 종결 경로**

## 초기 복합 사건

고객 계약의 SLA와 공급사 보상 한도가 다르고 자동갱신·가격인상·데이터 반환 조건이 다른 날짜에 발동함

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 고객 갱신·공급사 종료·가격 변경이 서로 다른 날 발동 |
| 선택 1·재료 | M25·M35·M53: 약속·서비스·비용의 시간축 통합 |
| 변화 2 | 공급사가 연결 기간 연장에 동의하고 권한자도 조건 수락 |
| 선택 2·재료 | M31·M40·M42: 변경문·일정·서비스·납품 의무 대조 |
| 첫 도달 상태 | 제공된 합의 아래 계약 이행관리 경로 있음 |
| 첫 판정 | 범위 내 종결 경로 |
