# 002. 변호사 (형사 변호)

유형: 위임형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 외부 결과·관측 대기**

## 초기 복합 사건

총수가 여러 거래로 기소되고 직원 진술은 바뀌는데, 회사 민사소송의 거래 설명과 개인의 방어 논리가 충돌함

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 직원의 번복 진술과 결재 원본이 총수·회사 주장에 서로 다르게 작용 |
| 선택 1·재료 | M18·M25·M27: 공소사실별 근거를 갱신하고 의뢰인·비밀·기존 서면 영향을 분리 |
| 변화 2 | 긴급 구속 관련 일정과 민사 제출 일정이 겹침 |
| 선택 2·재료 | M04·M35·M43: 형사·민사 전문 판단을 교차 검토하고 기한별 제출·출석 계획 재배정 |
| 첫 도달 상태 | 방어 전략·신문·서면 경로는 있으나 법원 판단·전문 수행은 외부 의존 |
| 첫 판정 | 외부 결과·관측 대기 |
