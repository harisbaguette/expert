# 083. 브랜드 마케팅

유형: 고용형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 범위 내 종결 경로**

## 초기 복합 사건

리뉴얼 캠페인의 신규 이미지가 기존 고객의 신뢰 이유를 약화시키고 판매점은 제품 설명과 프로모션이 다르다고 반발함

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 신규 시안이 기존 고객의 신뢰 요소를 제거 |
| 선택 1·재료 | M22·M23·M54: 세그먼트별 인식·제품 설명·접점 시험 |
| 변화 2 | 모의 반응에서 기존 자산을 일부 유지한 안이 목표에 적합 |
| 선택 2·재료 | M09·M40·M51: 브랜드·판매점 자료를 정렬해 출시안 선택 |
| 첫 도달 상태 | 제공된 반응 아래 캠페인·접점 인계 경로 있음 |
| 첫 판정 | 범위 내 종결 경로 |
