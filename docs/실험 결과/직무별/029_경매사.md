# 029. 경매사

유형: 위임형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 목표·조건 조정 필요**

## 초기 복합 사건

낮은 감정가의 경매 물건에 선순위 임차인 주장과 점유 불일치가 있고 대출은 낙찰 후 재심사 예정임

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 점유자 주장과 매각 자료가 다르고 수리비 증가 |
| 선택 1·재료 | M25·M53: 권리·점유·총취득비를 재구성 |
| 변화 2 | 의뢰인은 경쟁 입찰가 이상 지불과 목표 수익률 유지를 동시에 고수 |
| 선택 2·재료 | M33·M34: 고정 수입·비용에서 허용 상한과 요구 입찰가 충돌 검출 |
| 첫 도달 상태 | 해당 가격에서 원래 수익 목표 불가, 입찰가·목표·참여 여부 조정 필요 |
| 첫 판정 | 목표·조건 조정 필요 |
