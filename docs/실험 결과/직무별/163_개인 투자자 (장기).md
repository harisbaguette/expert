# 163. 개인 투자자 (장기)

유형: 운영형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 목표·조건 조정 필요**

## 초기 복합 사건

사업 가설이 흔들리는데 가격은 싸 보이고 개인의 주택자금 필요·집중 투자·세금·유동성이 매도 판단과 충돌함

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 투자 가설이 반증되고 주택자금 지급일이 앞당겨짐 |
| 선택 1·재료 | M18·M33·M53: 가치 가정·유동성·집중 위험 재평가 |
| 변화 2 | 사용자는 손실 없이 즉시 현금화와 기존 상승 여력 유지를 요구 |
| 선택 2·재료 | M34·M38: 현재 가격·유동성에서 불가능한 동시 조건 제시 |
| 첫 도달 상태 | 원래 투자·현금 목표 조정 필요 |
| 첫 판정 | 목표·조건 조정 필요 |
