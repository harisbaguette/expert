# 014. 변리사 (상표·디자인)

유형: 위임형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 외부 결과·관측 대기**

## 초기 복합 사건

신제품 출시 직전 유사 이름의 선등록과 기존 디자인 공개가 발견돼 이름·상품범위·출시 일정을 같이 결정해야 함

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 유사 표장이 같은 고객군에서 사용 중이라는 자료 도착 |
| 선택 1·재료 | M07·M14·M34: 도형 유사성뿐 아니라 사용·범위·출시 대안 검토 |
| 변화 2 | 출시팀이 이름 변경을 거부하고 심사 일정은 확정 불가 |
| 선택 2·재료 | M25·M38: 자산 변경 비용과 권리 위험·대체 출시안을 함께 제시 |
| 첫 도달 상태 | 출원·브랜드 대안 가능, 권리 확보·분쟁 종결은 외부 의존 |
| 첫 판정 | 외부 결과·관측 대기 |
