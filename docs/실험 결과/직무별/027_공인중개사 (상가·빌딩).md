# 027. 공인중개사 (상가·빌딩)

유형: 위임형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 외부 결과·관측 대기**

## 초기 복합 사건

매도자가 만실 수익률을 제시했지만 무상임대 기간·체납·만기집중이 있고 임차인이 시설 투자 보상을 요구함

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 임대료 장부 중 일부가 실제 미수이며 수선비도 누락 |
| 선택 1·재료 | M52·M53: 순수익·보증금·현금수지를 재작성 |
| 변화 2 | 임차인 확인과 현장 수선 견적이 서로 다름 |
| 선택 2·재료 | M18·M38·M39: 차이 검증·임대조건·인도 협의 연결 |
| 첫 도달 상태 | 가격·조건 대안 가능, 실사·당사자 합의는 미정 |
| 첫 판정 | 외부 결과·관측 대기 |
