# 017. 세무사 (상속·증여·가업 승계)

유형: 위임형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 목표·조건 조정 필요**

## 초기 복합 사건

가족기업 승계에서 비사업 자산·과거 증여·후계자 경영 참여·납부 현금이 쟁점인데 가족은 지분을 균등 분할하려 함

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 절세안의 사후조건과 사업 투자에 필요한 현금이 충돌 |
| 선택 1·재료 | M25·M53: 세액만 비교하던 안을 다기간 현금·유지조건으로 전환 |
| 변화 2 | 가족은 동일 지배력·동일 현금 지급을 모두 고수하고 외부 자금 없음 |
| 선택 2·재료 | M34·M38: 제약을 고정한 채 가능한 대안이 없는지 확인 |
| 첫 도달 상태 | 세금 최소·지배력 유지·즉시 지급의 동시 목표 조정 필요 |
| 첫 판정 | 목표·조건 조정 필요 |
