# 059. 경영기획

유형: 고용형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 목표·조건 조정 필요**

## 초기 복합 사건

사업부들은 매출 확대를 요청하지만 모두 같은 개발팀·설비에 의존하고 매출 증가에도 전사 현금은 악화됨

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 두 사업부 투자안이 동일 설비와 개발자 전 시간을 각각 전제 |
| 선택 1·재료 | M25·M33·M53: 전사 자원·현금 기준으로 통합 계산 |
| 변화 2 | 경영진이 두 출시일·투자규모·차입 한도를 모두 고정 |
| 선택 2·재료 | M34·M35: 자원 중복과 현금 부족 시점을 제시 |
| 첫 도달 상태 | 개별안이 좋아도 전사 동시 실행 불가능, 우선순위 조정 필요 |
| 첫 판정 | 목표·조건 조정 필요 |
