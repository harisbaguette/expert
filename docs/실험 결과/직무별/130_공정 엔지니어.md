# 130. 공정 엔지니어

유형: 고용형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 외부 결과·관측 대기**

## 초기 복합 사건

속도를 높여 평균 생산량은 늘었지만 원재료 편차·설비 마모와 상호작용해 장기 수율과 다음 공정 품질이 악화됨

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 속도 개선 뒤 후공정 불량·설비 마모가 증가 |
| 선택 1·재료 | M18·M53: 평균 산출량과 장기 수율·상호작용을 분리 |
| 변화 2 | 모의 파일럿은 수정 조건 통과하나 장기 배치 관측이 아직 없음 |
| 선택 2·재료 | M54·M51: 확대 조건·추적 기간·중단 신호 설정 |
| 첫 도달 상태 | 공정 개선 후보 가능, 지속 양산 효과는 관측 대기 |
| 첫 판정 | 외부 결과·관측 대기 |
