# 165. 엔젤 투자자

유형: 운영형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 외부 결과·관측 대기**

## 초기 복합 사건

창업팀의 지표가 계약·입금과 다르고 지분·우선권·후속 희석·공동창업자 갈등 때문에 성장성만으로 투자 여부를 정할 수 없음

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 고객 지표가 실제 입금과 다르고 우선권·희석 조건 추가 확인 |
| 선택 1·재료 | M18·M25·M53: 지표·캡테이블·후속자금·회수 가정 재작성 |
| 변화 2 | 창업팀이 핵심 계약·지식재산 권리 원본 제공 보류 |
| 선택 2·재료 | M34·M38·M39: 투자 보류·조건부 실사·미확인 범위 제시 |
| 첫 도달 상태 | 투자 메모·협상안 가능, 실사 완료·거래 판단은 외부 의존 |
| 첫 판정 | 외부 결과·관측 대기 |
