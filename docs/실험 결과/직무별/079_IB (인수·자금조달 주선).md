# 079. IB (인수·자금조달 주선)

유형: 고용형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 목표·조건 조정 필요**

## 초기 복합 사건

조달을 추진하던 회사에 실사상 회계 쟁점이 발견되고 투자자 수요가 약해져 가격·물량·조건을 바꿔야 함

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 회계 실사 쟁점으로 투자자 수요와 가격이 낮아짐 |
| 선택 1·재료 | M18·M53: 공시·가치·조달금액·조건 수정 |
| 변화 2 | 발행사는 가격 하한·전액 조달·일정을 모두 고수 |
| 선택 2·재료 | M34·M38: 주어진 수요 곡선에서 조달 미달을 확인 |
| 첫 도달 상태 | 원래 조달 조건 동시 달성 불가 |
| 첫 판정 | 목표·조건 조정 필요 |
