# 087. 홍보

유형: 고용형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 외부 결과·관측 대기**

## 초기 복합 사건

제품 사고 제보가 확산되는데 법무·품질·영업의 사실 설명이 다르고 기자는 즉시 답변을 요구함

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 새 사고 제보가 최초 회사 입장과 충돌 |
| 선택 1·재료 | M18·M38: 확인 사실·미확인·정정할 표현 구분 |
| 변화 2 | 조사 결과는 늦지만 기자는 즉답 요구 |
| 선택 2·재료 | M08·M31·M35: 확인 가능한 조치·대기 내용·정정 계획만 공개 |
| 첫 도달 상태 | 응대·정정 경로 가능, 사고 사실·외부 반응은 계속 추적 |
| 첫 판정 | 외부 결과·관측 대기 |
