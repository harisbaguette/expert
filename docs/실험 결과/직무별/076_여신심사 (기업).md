# 076. 여신심사 (기업)

유형: 고용형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 목표·조건 조정 필요**

## 초기 복합 사건

기업의 이익은 흑자인데 매출채권과 재고가 쌓이고 계열사 보증·차환 만기가 숨은 자금위험을 만듦

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 매출채권 회수가 늦고 계열 보증 지급이 현실화 |
| 선택 1·재료 | M25·M33·M53: 유동성·담보·차환 시나리오 재산정 |
| 변화 2 | 추가 담보·출자 없이 기존 조건 대출 유지 요구 |
| 선택 2·재료 | M34·M35: 위험 한도와 조건 충돌 표시 |
| 첫 도달 상태 | 주어진 위험 한도에서 기존 대출 조건 유지 불가 |
| 첫 판정 | 목표·조건 조정 필요 |
