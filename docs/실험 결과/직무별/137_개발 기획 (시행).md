# 137. 개발 기획 (시행)

유형: 고용형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 목표·조건 조정 필요**

## 초기 복합 사건

토지 일부 미확보·민원·인허가 조건·공사비 상승이 겹쳐 분양가를 올려도 금융 약정과 착공 조건을 충족하지 못함

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 일부 토지 미확보와 인허가 조건 추가로 착공 지연 |
| 선택 1·재료 | M25·M33·M53: 지연·공사비·차환·분양 현금 통합 |
| 변화 2 | 토지 협상·추가 출자·공기 조정을 모두 금지 |
| 선택 2·재료 | M34·M38: 선행조건 미충족과 현금 한계 제시 |
| 첫 도달 상태 | 기존 일정·규모·자금 조건의 사업 진행 불가 |
| 첫 판정 | 목표·조건 조정 필요 |
