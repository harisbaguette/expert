# 140. 유튜버 (예능·엔터)

유형: 운영형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 외부 결과·관측 대기**

## 초기 복합 사건

반복 포맷의 반응이 떨어지고 출연자 갈등·예상 밖 촬영 결과·스폰서 요구 때문에 웃음·관계·회차 연결이 흔들림

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 기존 포맷 반응 하락과 출연자 갈등 심화 |
| 선택 1·재료 | M22·M38: 웃음 구조·역할·관계 소진을 분리 |
| 변화 2 | 새 회차안은 준비되나 출연 동의·실제 반응 미확보 |
| 선택 2·재료 | M35·M39·M51: 촬영·피드백·시리즈 전환 조건 관리 |
| 첫 도달 상태 | 기획·제작 계획 가능, 출연·시청 반응은 외부 의존 |
| 첫 판정 | 외부 결과·관측 대기 |
