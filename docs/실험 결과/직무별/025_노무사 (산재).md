# 025. 노무사 (산재)

유형: 위임형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 외부 결과·관측 대기**

## 초기 복합 사건

장기간 여러 공장에서 일한 근로자가 질병을 진단받았지만 작업환경 측정과 과거 업무 기록이 부족하고 회사가 관련성을 부인함

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 노출 이력과 의학 소견이 어긋나 직업성 가설이 갈림 |
| 선택 1·재료 | M18·M25: 작업·시간·의학 의견을 분리하고 추가 근거 지정 |
| 변화 2 | 사업주가 현장자료 제출을 거부하고 추가 의료평가 지연 |
| 선택 2·재료 | M35·M39: 취득·보완 경로·기한·미확인 인과를 유지 |
| 첫 도달 상태 | 산재 자료·신청 경로 가능, 인과 판단·기관 결과는 대기 |
| 첫 판정 | 외부 결과·관측 대기 |
