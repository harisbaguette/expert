# 152. 커뮤니티 운영자

유형: 운영형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 외부 결과·관측 대기**

## 초기 복합 사건

오래된 핵심 회원과 신규 회원이 충돌하고 신고·조작 계정·운영진 이해관계 때문에 같은 규칙 적용도 불공정하게 느껴짐

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 신고 대상 발언의 앞뒤 맥락과 운영진 이해관계가 추가 확인 |
| 선택 1·재료 | M18·M31·M38: 맥락·반복행동·결정권·이의절차 재검토 |
| 변화 2 | 일부 회원은 제재를 수용하나 장기 신뢰·참여는 미관측 |
| 선택 2·재료 | M25·M51: 중재·제재·이의·후속 반응을 연결 |
| 첫 도달 상태 | 운영 결정 경로 있음, 커뮤니티 신뢰 회복은 추적 필요 |
| 첫 판정 | 외부 결과·관측 대기 |
