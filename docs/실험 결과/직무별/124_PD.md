# 124. PD

유형: 고용형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 외부 결과·관측 대기**

## 초기 복합 사건

주요 출연자가 촬영 직전 빠지고 취재 사실이 뒤집혀 예산·일정·방송 약속·편집 방향을 동시에 바꿔야 함

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 핵심 출연자 이탈과 취재 사실 변경이 동시에 발생 |
| 선택 1·재료 | M34·M35: 회차 목적·촬영·예산·권리 재구성 |
| 변화 2 | 대체 출연·편성 조건 합의는 아직 없음 |
| 선택 2·재료 | M38·M39: 제작 대안·외부 수행·결정 기한을 연결 |
| 첫 도달 상태 | 제작안은 가능, 출연·촬영·편성 결과는 외부 의존 |
| 첫 판정 | 외부 결과·관측 대기 |
