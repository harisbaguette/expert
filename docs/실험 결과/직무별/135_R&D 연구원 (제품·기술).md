# 135. R&D 연구원 (제품·기술)

유형: 고용형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 외부 결과·관측 대기**

## 초기 복합 사건

연구실 성능은 좋지만 측정 오차·재현성·재료 배치·양산 공정 차이로 실제 제품 성능과 원가를 만족하지 못함

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 성능이 측정오차인지 기술 효과인지 확인할 실험이 가설 채택 뒤에만 허용됨 |
| 선택 1·재료 | M18·M35: 가설 채택의 근거와 실험 활성 조건이 서로 의존 |
| 변화 2 | 단순 조립기는 가설 불명으로 실험을 대기 |
| 선택 2·재료 | M53·M54·M50: 탐색·측정용 시험을 채택·양산 결정과 분리해야 함 |
| 첫 도달 상태 | 조건 판정을 위한 탐색 의존 명시 강화 필요 |
| 첫 판정 | 조건 명세 강화 필요 |

## 명세 보완 후 재전개

가정 응답: 허용된 탐색 실험을 먼저 수행했지만 결과가 불명. 예산·정보 가치에 따른 추가 실험 또는 보류를 선택하며 가설 채택·양산으로 넘기지 않음.
