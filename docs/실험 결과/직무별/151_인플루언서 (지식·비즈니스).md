# 151. 인플루언서 (지식·비즈니스)

유형: 운영형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 범위 내 종결 경로**

## 초기 복합 사건

투자한 회사나 유료 자문 고객을 평가하면서 일반 독자가 해설을 개인별 조언으로 받아들여 신뢰·이해관계·상품 판매가 얽힘

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 본인 투자기업에 대한 해설과 유료 상품 판매가 충돌 |
| 선택 1·재료 | M18·M27·M38: 사실·견해·이해관계·대상 범위를 분리 |
| 변화 2 | 모의 독자 질문에서 개인별 조언으로 오해한 부분 확인 |
| 선택 2·재료 | M09·M42·M46: 주장·예시·표시·질의응답 수정 |
| 첫 도달 상태 | 주어진 근거·반응 아래 콘텐츠 경계 정리 경로 있음 |
| 첫 판정 | 범위 내 종결 경로 |
