# 075. 여신심사 (개인)

유형: 고용형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 범위 내 종결 경로**

## 초기 복합 사건

대출자의 소득은 충분해 보이나 최근 신규채무와 계좌 거래가 신고소득과 맞지 않고 자동모형은 승인으로 나옴

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 최근 대출이 누락돼 상환부담이 자동모형 입력과 다름 |
| 선택 1·재료 | M18·M52·M53: 검증된 소득·채무로 재계산 |
| 변화 2 | 보완된 증빙과 가상 심사 규칙이 한도 축소를 지시 |
| 선택 2·재료 | M31·M42: 허용 판단 범위·근거·조건을 대조 |
| 첫 도달 상태 | 고정 심사 규칙 아래 조건부 심사의견 종결 경로 있음 |
| 첫 판정 | 범위 내 종결 경로 |
