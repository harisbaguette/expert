# 114. IT 운영

유형: 고용형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 범위 내 종결 경로**

## 초기 복합 사건

조직개편과 퇴사자 정리가 겹쳐 업무용 공유계정·라이선스·장비가 남고 급한 복구 요청이 권한 검증을 우회하게 만듦

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 퇴사자 계정이 공유 자동화와 라이선스에 남음 |
| 선택 1·재료 | M25·M31: 실제 접근·서비스 의존과 회수 범위 확인 |
| 변화 2 | 모의 권한 회수·담당 이전·사용자 과업 확인 통과 |
| 선택 2·재료 | M10·M42·M47: 접근 잔존·업무 복구·비용 대사 |
| 첫 도달 상태 | 제공된 시스템 확인 아래 IT 운영 처리 경로 있음 |
| 첫 판정 | 범위 내 종결 경로 |
