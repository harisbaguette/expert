# 018. 세무사 (조사·불복)

유형: 위임형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 외부 결과·관측 대기**

## 초기 복합 사건

조사팀이 가공경비를 의심하지만 장부에는 거래가 있고 공급자는 폐업해 거래 실질을 설명할 자료가 부족함

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 원장과 은행 거래가 달라 거래 실질에 두 설명이 존재 |
| 선택 1·재료 | M18·M34: 설명별 지지·반대 근거와 불리한 해석을 유지 |
| 변화 2 | 조사팀이 새 기간 자료를 요구하며 해석을 확정하지 않음 |
| 선택 2·재료 | M35·M38·M47: 제출 범위·시점·설명의 일관성과 후속 불복 경로 관리 |
| 첫 도달 상태 | 대응안·증거 묶음 가능, 해석 다툼·기관 결과는 미정 |
| 첫 판정 | 외부 결과·관측 대기 |
