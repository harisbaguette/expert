# 159. 인디게임 개발자

유형: 운영형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 목표·조건 조정 필요**

## 초기 복합 사건

작은 팀이 출시를 서두르는데 게임은 실행돼도 초반 재미·저사양 성능·세이브·상점 약속·지원 여력이 동시에 부족함

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 출시 빌드는 실행되지만 초반 이탈·구세이브 손상 발견 |
| 선택 1·재료 | M22·M25·M54: 핵심 재미·온보딩·저장 복구를 우선 수정 |
| 변화 2 | 개발자가 출시일·모든 콘텐츠·무결함을 고수하고 남은 시간 부족 |
| 선택 2·재료 | M33·M35: 필수 수정·범위·일정 선택지 제시 |
| 첫 도달 상태 | 원래 출시 범위·기한·품질 동시 달성 불가 |
| 첫 판정 | 목표·조건 조정 필요 |
