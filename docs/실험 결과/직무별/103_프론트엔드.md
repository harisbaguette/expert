# 103. 프론트엔드

유형: 고용형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 범위 내 종결 경로**

## 초기 복합 사건

느린 망과 보조기술에서 결제 폼 오류가 숨고 재시도 때 중복 요청되며 다국어 문장이 레이아웃을 깨뜨림

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 느린 망·스크린리더에서 오류 알림 누락과 중복 제출 |
| 선택 1·재료 | M25·M42: 상태·포커스·요청 제어·텍스트 확장 수정 |
| 변화 2 | 모의 브라우저 과업시험이 중단·재시도·오류 복구 통과 |
| 선택 2·재료 | M54·M40: 과업과 기기·환경별 인수 기록 |
| 첫 도달 상태 | 제공된 과업시험 아래 프론트엔드 인수 경로 있음 |
| 첫 판정 | 범위 내 종결 경로 |
