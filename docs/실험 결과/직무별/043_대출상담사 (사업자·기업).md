# 043. 대출상담사 (사업자·기업)

유형: 위임형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 외부 결과·관측 대기**

## 초기 복합 사건

수주한 기업의 운전자금이 부족한데 매출채권 담보·기존 보증·시설대출 약정이 서로 제한을 만듦

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 계열 보증의 지급 가능성과 담보 선순위가 추가 확인 |
| 선택 1·재료 | M25·M33·M53: 가용 담보·노출·차환 현금 재산정 |
| 변화 2 | 대주가 조건부 승인을 내지만 보증기관 확인 미도착 |
| 선택 2·재료 | M31·M35: 조건부 승인을 실행 가능 상태와 구분 |
| 첫 도달 상태 | 조달 전략·서류 가능, 보증·대주 실행 의존 |
| 첫 판정 | 외부 결과·관측 대기 |
