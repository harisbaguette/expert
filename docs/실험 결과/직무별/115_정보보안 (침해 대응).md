# 115. 정보보안 (침해 대응)

유형: 고용형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 외부 결과·관측 대기**

## 초기 복합 사건

탈취 계정이 클라우드·백업에 접근하고 로그 일부가 지워져 즉시 차단하면 증거·업무 연속성을 함께 잃을 수 있음

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 탈취 계정이 백업까지 접근했고 로그 일부가 없음 |
| 선택 1·재료 | M18·M35: 증거 보존·확산·업무 연속성으로 봉쇄 순서 선택 |
| 변화 2 | 확인된 경로는 봉쇄됐지만 초기 침입·유출 범위는 불명 |
| 선택 2·재료 | M39·M43·M51: 독립 조사·복구·후속 감시 연결 |
| 첫 도달 상태 | 봉쇄·복구 경로 가능, 근절·피해 범위 확정은 추가 관측 필요 |
| 첫 판정 | 외부 결과·관측 대기 |
