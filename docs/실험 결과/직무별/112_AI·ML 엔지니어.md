# 112. AI·ML 엔지니어

유형: 고용형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 범위 내 종결 경로**

## 초기 복합 사건

고객 문서 RAG가 그럴듯한 답을 내지만 권한 변경·검색 누락·지시문 오염·모델 업데이트가 겹쳐 다른 고객 자료와 오답을 반환함

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 고급 검색은 근거 부족 때만 켜지는데 부족 판정에 고급 검색이 필요 |
| 선택 1·재료 | M18·M35: 단순 무결과와 확인 불가를 구별 |
| 변화 2 | 생성기가 불명 조건을 대기로만 처리해 검색 보완을 시작하지 못함 |
| 선택 2·재료 | M19·M50: 조건 확인용 근거 취득 경로를 먼저 활성화해야 함 |
| 첫 도달 상태 | 조건부 기능의 판정 의존 명시 강화 필요 |
| 첫 판정 | 조건 명세 강화 필요 |

## 명세 보완 후 재전개

가정 응답: 추가 검색이 허용돼 필요한 근거를 확보하고 고객 경계·근거 검수가 통과. 검색 보완→근거 있는 답변 경로로 전개.
