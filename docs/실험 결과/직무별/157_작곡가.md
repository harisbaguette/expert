# 157. 작곡가

유형: 운영형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 범위 내 종결 경로**

## 초기 복합 사건

광고 길이·가창 음역·영상 타이밍이 바뀌고 공동작업자의 샘플·지분·원본이 정리되지 않아 수정·발매가 막힘

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 영상 길이·가창 음역 변경과 샘플 권리 문제 발견 |
| 선택 1·재료 | M22·M25·M55: 구조·조성·편성·자산 대안 재설계 |
| 변화 2 | 대체 자산 권리 확인·모의 청취·세션 재열기 통과 |
| 선택 2·재료 | M09·M42·M40: 악보·MIDI·세션·스템·크레딧 검수 |
| 첫 도달 상태 | 제공된 권리·청취 응답 아래 음악 납품 경로 있음 |
| 첫 판정 | 범위 내 종결 경로 |
