# 164. 개인 투자자 (단기 매매)

유형: 운영형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 범위 내 종결 경로**

## 초기 복합 사건

급변장에서 호가 공백·부분 체결·증거금 변화·연결 장애가 겹쳐 백테스트와 다른 손실·미결 주문이 생김

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 호가 공백·부분 체결·증거금 변화와 연결 장애 동시 발생 |
| 선택 1·재료 | M08·M10·M25: 주문·체결·노출을 분리하고 재전송 방지 |
| 변화 2 | 외부 조회가 미결 주문과 잔고를 확정, 위임 한도 안 축소 가능 |
| 선택 2·재료 | M33·M42: 실제 체결·수수료·잔여 노출로 정산 |
| 첫 도달 상태 | 제공된 시장 응답 아래 위험 축소·대사 경로 있음; 수익 보장 아님 |
| 첫 판정 | 범위 내 종결 경로 |
