# 013. 변리사 (특허)

유형: 위임형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 외부 결과·관측 대기**

## 초기 복합 사건

공개 예정인 제품의 차별점이 심사관이 찾은 선행기술과 겹치고, 넓은 청구항을 지키려다 명세서에 없는 사항을 추가할 위험이 생김

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 선행문헌이 핵심 구성 일부를 공개한 것으로 확인 |
| 선택 1·재료 | M19·M25·M34: 청구항별 근거·차별 구성·기재 범위를 재정렬 |
| 변화 2 | 발명자가 미기재 구성을 추가해 달라고 요청 |
| 선택 2·재료 | M18·M35·M43: 원출원 근거와 변경안을 대조하고 보정·별도 검토 경로 분리 |
| 첫 도달 상태 | 명세·청구·보정 대안 준비, 심사 판단과 발명 사실 확인 대기 |
| 첫 판정 | 외부 결과·관측 대기 |
