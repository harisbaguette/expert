# 048. 심리상담사 (부부·가족)

유형: 위임형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 외부 결과·관측 대기**

## 초기 복합 사건

부부가 갈등의 책임을 상대에게 돌리고 개별 면담의 비밀이 공동 회기에 영향을 주며 자녀 문제까지 연결됨

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 한 배우자가 비밀 정보를 제공하고 다른 배우자가 전면 공유 요구 |
| 선택 1·재료 | M27·M31·M38: 상담계약·관계·비밀 경계를 재검토 |
| 변화 2 | 두 사람은 조정 대화 참여 여부부터 합의하지 못함 |
| 선택 2·재료 | M34·M39: 가능한 개별 확인·공동 작업 범위·전문 지원을 구분 |
| 첫 도달 상태 | 절차·중재 경로 가능, 상대의 참여·관계 변화는 강제할 수 없음 |
| 첫 판정 | 외부 결과·관측 대기 |
