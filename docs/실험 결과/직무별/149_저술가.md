# 149. 저술가

유형: 운영형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 범위 내 종결 경로**

## 초기 복합 사건

수년간 집필한 비문학 원고에서 핵심 근거가 반박되고 장별 중복·인용권리·독자 난도가 드러나 구조를 다시 짜야 함

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 핵심 근거가 반박돼 여러 장의 논증이 흔들림 |
| 선택 1·재료 | M18·M25·M34: 주장·인용·장 구조를 재편 |
| 변화 2 | 저자가 반론·주장 축소를 수용하고 모의 전권 교정 통과 |
| 선택 2·재료 | M09·M42·M46: 논증·서지·권리·독자 흐름 검수 |
| 첫 도달 상태 | 제공된 합의·근거 아래 원고 종결 경로 있음 |
| 첫 판정 | 범위 내 종결 경로 |
