# 142. 스트리머

유형: 운영형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 범위 내 종결 경로**

## 초기 복합 사건

게임 장애·음향 끊김·악성 채팅·후원 요청이 동시에 들어와 방송 흐름과 대응 우선순위가 무너짐

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 방송 장애와 악성 채팅·후원 요청 동시 발생 |
| 선택 1·재료 | M08·M35·M38: 방송 유지·모더레이션·응대를 병행 분리 |
| 변화 2 | 모의 방송 도구가 대체 장면·음향 복구·중재 결과를 반환 |
| 선택 2·재료 | M10·M42·M51: 진행·약속·후원·사후 기록 확인 |
| 첫 도달 상태 | 제공된 라이브 응답 아래 방송 지속·정리 경로 있음 |
| 첫 판정 | 범위 내 종결 경로 |
