# 136. 인허가 RA (의료기기·의약품)

유형: 고용형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 외부 결과·관측 대기**

## 초기 복합 사건

제품 변경이 임상·성능·제조·표시 자료와 맞지 않고 국가별 경로·기관 질의가 달라 기존 자료 재사용 범위를 판단해야 함

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 제품 변경이 기존 시험·표시·임상 주장과 불일치 |
| 선택 1·재료 | M18·M25·M26: 국가별 경로·증거 격차·제출 영향 재검토 |
| 변화 2 | 기관이 추가 증거를 요구하고 시험기관 일정 지연 |
| 선택 2·재료 | M35·M39·M40: 시험·답변·기한·미완료 제출 조건 연결 |
| 첫 도달 상태 | 인허가 자료·전략 가능, 시험·기관 결정 대기 |
| 첫 판정 | 외부 결과·관측 대기 |
