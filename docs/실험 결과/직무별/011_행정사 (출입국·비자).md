# 011. 행정사 (출입국·비자)

유형: 위임형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 외부 결과·관측 대기**

## 초기 복합 사건

취업 외국인이 고용주를 옮기는데 직무·학력 증빙과 새 고용계약이 맞지 않고 가족의 체류 일정도 다름

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 고용 종료와 가족관계 변동이 기존 체류 신청 전제를 바꿈 |
| 선택 1·재료 | M25·M12·M13: 자격별 전제·서류·기한을 다시 구성 |
| 변화 2 | 증빙 발급이 지연되고 기관 대면 확인 요청 |
| 선택 2·재료 | M35·M39: 대체 증빙 가능성을 확인하고 대면·기한 경로 연결 |
| 첫 도달 상태 | 제출·보완 계획 가능, 증빙·신원 확인·결정은 외부 의존 |
| 첫 판정 | 외부 결과·관측 대기 |
