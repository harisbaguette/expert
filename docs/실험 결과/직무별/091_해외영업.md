# 091. 해외영업

유형: 고용형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 외부 결과·관측 대기**

## 초기 복합 사건

바이어가 결제방식·인도조건을 바꾸고 운임·환율·수입허가가 흔들려 수주액은 커도 회수·납기 위험이 커짐

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 환율·인도조건 변경으로 회수 위험과 비용이 증가 |
| 선택 1·재료 | M53·M38: 결제·운송·인도 조건별 대안 비교 |
| 변화 2 | 바이어가 일부 조건을 수락하나 수입허가·은행 확인 대기 |
| 선택 2·재료 | M35·M39: 승인·선적·회수 선행조건 연결 |
| 첫 도달 상태 | 수출 계약·실행 계획 가능, 기관·바이어 이행은 외부 의존 |
| 첫 판정 | 외부 결과·관측 대기 |
