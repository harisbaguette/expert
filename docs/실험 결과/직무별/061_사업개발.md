# 061. 사업개발

유형: 고용형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 목표·조건 조정 필요**

## 초기 복합 사건

유통사가 독점권과 최소 물량을 요구하지만 내부 제품팀은 고객 맞춤개발을 감당하기 어렵고 파트너 매출 예측도 불확실함

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 유통사 최소물량 요구가 내부 공급능력을 초과 |
| 선택 1·재료 | M35·M53: 독점·물량·개발 약속의 통합 비용 산정 |
| 변화 2 | 유통사가 파일럿·조건 축소를 거부 |
| 선택 2·재료 | M33·M38: 이행 불가능한 약속을 제외하고 결렬 대안 확인 |
| 첫 도달 상태 | 현 조건으로 성사·이행 동시 달성 불가 |
| 첫 판정 | 목표·조건 조정 필요 |
