# 154. 온라인 셀러 (소싱·오픈마켓)

유형: 운영형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 범위 내 종결 경로**

## 초기 복합 사건

여러 마켓에서 같은 재고가 동시 판매되고 공급사 이미지·인증·반품 조건이 불완전해 품절 취소와 제재·손실이 겹침

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 두 마켓이 같은 마지막 재고를 예약 |
| 선택 1·재료 | M25·M52: 가용 재고·주문·취소 상태를 통합 |
| 변화 2 | 모의 원천 조회에서 한 주문만 확정되고 다른 주문은 취소 가능 |
| 선택 2·재료 | M10·M35·M42: 중복 이행 방지·고객 안내·환불·정산 대사 |
| 첫 도달 상태 | 제공된 시스템 응답 아래 주문 예외 처리 경로 있음 |
| 첫 판정 | 범위 내 종결 경로 |
