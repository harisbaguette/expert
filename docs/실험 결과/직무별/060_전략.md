# 060. 전략

유형: 고용형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 범위 내 종결 경로**

## 초기 복합 사건

기존 제품 매출이 줄어 신규시장에 진입하려는데 고객 인터뷰는 긍정적이지만 구매 의사와 유통 경제성이 확인되지 않음

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 호의적 인터뷰 고객들이 실제 가격에서는 구매를 거절 |
| 선택 1·재료 | M18·M34: 시장 진입 가설을 구매·유통 경제성으로 재정의 |
| 변화 2 | 작은 모의 판매에서 특정 세그먼트만 유료 수요 확인 |
| 선택 2·재료 | M53·M54: 전체 확대 대신 한정 실증·중단 조건 선택 |
| 첫 도달 상태 | 제공된 시장 반응 아래 단계적 진입 결정안 종결 경로 있음 |
| 첫 판정 | 범위 내 종결 경로 |
