# 035. 보험설계사 (생명·장기)

유형: 위임형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 목표·조건 조정 필요**

## 초기 복합 사건

고객이 보험료를 줄이려 기존 계약을 해지하려 하지만 새 계약에는 과거 질환 관련 조건과 보장 공백 가능성이 있음

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 기존 계약의 보장·해지 비용이 새 제안보다 유리한 부분 확인 |
| 선택 1·재료 | M21·M53: 유지·추가·전환안을 비용·보장·기간별 재비교 |
| 변화 2 | 고객이 모든 보장 확대와 보험료 인하를 요구하고 해당 상품 조합 없음 |
| 선택 2·재료 | M34·M38: 설명·이해 확인 후 보장·가격·위험 목표 조정 요청 |
| 첫 도달 상태 | 현재 상품·예산에서 동시 목표 불가능 |
| 첫 판정 | 목표·조건 조정 필요 |
