# 116. 정보보안 (취약점 관리)

유형: 고용형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 범위 내 종결 경로**

## 초기 복합 사건

같은 취약점이 외부 노출 서비스와 교체 불가 장비에 있고 스캐너 점수는 높지만 실제 악용 경로·업무 영향은 다름

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 높은 스캔 점수의 일부는 오탐, 다른 낮은 점수는 실제 외부 경로 존재 |
| 선택 1·재료 | M18·M33: 악용 가능·노출·업무 영향으로 우선순위 수정 |
| 변화 2 | 모의 패치·완화 재시험에서 실제 경로 차단 확인 |
| 선택 2·재료 | M54·M42: 조치·예외·잔여 위험을 자산별 기록 |
| 첫 도달 상태 | 주어진 시험 아래 취약점 조치 판단 경로 있음 |
| 첫 판정 | 범위 내 종결 경로 |
