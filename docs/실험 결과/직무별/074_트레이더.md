# 074. 트레이더

유형: 고용형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 범위 내 종결 경로**

## 초기 복합 사건

대량 주문 집행 중 가격이 급변하고 거래소 응답이 지연돼 일부 주문은 체결 여부를 모르는 상태가 됨

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 주문 확인 응답을 잃고 가격이 급변 |
| 선택 1·재료 | M10·M25: 재주문 없이 원주문의 체결·취소 상태 조회 |
| 변화 2 | 부분 체결·잔량 취소가 확인됨 |
| 선택 2·재료 | M33·M53·M42: 실제 잔여 수량·가격·노출로 집행 계획 조정 |
| 첫 도달 상태 | 주어진 체결 증거 아래 주문·잔고 대사 경로 있음 |
| 첫 판정 | 범위 내 종결 경로 |
