# 128. 생산관리

유형: 고용형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 목표·조건 조정 필요**

## 초기 복합 사건

긴급 주문·설비 고장·자재 부족이 겹치고 라인별 전환·숙련·검사 제약 때문에 단순 우선순위 변경으로 납기를 맞출 수 없음

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 설비 고장·자재 부족으로 병목능력 감소 |
| 선택 1·재료 | M25·M53: 작업순서·전환·검사·인력 포함 재계획 |
| 변화 2 | 추가 자원·외주·분할납품 불허, 요구 수량이 최대 능력 초과 |
| 선택 2·재료 | M34·M35: 품질 생략 대신 미달 수량·일정 대안 제시 |
| 첫 도달 상태 | 원래 품질·물량·납기 동시 달성 불가능 |
| 첫 판정 | 목표·조건 조정 필요 |
