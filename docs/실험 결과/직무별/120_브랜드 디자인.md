# 120. 브랜드 디자인

유형: 고용형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 목표·조건 조정 필요**

## 초기 복합 사건

합병 브랜드가 기존 고객 신뢰를 지키면서 새 시장에 진입해야 하고 양사 이름·상표·문화·채널이 충돌함

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 합병 이름이 기존 인식과 상표 검토에서 충돌 |
| 선택 1·재료 | M18·M22·M23: 브랜드 구조·표현·접점 대안 분리 |
| 변화 2 | 경영진은 양사 정체성의 상반된 약속과 단일 이름을 고수 |
| 선택 2·재료 | M34·M38: 브랜드 우선순위와 실현 가능한 약속 재협의 |
| 첫 도달 상태 | 상반된 정체성 요구의 동시 실현 불가, 목표 조정 필요 |
| 첫 판정 | 목표·조건 조정 필요 |
