# 090. 기술영업 (프리세일즈)

유형: 고용형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 범위 내 종결 경로**

## 초기 복합 사건

고객 폐쇄망에서 데모는 성공했으나 실제 데이터량·인증·복구 요구를 만족하지 못하고 입찰 마감이 다가옴

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 실제 부하에서 지연 목표를 넘고 복구가 실패 |
| 선택 1·재료 | M10·M54: 데모 합격을 취소하고 병목·환경 차이 분리 |
| 변화 2 | 증설·범위 축소 후 모의 PoC가 대표 부하·복구를 통과 |
| 선택 2·재료 | M35·M42·M40: 충족·미충족 요구와 최종 구성·인수 조건 기록 |
| 첫 도달 상태 | 주어진 PoC 증거 아래 기술제안 종결 경로 있음 |
| 첫 판정 | 범위 내 종결 경로 |
