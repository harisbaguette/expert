# 108. QA·테스트 엔지니어

유형: 고용형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 범위 내 종결 경로**

## 초기 복합 사건

결제 개편의 자동 테스트는 모두 통과하지만 테스트 데이터가 정상 패턴뿐이고 운영 로그에는 간헐적 환불 불일치가 있음

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 자동 테스트는 통과하지만 환불 대사 불일치 재현 |
| 선택 1·재료 | M49·M54: 구현과 별개 거래 오라클·실패 순서 시험 구성 |
| 변화 2 | 수정 후에도 한 경로가 실패해 출시 기준 미달 |
| 선택 2·재료 | M42·M45: 재현·영향·필수 결함을 보고하고 출시 보류 |
| 첫 도달 상태 | QA 판단·결함 인계는 종결 가능; 제품 출시 합격으로 세지 않음 |
| 첫 판정 | 범위 내 종결 경로 |
