# 109. 데이터 엔지니어

유형: 고용형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 범위 내 종결 경로**

## 초기 복합 사건

원천 스키마 변경과 지연 이벤트·삭제 요청이 겹쳐 매출 집계가 중복되고 재처리하면 이미 삭제한 정보가 살아남

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 스키마 변경·지연 이벤트·삭제 요청 뒤 재처리 시도 |
| 선택 1·재료 | M25·M31·M52: 사건시각·삭제 상태·데이터 계보 확인 |
| 변화 2 | 모의 재처리가 삭제 고객을 부활시키는 결과 반환 |
| 선택 2·재료 | M35·M42: 재처리에도 삭제 조건을 적용하고 하류·백업 복원 경로 검수 |
| 첫 도달 상태 | 주어진 원천·검사 아래 데이터 정정 경로 있음 |
| 첫 판정 | 범위 내 종결 경로 |
