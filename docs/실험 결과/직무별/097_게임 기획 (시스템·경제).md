# 097. 게임 기획 (시스템·경제)

유형: 고용형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 범위 내 종결 경로**

## 초기 복합 사건

복귀 보상과 거래 이벤트를 악용한 다계정이 재화를 증식시키고 정상 유저의 성장·시장가격까지 무너뜨림

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 경제 악용 여부를 알아야 실험 기능이 켜지지만 악용 판별에 그 실험이 필요 |
| 선택 1·재료 | M35·M54: 조건 판정에 쓰는 실험과 패치 실행의 활성 조건을 분리할 필요 확인 |
| 변화 2 | 단순 구현은 불명 조건을 대기로 보내 탐지가 진행되지 않음 |
| 선택 2·재료 | M25·M50: 진단용 선행 의존과 실행 허가를 따로 조립해야 함 |
| 첫 도달 상태 | 조건 판정 의존의 명시 강화 필요 |
| 첫 판정 | 조건 명세 강화 필요 |

## 명세 보완 후 재전개

가정 응답: 허용된 경제 진단이 복제 경로를 확인하고, 보정안 모의실험이 재화 불변조건·정상 이용자 조건을 통과. 진단→패치 검증→인수 경로로 전개.
