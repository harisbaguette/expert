# 044. 의사 (만성질환)

유형: 위임형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 외부 결과·관측 대기**

## 초기 복합 사건

여러 진료기관을 다니는 환자의 가정 측정과 진료실 수치가 다르고 복약 누락·검사 공백이 발견됨

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 새 환자 보고가 기존 추적 기록과 불일치하고 검사 필요성이 생김 |
| 선택 1·재료 | M18·M25·M38: 진술·측정·추정을 분리해 필요한 확인을 구성 |
| 변화 2 | 검사 결과와 직접 평가가 아직 없음 |
| 선택 2·재료 | M39·M36: 확인 전 가능한 설명·연계와 확정할 수 없는 판단을 구분 |
| 첫 도달 상태 | 추적·질문·연계 계획 가능, 임상 판단·처치는 외부 확인 의존 |
| 첫 판정 | 외부 결과·관측 대기 |
