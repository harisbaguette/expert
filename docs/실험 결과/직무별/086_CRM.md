# 086. CRM

유형: 고용형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 범위 내 종결 경로**

## 초기 복합 사건

할인 메시지로 재구매가 늘었지만 원래 구매할 고객에게 쿠폰이 나가고 수신거부·중복고객 문제도 생김

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 중복 고객ID와 수신거부가 쿠폰 여정에 남음 |
| 선택 1·재료 | M52·M31: 식별·동의·혜택 상태를 정리 |
| 변화 2 | 모의 대조군에서 할인 없이 구매할 고객군의 쿠폰 효과 없음 |
| 선택 2·재료 | M53·M54·M10: 제외·빈도·혜택안을 수정하고 재발송 방지 |
| 첫 도달 상태 | 주어진 동의·실험 데이터 아래 CRM 수정 경로 있음 |
| 첫 판정 | 범위 내 종결 경로 |
