# 064. 채용

유형: 고용형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 목표·조건 조정 필요**

## 초기 복합 사건

채용부서는 다재다능한 시니어를 원하지만 예산이 낮고 면접관마다 기준이 달라 좋은 후보가 이탈함

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 면접관 기준 불일치로 유효 후보가 탈락한 사실 확인 |
| 선택 1·재료 | M21·M35: 역할별 과업·증거·평가 기준 재합의 |
| 변화 2 | 보상 상향·역할 축소 없이 희소 숙련자를 즉시 채용하라고 요구 |
| 선택 2·재료 | M33·M38: 현재 후보·예산·기한의 불일치 제시 |
| 첫 도달 상태 | 고정 조건에서 즉시 채용 보장 불가, 역할·보상·기간 조정 필요 |
| 첫 판정 | 목표·조건 조정 필요 |
