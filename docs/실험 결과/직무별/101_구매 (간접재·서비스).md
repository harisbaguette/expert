# 101. 구매 (간접재·서비스)

유형: 고용형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 범위 내 종결 경로**

## 초기 복합 사건

최저가 IT 외주 제안이 데이터 이전·운영지원·사용권을 제외해 계약 후 비용과 종속성이 급증할 가능성이 있음

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 최저가 제안이 이전·운영·사용권을 제외 |
| 선택 1·재료 | M18·M53: 비교 범위를 정규화하고 생애비용 재산정 |
| 변화 2 | 공급사가 추가 비용·종료·검수 조건을 명확히 제시 |
| 선택 2·재료 | M38·M35·M40: 비교 평가·협상·인수 조건 확정 |
| 첫 도달 상태 | 주어진 제안·합의 아래 구매 결정안 종결 경로 있음 |
| 첫 판정 | 범위 내 종결 경로 |
