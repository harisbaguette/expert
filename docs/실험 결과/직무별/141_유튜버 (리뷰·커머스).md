# 141. 유튜버 (리뷰·커머스)

유형: 운영형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 범위 내 종결 경로**

## 초기 복합 사건

협찬사가 유리한 조건을 요구하고 샘플 편차·펌웨어 변경으로 비교 결과가 달라져 추천·제휴 매출·신뢰가 충돌함

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 협찬 제품이 비교시험에서 불리한 결과를 냄 |
| 선택 1·재료 | M18·M54: 조건·버전·샘플 편차와 실측 재확인 |
| 변화 2 | 모의 재시험도 같고 게시 권한은 독립 리뷰를 허용 |
| 선택 2·재료 | M27·M09·M42: 결과·조건·이해관계·용도별 평가를 함께 공개안에 반영 |
| 첫 도달 상태 | 제공된 시험·권한 아래 리뷰 제작 경로 있음 |
| 첫 판정 | 범위 내 종결 경로 |
