# 099. MD (오프라인 매입)

유형: 고용형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 범위 내 종결 경로**

## 초기 복합 사건

계절상품을 대량 매입했는데 상권별 수요가 갈리고 반품권·진열비·후속 공급 조건 때문에 단순 할인으로 해결되지 않음

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 같은 상품의 매장별 수요가 갈리고 반품권은 일부만 존재 |
| 선택 1·재료 | M25·M53: 가용·이동·반품·할인 비용을 비교 |
| 변화 2 | 공급사·점포가 이동·반품 조건을 수락 |
| 선택 2·재료 | M35·M40: 물량·일정·검수·정산으로 연결 |
| 첫 도달 상태 | 제공된 합의·수요 아래 매입·소진 계획 종결 경로 있음 |
| 첫 판정 | 범위 내 종결 경로 |
