# 127. 영상 편집자

유형: 고용형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 범위 내 종결 경로**

## 초기 복합 사건

혼합 프레임·휴대폰 HDR·다중 녹음 소스에 후반 수정이 들어와 싱크·색·자막·권리와 온라인 편집 연결이 깨짐

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 프록시 재연결에서 색·싱크·자막이 어긋남 |
| 선택 1·재료 | M25·M09: 원본·타임코드·색·오디오 매핑 수정 |
| 변화 2 | 모의 전편 재생과 프로젝트 재열기가 모두 통과 |
| 선택 2·재료 | M42·M40: 마스터·자막·분리음원·편집 원본 대조 |
| 첫 도달 상태 | 제공된 재생 증거 아래 영상 납품 경로 있음 |
| 첫 판정 | 범위 내 종결 경로 |
