# 009. 법무사 (개인회생·파산)

유형: 위임형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 외부 결과·관측 대기**

## 초기 복합 사건

자영업자의 카드채무와 보증채무가 섞이고 최근 재산 처분과 가족 송금의 설명이 부족해 보정 요청이 옴

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 누락 채무와 최근 가족 송금 확인 |
| 선택 1·재료 | M52·M25: 채권자·재산·가용소득 목록과 관련 신청자료 재대사 |
| 변화 2 | 법원이 소득 지속성 보완을 요구하나 고용 자료 미도착 |
| 선택 2·재료 | M35·M39: 보완 항목·기한·취득 책임을 연결 |
| 첫 도달 상태 | 수정 초안까지 가능, 외부 소득 근거·법원 결과 대기 |
| 첫 판정 | 외부 결과·관측 대기 |
