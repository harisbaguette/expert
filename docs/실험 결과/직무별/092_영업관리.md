# 092. 영업관리

유형: 고용형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 범위 내 종결 경로**

## 초기 복합 사건

분기 말 취소 가능한 주문을 확정 매출처럼 올리고 반품·미수·중복 실적 때문에 팀 보상과 생산계획이 왜곡됨

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 취소가능 주문이 확정 매출·성과급에 포함 |
| 선택 1·재료 | M25·M52: 수주·출하·매출·수금 상태를 다시 대사 |
| 변화 2 | 모의 반품·입금 자료가 수정 실적을 확인 |
| 선택 2·재료 | M53·M42: 생산예측·보상·미수 대장 전파 |
| 첫 도달 상태 | 제공된 기록 아래 실적·정산 정정 경로 있음 |
| 첫 판정 | 범위 내 종결 경로 |
