# 045. 의사 (정신건강)

유형: 위임형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 외부 결과·관측 대기**

## 초기 복합 사건

수면·활동·기분 변화에 대해 환자와 가족 설명이 다르고 치료 중단·부작용 의심·일상 기능 저하가 동반됨

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 본인 설명과 가족 관찰이 다르고 최근 기능 변화가 보고됨 |
| 선택 1·재료 | M18·M25·M38: 정보원별 근거·비밀·관계와 평가 필요를 구분 |
| 변화 2 | 실제 면담·전문 평가에서만 확인 가능한 부분이 남음 |
| 선택 2·재료 | M39·M43: 필요한 평가·위기 연계·전문 기여를 기록 |
| 첫 도달 상태 | 평가 준비·연계 가능, 진단·치료 성과 종결은 불가 |
| 첫 판정 | 외부 결과·관측 대기 |
