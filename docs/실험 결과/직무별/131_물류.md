# 131. 물류

유형: 고용형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 외부 결과·관측 대기**

## 초기 복합 사건

항만 지연·냉장 이탈·부분 분실이 겹쳐 고객 납기와 대체운송 비용·보험·반품 처리를 함께 결정해야 함

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 배송 지연 중 온도 이탈·부분 분실 확인 |
| 선택 1·재료 | M07·M25·M53: 위치·품질·대체 운송·회수 비용으로 분기 |
| 변화 2 | 실물 상태·인수 주체의 확인이 늦어짐 |
| 선택 2·재료 | M35·M38·M39: 고객 안내·운송사 조정·검수·클레임 연결 |
| 첫 도달 상태 | 대응 계획·가능한 조치 수행, 정상 인도·손해 확정 대기 |
| 첫 판정 | 외부 결과·관측 대기 |
