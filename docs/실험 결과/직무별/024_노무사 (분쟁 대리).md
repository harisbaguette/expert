# 024. 노무사 (분쟁 대리)

유형: 위임형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 외부 결과·관측 대기**

## 초기 복합 사건

저성과 해고의 평가 기록이 사후 작성됐다는 주장이 나오고 노조 활동·괴롭힘·임금 쟁점이 함께 제기됨

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 해고 사유 기록이 뒤늦게 작성됐다는 메타데이터 발견 |
| 선택 1·재료 | M18·M35: 사건 시간축·진술·입증 계획을 수정 |
| 변화 2 | 노동위원회 이후 법원 단계 검토가 필요해짐 |
| 선택 2·재료 | M27·M39: 절차별 업무 범위와 담당 전문 수행을 분리 |
| 첫 도달 상태 | 주장·증거·절차 준비 가능, 심판 결과·후속 대리는 외부 의존 |
| 첫 판정 | 외부 결과·관측 대기 |
