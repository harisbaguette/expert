# 036. 보험설계사 (손해·자동차)

유형: 위임형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 외부 결과·관측 대기**

## 초기 복합 사건

배달 차량이 일반 용도로 가입돼 있고 사업장 특약도 실제 운영과 달라 사고 접수에서 보장 다툼이 생김

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 실제 운행·사업장 용도가 청약 정보와 다름 |
| 선택 1·재료 | M17·M21: 위험 사실·담보·고지 필요를 다시 구성 |
| 변화 2 | 보험사가 추가 실사·조건 변경 검토 요청 |
| 선택 2·재료 | M35·M38·M39: 고객 설명·보완·갱신 공백 대안 연결 |
| 첫 도달 상태 | 설계·청약 준비 가능, 인수 결정과 실사 대기 |
| 첫 판정 | 외부 결과·관측 대기 |
