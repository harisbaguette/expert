# 158. 일러스트레이터

유형: 운영형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 범위 내 종결 경로**

## 초기 복합 사건

책의 여러 장면에서 인물·빛·소품이 일관돼야 하고 표지·인쇄·굿즈 변형과 수정 요청이 겹침

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 연속 장면에서 인물 소품·빛·크기 불일치 |
| 선택 1·재료 | M23·M25·M09: 캐릭터·장면 관계를 기준으로 관련 컷 수정 |
| 변화 2 | 모의 실크기 출력·레이어 편집 검수 통과 |
| 선택 2·재료 | M42·M40: 원본·인쇄·변형·수정 지침 인계 |
| 첫 도달 상태 | 제공된 시각 검수 아래 삽화 납품 경로 있음 |
| 첫 판정 | 범위 내 종결 경로 |
