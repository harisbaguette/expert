# 089. 영업 (B2B 기존·키어카운트)

유형: 고용형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 목표·조건 조정 필요**

## 초기 복합 사건

큰 고객이 장애 보상을 요구하며 갱신을 보류하고 계열사 통합 할인과 아직 없는 기능을 동시에 요구함

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 장애 보상과 계열사 할인을 합치면 계정 이익이 음수 |
| 선택 1·재료 | M33·M53: 갱신·지원·개발 약속을 합산 |
| 변화 2 | 고객이 범위 축소·가격 조정을 모두 거부 |
| 선택 2·재료 | M34·M38: 유지·철수·대체 범위의 효과 제시 |
| 첫 도달 상태 | 기존 범위·가격으로 수익 있는 갱신 불가능 |
| 첫 판정 | 목표·조건 조정 필요 |
