# 126. 에디터

유형: 고용형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 목표·조건 조정 필요**

## 초기 복합 사건

전문가 원고의 핵심 주장이 자료와 어긋나고 저자는 수정을 거부하며 마감·법적 분쟁·독자 이해가 충돌함

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 핵심 주장이 반증되고 저자가 삭제를 거부 |
| 선택 1·재료 | M18·M38: 증거·대안 표현·독자 영향과 편집권 확인 |
| 변화 2 | 발행인은 사실 검증과 저자 원문 무수정을 동시에 요구 |
| 선택 2·재료 | M27·M34: 권한·진실성·출판 조건 충돌 제시 |
| 첫 도달 상태 | 현 요구로 출판 목표 충족 불가, 수정·보류·계약 조정 필요 |
| 첫 판정 | 목표·조건 조정 필요 |
