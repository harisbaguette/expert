# 022. 관세사

유형: 위임형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 외부 결과·관측 대기**

## 초기 복합 사건

복합 전자제품의 세번이 다투어지고 해외산 부품으로 바뀐 뒤에도 공급사가 예전 원산지 확인서를 보냄

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 부품 변경으로 기능·원산지 계산 전제가 바뀜 |
| 선택 1·재료 | M07·M25·M53: 제품 판본별 분류·원산지 증빙을 재연결 |
| 변화 2 | 공급사가 옛 확인서만 제공하고 기관 사전심사 미회신 |
| 선택 2·재료 | M18·M35·M39: 미확정 분류·증빙과 신고 일정의 대안 관리 |
| 첫 도달 상태 | 심사·신고 준비 가능, 물품 사실·기관 판단 대기 |
| 첫 판정 | 외부 결과·관측 대기 |
