# 046. 심리상담사 (개인)

유형: 위임형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 외부 결과·관측 대기**

## 초기 복합 사건

직장 갈등으로 시작한 상담이 반복되는 관계 패턴과 회피로 이어지고 내담자는 과제 수행 없이 같은 어려움을 호소함

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 상담자가 세운 가설과 다른 행동 패턴을 내담자가 제시 |
| 선택 1·재료 | M22·M25·M38: 사례개념화·개입 목표를 갱신 |
| 변화 2 | 내담자는 설명에는 동의하지만 회기 밖 변화가 아직 없음 |
| 선택 2·재료 | M45·M51: 동의를 효과로 세지 않고 다음 관찰·개입 평가 연결 |
| 첫 도달 상태 | 적응적 상담 경로 있음, 관계·기능 변화는 실제 상호작용 의존 |
| 첫 판정 | 외부 결과·관측 대기 |
