# 070. 펀드매니저 (주식)

유형: 고용형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 목표·조건 조정 필요**

## 초기 복합 사건

펀드 환매가 늘었는데 유동성 낮은 보유주식과 거래정지 종목이 있어 벤치마크 위험과 현금 마련이 충돌함

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 환매 요구 10, 즉시 현금화 가능액 6으로 감소 |
| 선택 1·재료 | M33·M53: 유동성·가격 충격·잔여 투자자 영향을 함께 계산 |
| 변화 2 | 추가 자금·환매 일정 변경 수단이 주어진 조건에 없음 |
| 선택 2·재료 | M34·M35: 모든 환매의 무손실 즉시 지급 불가를 표시 |
| 첫 도달 상태 | 고정 자산·기간에서 원래 지급 목표 불가능 |
| 첫 판정 | 목표·조건 조정 필요 |
