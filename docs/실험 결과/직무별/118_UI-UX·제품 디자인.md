# 118. UI/UX·제품 디자인

유형: 고용형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 범위 내 종결 경로**

## 초기 복합 사건

숙련자 중심 업무도구를 단순화했더니 초보자는 편해도 전문가의 대량 작업·보조기술·오류 복구가 막힘

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 단순화 화면이 숙련자 대량작업과 오류 복구를 막음 |
| 선택 1·재료 | M07·M34: 집단·과업·빈도별 비용으로 흐름 수정 |
| 변화 2 | 모의 사용자 시험에서 초보·숙련·보조기술 과업이 수정안 통과 |
| 선택 2·재료 | M54·M42·M40: 상태·접근성·과업별 인수 연결 |
| 첫 도달 상태 | 제공된 사용자 관측 아래 UX 설계 인수 경로 있음 |
| 첫 판정 | 범위 내 종결 경로 |
