# 031. 건축사 (주택·소규모 건축)

유형: 위임형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 범위 내 종결 경로**

## 초기 복합 사건

협소 대지에서 주차·채광·계단·예산을 맞췄는데 실측 경계와 기존 구조가 도면과 다름

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 실측에서 기존 벽체·설비 위치가 도면과 다름 |
| 선택 1·재료 | M07·M25·M35: 공간·설비·법규 요구와 설계 객체 갱신 |
| 변화 2 | 예산·일정 안에 대체안이 있고 모의 간섭검사 통과 |
| 선택 2·재료 | M09·M42: 평면·도면·물량을 동기화하고 수정 범위 검수 |
| 첫 도달 상태 | 제공된 실측·규칙 아래 설계 인계 경로 있음; 허가·시공은 별도 |
| 첫 판정 | 범위 내 종결 경로 |
