# 040. 투자자문사

유형: 위임형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 목표·조건 조정 필요**

## 초기 복합 사건

고객 회사 주식에 자산이 집중돼 있는데 주택 잔금이 예정돼 있고 시장 하락 시 거래가 어려움

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 고객의 현금 필요가 앞당겨지고 포트폴리오 상관도 상승 |
| 선택 1·재료 | M33·M53: 유동성·집중·하락 시나리오 재계산 |
| 변화 2 | 고객은 손실 가능성 없이 기존 목표 수익률을 보장하라고 요구 |
| 선택 2·재료 | M34·M38: 보장할 수 없는 성과와 가능한 위험 조정안을 구분 |
| 첫 도달 상태 | 원래 보장 요구 충족 불가, 목표·위험·기간 조정 필요 |
| 첫 판정 | 목표·조건 조정 필요 |
