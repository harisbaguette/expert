# 088. 영업 (B2B 신규 개척)

유형: 고용형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 목표·조건 조정 필요**

## 초기 복합 사건

현업은 제품을 원하지만 보안·구매·재무가 반대하고 경쟁사는 저가를 제시해 고객맞춤 기능을 무리하게 약속할 유인이 생김

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 보안팀은 핵심 요구 미충족, 영업은 맞춤개발을 약속하려 함 |
| 선택 1·재료 | M35·M53: 구매 문제·검증·이행비를 재구성 |
| 변화 2 | 고객은 검증 전 확정 계약과 무상 개발을 고수 |
| 선택 2·재료 | M33·M38: 권한·역량 한도 안의 제안만 비교 |
| 첫 도달 상태 | 현 조건에서 수주·이행·수익 동시 충족 불가 |
| 첫 판정 | 목표·조건 조정 필요 |
