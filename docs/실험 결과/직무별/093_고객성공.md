# 093. 고객성공

유형: 고용형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 외부 결과·관측 대기**

## 초기 복합 사건

계약 담당자가 퇴사하고 이용자는 교육을 마쳤지만 핵심 업무를 수행하지 못해 갱신 직전 성과가 없다는 불만이 나옴

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 고객 사용률은 높지만 핵심 결산 과업 수행 실패 |
| 선택 1·재료 | M17·M38: 접속 지표 대신 실제 업무 장애·목표 확인 |
| 변화 2 | 제품 수정과 교육 계획에는 동의, 실제 다음 결산은 미도래 |
| 선택 2·재료 | M35·M51: 정착 계획과 과업·성과 관찰 시점 설정 |
| 첫 도달 상태 | 성공계획은 가능, 고객 성과·갱신 판단 대기 |
| 첫 판정 | 외부 결과·관측 대기 |
