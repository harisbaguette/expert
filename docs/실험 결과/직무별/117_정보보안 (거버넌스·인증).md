# 117. 정보보안 (거버넌스·인증)

유형: 고용형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 범위 내 종결 경로**

## 초기 복합 사건

인증 증빙은 갖췄으나 새 SaaS·위탁사·해외팀이 통제 범위 밖이고 담당자가 점검 시점에만 설정을 맞춤

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 새 위탁 SaaS가 인증 범위 밖에서 데이터를 처리 |
| 선택 1·재료 | M25·M26: 범위·흐름·통제 목적을 다시 연결 |
| 변화 2 | 운영 증거 표본에서 문서와 실제 통제 불일치 확인 |
| 선택 2·재료 | M18·M49·M35: 격차·책임·개선·재평가 계획 작성 |
| 첫 도달 상태 | 감사·격차 보고는 종결 가능; 인증·보안 효과 완료와 구분 |
| 첫 판정 | 범위 내 종결 경로 |
