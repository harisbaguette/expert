# 161. SaaS 운영자

유형: 운영형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 외부 결과·관측 대기**

## 초기 복합 사건

대형 고객 요구로 개발을 집중한 사이 작은 고객 이탈·장애·클라우드 비용·지원 부채가 늘고 갱신·현금이 악화됨

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 대형 고객 개발 약속 때문에 서비스 장애·지원비·이탈 증가 |
| 선택 1·재료 | M33·M53: 제품·고객·운영·현금의 결합 효과 재산정 |
| 변화 2 | 위임자가 범위 축소·가격 변경을 수락하지만 효과 관측 전 |
| 선택 2·재료 | M34·M35·M51: 출시·고객 합의·서비스·수익을 순차 추적 |
| 첫 도달 상태 | 운영 조정 경로 있음, 갱신·유지·현금 개선 성과는 대기 |
| 첫 판정 | 외부 결과·관측 대기 |
