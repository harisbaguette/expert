# 111. 데이터 사이언티스트

유형: 고용형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 외부 결과·관측 대기**

## 초기 복합 사건

이탈 모델 정확도가 높지만 미래 정보를 쓰고 개입 대상 선정이 비용·편향·기존 영업 행동 때문에 실제 성과를 악화시킴

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 미래 정보가 특성에 들어가 오프라인 정확도가 부풀었음 |
| 선택 1·재료 | M52·M53: 시점·라벨·분할·선택편향 수정 |
| 변화 2 | 누출 제거 후 예측 개선은 남지만 개입 효과는 미관측 |
| 선택 2·재료 | M54·M51: 비용·대조 개입·모니터링을 분리 |
| 첫 도달 상태 | 모델 검증·개입 설계 가능, 실제 업무 효과는 대기 |
| 첫 판정 | 외부 결과·관측 대기 |
