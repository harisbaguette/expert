# 003. 변호사 (가사·상속)

유형: 위임형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 목표·조건 조정 필요**

## 초기 복합 사건

재혼가족이 비상장회사 주식과 부동산을 상속받는데 생전 증여와 유언 진정성을 서로 다르게 주장함

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 유언 사본과 다른 원본 발견, 비상장주식 유동성 없음 |
| 선택 1·재료 | M18·M25·M53: 유언 효력 가정과 재산가액·현금 조달을 별도 분기 |
| 변화 2 | 한 상속인이 지분 유지와 즉시 전액 현금을 동시에 요구 |
| 선택 2·재료 | M34·M38: 지분·현금·기간 제약을 대조하고 요구 충돌을 명시 |
| 첫 도달 상태 | 모든 요구 동시 충족 불가, 분할·매각·기간 중 목표 조정 필요 |
| 첫 판정 | 목표·조건 조정 필요 |
