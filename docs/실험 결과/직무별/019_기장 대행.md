# 019. 기장 대행

유형: 위임형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 범위 내 종결 경로**

## 초기 복합 사건

사업주가 법인카드로 개인 지출을 하고 카드 취소가 다음 달 반영돼 현금잔액과 비용이 맞지 않음

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 같은 영수증이 카드와 비용 정산에 이중 입력됨 |
| 선택 1·재료 | M52·M21: 결제·증빙 키와 거래 의미로 중복 전표 후보 분리 |
| 변화 2 | 거래처 확인과 통장 대사가 하나의 결제임을 확인 |
| 선택 2·재료 | M25·M42: 중복 분개 취소·잔액·마감 영향 재계산 |
| 첫 도달 상태 | 주어진 거래 묶음의 기장·대사 종결 경로 있음 |
| 첫 판정 | 범위 내 종결 경로 |
