# 016. 세무사 (신고·기장)

유형: 위임형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 범위 내 종결 경로**

## 초기 복합 사건

온라인몰의 주문액·PG 정산액·환불액이 다르고 해외 매출과 개인 사용 경비가 섞여 신고 초안이 틀어짐

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 정산 수수료를 매출 차감과 비용에 중복 반영한 사실 확인 |
| 선택 1·재료 | M52·M53: 원거래→정산→입금 대사로 중복 제거 |
| 변화 2 | 누락 환불 자료가 도착하고 가상 검산기가 수정 세액 일치를 반환 |
| 선택 2·재료 | M25·M42: 영향 전표·세무조정·신고 초안을 갱신하고 검산 |
| 첫 도달 상태 | 주어진 자료·계산 규칙에서 장부·신고 초안 종결 경로 있음; 실제 신고는 별도 |
| 첫 판정 | 범위 내 종결 경로 |
