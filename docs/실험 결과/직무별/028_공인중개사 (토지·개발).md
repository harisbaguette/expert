# 028. 공인중개사 (토지·개발)

유형: 위임형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 외부 결과·관측 대기**

## 초기 복합 사건

저렴한 토지가 있으나 진입도로는 타인 소유이고 경계·용도·농지전용 가능성에 관해 매도인 설명이 엇갈림

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 진입로 이용 조건과 실제 경계가 광고 설명과 다름 |
| 선택 1·재료 | M07·M18·M34: 개발 가능 가정을 취소하고 조건부 매매안 재작성 |
| 변화 2 | 경계 측량·관청 확인이 매도자의 요구 일정에 맞지 않음 |
| 선택 2·재료 | M35·M38·M39: 확인 선행조건·계약 일정·철회 대안 제시 |
| 첫 도달 상태 | 개발·거래 판단 근거 준비, 현장·기관 확인 대기 |
| 첫 판정 | 외부 결과·관측 대기 |
