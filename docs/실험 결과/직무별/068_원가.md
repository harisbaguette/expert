# 068. 원가

유형: 고용형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 범위 내 종결 경로**

## 초기 복합 사건

생산량이 줄어 고정비 배부가 급증했는데 영업은 일부 제품의 단종을 요청하고 부산물 수익과 재작업비도 섞임

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 저생산량 배부가 제품 적자를 부풀리고 부산물 수익 누락 |
| 선택 1·재료 | M52·M53: 회피 가능한 원가·공통 고정비·부산물 분리 |
| 변화 2 | 모의 생산 자료에서 단종해도 고정비 대부분 존속 확인 |
| 선택 2·재료 | M34·M42: 단종 판단을 증분손익으로 재작성 |
| 첫 도달 상태 | 주어진 비용 구조에서 제품·원가 의사결정안 종결 경로 있음 |
| 첫 판정 | 범위 내 종결 경로 |
