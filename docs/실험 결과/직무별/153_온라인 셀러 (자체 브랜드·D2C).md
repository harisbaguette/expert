# 153. 온라인 셀러 (자체 브랜드·D2C)

유형: 운영형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 목표·조건 조정 필요**

## 초기 복합 사건

광고가 성공해 주문이 급증했지만 품질 편차·배송 지연·환불이 늘고 생산 선금 때문에 매출 증가와 함께 현금이 부족해짐

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 매출 급증과 함께 환불·제조 선금·지원비도 증가 |
| 선택 1·재료 | M33·M53: 단위경제·운전자금·품질 비용 통합 |
| 변화 2 | 가격·광고·물량·납기 조정 및 추가 자금이 모두 불허 |
| 선택 2·재료 | M34·M35: 매출 확대가 현금 고갈을 앞당기는 조건 표시 |
| 첫 도달 상태 | 원래 성장·가격·납기·현금 목표 동시 달성 불가 |
| 첫 판정 | 목표·조건 조정 필요 |
