# 095. PM·PO (B2B SaaS)

유형: 고용형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 목표·조건 조정 필요**

## 초기 복합 사건

대형 고객의 특수 승인·권한 요구가 기존 테넌트 모델과 충돌하고 계약 마감 때문에 제품을 고객별로 분기할 압력이 생김

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 대형 고객 예외 권한이 공통 테넌트 격리를 깨뜨림 |
| 선택 1·재료 | M25·M31·M35: 확장점·공통 모델·계약 조건 재설계 |
| 변화 2 | 일정·개발비 고정에 고객별 코드분기 금지도 함께 요구 |
| 선택 2·재료 | M33·M53: 현실 작업량과 조건의 양립 여부 확인 |
| 첫 도달 상태 | 모든 요구 동시 충족 불가, 일정·범위·비용 조정 필요 |
| 첫 판정 | 목표·조건 조정 필요 |
