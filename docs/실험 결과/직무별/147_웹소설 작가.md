# 147. 웹소설 작가

유형: 운영형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 범위 내 종결 경로**

## 초기 복합 사건

독자 반응에 맞춰 전개를 바꾸면 기존 복선·인물 동기·세계 규칙이 깨지고 촉박한 연재 일정에서 장기 결말이 흔들림

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 독자 요구대로 반전을 바꾸면 기존 인물 동기·복선이 깨짐 |
| 선택 1·재료 | M25·M22·M34: 장기 인과·회차 효용에 맞는 대안 집필 |
| 변화 2 | 모의 편집·독자 검토가 수정안의 연속성·몰입을 수용 |
| 선택 2·재료 | M09·M46: 회차·설정·복선·일정 대조 |
| 첫 도달 상태 | 제공된 반응 아래 회차 집필·연재 준비 경로 있음 |
| 첫 판정 | 범위 내 종결 경로 |
