# 001. 변호사 (민사·상사 송무)

유형: 위임형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 외부 결과·관측 대기**

## 초기 복합 사건

납품업체가 미수금을 청구하자 구매자가 불량과 지체를 이유로 상계하고, 일부 물품을 제3자가 사용한 사실이 나옴

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 검수서 원본에서 20% 수량 미인도 확인 |
| 선택 1·재료 | M18·M25: 전액 청구 전제를 폐기하고 인도분·하자 항변·증거를 분리 |
| 변화 2 | 구매자가 인정 금액만 분할 지급 제안 |
| 선택 2·재료 | M34·M38·M53: 회수 시점·담보·분쟁비용을 비교해 조건부 합의안 작성 |
| 첫 도달 상태 | 청구 계산·서면·합의 대안까지 연결, 지급·재판 결과는 미정 |
| 첫 판정 | 외부 결과·관측 대기 |
