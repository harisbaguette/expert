# 049. 영양사

유형: 위임형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 외부 결과·관측 대기**

## 초기 복합 사건

만성질환과 알레르기가 있는 교대근무자가 식단을 지키지 못하고, 예산·조리시설·선호가 권장 식사와 맞지 않음

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 식사 일지와 실제 구매·섭취 설명이 달라짐 |
| 선택 1·재료 | M18·M53: 섭취 추정·영양·비용 제약을 다시 계산 |
| 변화 2 | 고객이 가능한 식단을 선택하지만 실천·몸 상태 자료는 아직 없음 |
| 선택 2·재료 | M38·M51: 이해·실천 계획과 추적 조건 설정 |
| 첫 도달 상태 | 식단·상담 계획 가능, 실제 건강·행동 효과는 외부 관찰 의존 |
| 첫 판정 | 외부 결과·관측 대기 |
