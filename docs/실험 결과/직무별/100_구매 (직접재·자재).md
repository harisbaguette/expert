# 100. 구매 (직접재·자재)

유형: 고용형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 외부 결과·관측 대기**

## 초기 복합 사건

핵심 부품 업체가 중단돼 대체품을 구했으나 도면 공차·인증·금형 소유와 생산 승인 때문에 즉시 투입할 수 없음

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 대체부품 치수는 맞지만 재질·승인 조건이 다름 |
| 선택 1·재료 | M21·M54: 도면·시험·양산 승인 요건 재정의 |
| 변화 2 | 공급사는 시험성적서 원본을 제공하지 못함 |
| 선택 2·재료 | M18·M35·M39: 추가 시험·검증·납기 대안 연결 |
| 첫 도달 상태 | 대체 소싱안 가능, 실물 적합성과 승인 대기 |
| 첫 판정 | 외부 결과·관측 대기 |
