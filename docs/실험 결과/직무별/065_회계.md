# 065. 회계

유형: 고용형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 범위 내 종결 경로**

## 초기 복합 사건

연결대상 회사의 마감일·계정이 다르고 기말 배송·검수 조건과 내부거래 미실현이익이 결산 수치를 바꿈

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 자회사 기말 매출에 미검수와 내부거래가 섞임 |
| 선택 1·재료 | M52·M53: 계정·기간·거래상대 대사와 연결 조정 |
| 변화 2 | 모의 외부 확인·상대법인 대사가 조정값을 확인 |
| 선택 2·재료 | M25·M42: 재무제표·주석·조정분개 판본을 일치시킴 |
| 첫 도달 상태 | 주어진 원장·정책 아래 연결결산 패키지 종결 경로 있음 |
| 첫 판정 | 범위 내 종결 경로 |
