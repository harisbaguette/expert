# 107. 임베디드·펌웨어

유형: 고용형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 외부 결과·관측 대기**

## 초기 복합 사건

전원 불안정 중 펌웨어 갱신과 센서 오류가 겹쳐 장치가 부팅 불능이거나 잘못된 출력 상태에 머물 수 있음

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 갱신 도중 전원 차단과 센서 오류가 동시 발생 |
| 선택 1·재료 | M25·M35·M54: 부트·갱신·출력 상태별 복구 조건 확인 |
| 변화 2 | 실제 장치의 전기·타이밍 시험을 할 장비 접근 불가 |
| 선택 2·재료 | M39·M40: 모의 통과와 실기기 미검증을 분리 |
| 첫 도달 상태 | 펌웨어 수정·시험 계획 가능, 장치 검증 대기 |
| 첫 판정 | 외부 결과·관측 대기 |
