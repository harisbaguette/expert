# 005. 변호사 (도산·회생)

유형: 위임형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 목표·조건 조정 필요**

## 초기 복합 사건

제조기업이 지급불능 위기인데 수주잔고는 남아 있고, 은행 담보·계열 보증·핵심 납품사의 공급중단이 얽힘

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 주요 고객 선수금 취소로 가용 현금 3, 필요 운영비 5 |
| 선택 1·재료 | M33·M53: 흑자 회생안도 단기 지급불능임을 검출 |
| 변화 2 | 신규 자금·공급 유예·자산 매각이 모두 거절됨 |
| 선택 2·재료 | M34·M38: 가동 유지안 폐기, 사업 축소·정리 대안으로 전환 |
| 첫 도달 상태 | 원래 규모의 계속 영업 목표 불가능, 정리·축소 결정 필요 |
| 첫 판정 | 목표·조건 조정 필요 |
