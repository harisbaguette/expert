# 098. MD (온라인)

유형: 고용형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 범위 내 종결 경로**

## 초기 복합 사건

할인 행사 매출이 늘지만 광고비·반품·품절 대체·쿠폰 중복 때문에 실제 공헌이익은 감소함

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 행사 매출 상승에도 반품·광고·쿠폰 비용으로 공헌이익 하락 |
| 선택 1·재료 | M52·M53: SKU별 순이익·재고·귀속을 재계산 |
| 변화 2 | 모의 수요에서 묶음·혜택 조정안이 재고·마진 조건 충족 |
| 선택 2·재료 | M34·M10·M42: 행사·발주·가격 변경과 정산 확인 |
| 첫 도달 상태 | 제공된 수요·비용 아래 MD 실행안 종결 경로 있음 |
| 첫 판정 | 범위 내 종결 경로 |
