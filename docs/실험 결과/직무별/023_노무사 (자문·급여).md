# 023. 노무사 (자문·급여)

유형: 위임형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 범위 내 종결 경로**

## 초기 복합 사건

합병한 두 회사의 고정수당과 교대근무 기록이 달라 초과근로수당 소급 정산과 임금체계 개편을 함께 요구받음

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 근태 누락과 보상항목 해석 차이가 급여를 바꿈 |
| 선택 1·재료 | M52·M53: 사실 대사와 적용 해석을 분리해 계산 |
| 변화 2 | 근태 원본과 이 업무에 고정한 급여 규칙이 확인됨 |
| 선택 2·재료 | M21·M42: 대상자별 재계산·소급 영향·명세서 대사 |
| 첫 도달 상태 | 명시된 규칙과 자료 아래 급여 정정 패키지 종결 경로 있음 |
| 첫 판정 | 범위 내 종결 경로 |
