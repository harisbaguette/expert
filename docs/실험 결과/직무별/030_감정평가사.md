# 030. 감정평가사

유형: 위임형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 외부 결과·관측 대기**

## 초기 복합 사건

수용 예정 토지의 비교거래는 적고 용도·오염·특수권리 때문에 거래 당사자들이 서로 다른 가격을 주장함

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 비교 거래 하나가 특수관계 거래로 밝혀짐 |
| 선택 1·재료 | M18·M53: 비교 표본·보정·가치 범위를 재계산 |
| 변화 2 | 현장 용도와 공부 차이에 대한 확인 미완료 |
| 선택 2·재료 | M21·M39: 평가 전제·대안 결과·필요 확인 분리 |
| 첫 도달 상태 | 평가모형·초안 가능, 현장·자격 수행 확정 대기 |
| 첫 판정 | 외부 결과·관측 대기 |
