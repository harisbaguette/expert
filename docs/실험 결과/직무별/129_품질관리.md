# 129. 품질관리

유형: 고용형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 외부 결과·관측 대기**

## 초기 복합 사건

출하 합격품이 고객 공정에서 불량을 내고 측정기 차이·로트 혼입·공급사 변경 때문에 원인이 갈림

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 측정기 이상 여부는 교정 시험으로만 알 수 있는데 이상 확인 뒤에만 시험을 켬 |
| 선택 1·재료 | M18·M35: 품질 판정에 선행하는 측정 신뢰 확인이 순환 대기 |
| 변화 2 | 생산팀은 불량 확정 전 계측 비용 집행을 막음 |
| 선택 2·재료 | M31·M54: 진단 권한·관측 의존과 생산 변경 조건을 따로 정해야 함 |
| 첫 도달 상태 | 조건 확인 기능의 선행 의존·권한 명시 강화 필요 |
| 첫 판정 | 조건 명세 강화 필요 |

## 명세 보완 후 재전개

판정용 교정·측정 신뢰 확인을 생산 변경과 분리해 준비. 실제 계측·교정 결과가 아직 없어 생산 합격으로 넘기지 않고 대기.
