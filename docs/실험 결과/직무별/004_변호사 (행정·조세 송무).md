# 004. 변호사 (행정·조세 송무)

유형: 위임형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 외부 결과·관측 대기**

## 초기 복합 사건

공장이 처분으로 운영 중단 위기에 놓이고 세무처분도 같은 거래 사실을 문제 삼아, 구제절차와 사업 일정을 동시에 관리해야 함

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 처분 통지 시점이 기존 기록보다 빠르고 공장 중단일 확정 |
| 선택 1·재료 | M18·M35·M37: 절차 시계와 운영 영향 재계산, 임시 구제·본안 병행 준비 |
| 변화 2 | 기관이 핵심 현장 사실을 부인하고 추가 조사 예고 |
| 선택 2·재료 | M07·M39·M43: 현장 근거 취득과 반박·보완 제출 연결 |
| 첫 도달 상태 | 신청·주장은 준비 가능하나 처분 변경·현장 확인까지 완료할 수 없음 |
| 첫 판정 | 외부 결과·관측 대기 |
