# 134. 수출입

유형: 고용형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 외부 결과·관측 대기**

## 초기 복합 사건

송장·포장·원산지·신용장 조건이 서로 달라 선적은 됐지만 통관·대금회수에서 보완과 지연 비용이 발생함

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 송장·원산지·결제 조건 불일치로 서류 하자 발생 |
| 선택 1·재료 | M18·M42: 물품·수량·가격·조건 교차 대사 |
| 변화 2 | 보완 서류는 준비되나 은행·통관의 수리 결과 미정 |
| 선택 2·재료 | M35·M38·M39: 선적·제출·회수의 기한·책임 연결 |
| 첫 도달 상태 | 서류·보완안 가능, 통관·대금회수는 외부 의존 |
| 첫 판정 | 외부 결과·관측 대기 |
