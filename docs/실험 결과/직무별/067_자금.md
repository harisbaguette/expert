# 067. 자금

유형: 고용형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 범위 내 종결 경로**

## 초기 복합 사건

세금·급여·매입대금이 같은 날 몰리고 큰 고객 입금이 지연됐는데 은행 이체 한 건의 처리 여부도 불명확함

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 은행 응답 유실로 세금 이체의 처리 여부 불명 |
| 선택 1·재료 | M03·M10·M25: 재전송 없이 실행 의도·은행 조회로 상태 확인 |
| 변화 2 | 은행 조회가 원거래 성공을 반환하고 급여 부족분은 별도 확인 |
| 선택 2·재료 | M33·M53·M42: 중복 지급 차단·잔액 재대사·지급순서 조정 |
| 첫 도달 상태 | 주어진 은행 응답 아래 지급·대사 종결 경로 있음 |
| 첫 판정 | 범위 내 종결 경로 |
