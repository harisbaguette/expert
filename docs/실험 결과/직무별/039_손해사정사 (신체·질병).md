# 039. 손해사정사 (신체·질병)

유형: 위임형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 외부 결과·관측 대기**

## 초기 복합 사건

사고 후 장해 청구에서 기존 질환과 새 손상이 섞이고 진단서마다 기능 제한 평가가 다름

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 추가 진료기록이 기존 장해·발병 시점 설명을 바꿈 |
| 선택 1·재료 | M18·M25: 의료 사실·의견·약관 판단을 다시 연결 |
| 변화 2 | 의료기관 간 소견이 갈리고 추가 평가 필요 |
| 선택 2·재료 | M21·M39·M43: 다른 전제·근거를 비교하고 의학 판단 지원 계수 |
| 첫 도달 상태 | 보험금 검토·쟁점표 가능, 의학적 결론·지급 결정 대기 |
| 첫 판정 | 외부 결과·관측 대기 |
