# 034. 기술사 (기계·전기 설비)

유형: 위임형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 외부 결과·관측 대기**

## 초기 복합 사건

데이터센터 냉각을 절감하려다 특정 랙 과열과 예비 전원 전환 시 냉각 중단이 발견됨

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 센서·계측을 해야 장애 판단이 가능하나 해당 기능은 장애 확인 때만 활성화됨 |
| 선택 1·재료 | M35·M50: 조건 판정에 필요한 관측 기능의 선행 활성화가 명시돼 있지 않아 조립 해석이 갈림 |
| 변화 2 | 운전팀은 고장 확정 전 계측 작업을 만들지 않음 |
| 선택 2·재료 | M07·M37·M54: 실행 기능과 판정용 관측의 의존을 분리해야 순환 대기 해소 |
| 첫 도달 상태 | 조건 판정 자체의 의존을 먼저 조립한다는 명시 보완 필요 |
| 첫 판정 | 조건 명세 강화 필요 |

## 명세 보완 후 재전개

진단용 계측을 먼저 요청할 수 있도록 분리. 자체 권한·현장 일정 확인 뒤 취득하며 고장 확인과 수리 실행 권한은 별개. 현장 수행·계측 결과 대기.
