# 123. 제품 (산업) 디자인

유형: 고용형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 외부 결과·관측 대기**

## 초기 복합 사건

보기 좋은 외장 설계가 금형 언더컷·조립 공차·발열·수리성과 충돌해 시제품은 되지만 양산 불량이 예상됨

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 외장안이 금형·열·조립 공차 시험에서 충돌 |
| 선택 1·재료 | M53·M54: 재료·구조·공정 대안 해석 |
| 변화 2 | 모의 해석은 수정안 통과하나 시제품 열·조립 시험 미실시 |
| 선택 2·재료 | M39·M40·M42: CAD·도면·BOM과 필요한 실물 검증을 연결 |
| 첫 도달 상태 | 설계 후보·제조 인계 가능, 양산 적합성은 실물 시험 대기 |
| 첫 판정 | 외부 결과·관측 대기 |
