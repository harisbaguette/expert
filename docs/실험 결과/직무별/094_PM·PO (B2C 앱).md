# 094. PM·PO (B2C 앱)

유형: 고용형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 범위 내 종결 경로**

## 초기 복합 사건

가입률을 올린 개편이 취소·환불·장기 이탈을 늘리고 실험군 오염과 계절 효과로 원인 판단이 어려움

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 가입 상승과 환불·장기 이탈 증가가 동시에 관측 |
| 선택 1·재료 | M52·M54: 배정·추적 오류·집단 구성 재검토 |
| 변화 2 | 정정한 모의 실험에서 변경안의 순효과가 음수 |
| 선택 2·재료 | M34·M35: 기존안 복원·측정 수정·후속 가설 선택 |
| 첫 도달 상태 | 주어진 실험 아래 출시·철회 결정 경로 있음 |
| 첫 판정 | 범위 내 종결 경로 |
