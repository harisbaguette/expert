# 156. 구매대행·리셀러

유형: 운영형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 외부 결과·관측 대기**

## 초기 복합 사건

주문 뒤 가격이 뛰고 판매자 진위·병행수입 조건·파손·반품 운임이 불명확해 선결제 고객과 손실 부담이 충돌함

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 판매자 진위와 수입·반품 조건이 확인되지 않음 |
| 선택 1·재료 | M18·M26·M53: 진위·거래 가능·총비용과 대안 분리 |
| 변화 2 | 원판매자가 증빙 제공을 거부하고 검수도 불가 |
| 선택 2·재료 | M35·M38·M39: 조달 보류·대체·환불 범위와 고객 결정 연결 |
| 첫 도달 상태 | 검토·고객 대응 가능, 상품 확보·진위 확인 완료 불가 |
| 첫 판정 | 외부 결과·관측 대기 |
