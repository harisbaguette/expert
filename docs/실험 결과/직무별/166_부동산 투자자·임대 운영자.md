# 166. 부동산 투자자·임대 운영자

유형: 운영형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 목표·조건 조정 필요**

## 초기 복합 사건

공실·연체·설비 수선·차환 만기가 겹치고 임차인 권리·보증금·공동소유자 이견 때문에 장부 수익률과 실제 현금이 갈림
