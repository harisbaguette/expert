# 121. 모션

유형: 고용형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 범위 내 종결 경로**

## 초기 복합 사건

방송·앱·세로광고에 같은 모션을 쓰려다 프레임·안전영역·용량·움직임 민감 사용자 조건이 달라짐

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 방송 프레임·앱 용량·동작 축소 설정이 서로 다름 |
| 선택 1·재료 | M09·M35: 같은 의도의 매체별 모션·축소 변형 설계 |
| 변화 2 | 모의 재생에서 타이밍·알파·프레임·앱 응답 통과 |
| 선택 2·재료 | M42·M40: 타임라인·원본·렌더·설정 인수 |
| 첫 도달 상태 | 제공된 재생 응답 아래 모션 납품 경로 있음 |
| 첫 판정 | 범위 내 종결 경로 |
