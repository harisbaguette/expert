# 041. 재무설계사

유형: 위임형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 목표·조건 조정 필요**

## 초기 복합 사건

맞벌이 가정이 조기은퇴를 원하지만 부모 돌봄·자녀 학비·변동금리 대출이 겹치고 부부 목표가 다름

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 부모 돌봄비 증가와 한 배우자의 소득 중단을 가정 |
| 선택 1·재료 | M25·M53: 생애현금·보장·부채 계획 재계산 |
| 변화 2 | 두 사람 모두 은퇴일·소비·유산 목표 변경을 거부, 자산 부족 |
| 선택 2·재료 | M34·M38: 우선순위와 제약 위반 시점을 구체화 |
| 첫 도달 상태 | 현재 자산에서 모든 목표 동시 달성 불가능 |
| 첫 판정 | 목표·조건 조정 필요 |
