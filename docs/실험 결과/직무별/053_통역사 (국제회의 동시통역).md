# 053. 통역사 (국제회의 동시통역)

유형: 위임형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 목표·조건 조정 필요**

## 초기 복합 사건

연사가 발표자료와 다른 숫자를 말하고 동시 발언·빠른 발화·음질 저하로 부정어와 단위가 불명확해짐

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 원음 손실로 숫자 한 구간은 복원 불가 |
| 선택 1·재료 | M08·M42: 숫자를 추정해 전달하지 않고 불명 구간 표시·확인 요청 |
| 변화 2 | 연사는 재발언을 거부하고 청중은 무누락·즉시 전달을 요구 |
| 선택 2·재료 | M36·M38: 지연·정확성·입력 손실의 한계를 구분 |
| 첫 도달 상태 | 잃어버린 정보를 즉시 정확히 전할 목표는 불가능 |
| 첫 판정 | 목표·조건 조정 필요 |
