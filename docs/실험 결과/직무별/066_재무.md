# 066. 재무

유형: 고용형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 목표·조건 조정 필요**

## 초기 복합 사건

신공장 투자안은 수익성이 좋지만 초기 손실·약정·배당 요구 때문에 자금조달과 신용 여력에 부담이 생김

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 신공장 수익은 양수지만 첫해 현금 4 부족 |
| 선택 1·재료 | M33·M53: 수익성·현금·약정별 대안 비교 |
| 변화 2 | 배당·투자·차입 제한을 모두 유지하라는 지시 |
| 선택 2·재료 | M34·M38: 단계 투자·배당 조정·자금조달 중 필요한 선택 제시 |
| 첫 도달 상태 | 원래 조건으로 자금계획 실행 불가 |
| 첫 판정 | 목표·조건 조정 필요 |
