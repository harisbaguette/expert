# 007. 변호사 (M&A·투자 거래)

유형: 위임형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 목표·조건 조정 필요**

## 초기 복합 사건

투자계약 직전 핵심 고객의 계약 해지권과 미공개 소송이 발견되고, 매도자는 계약 수정 없이 잔금 지급을 요구함

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 핵심 고객의 해지권이 종결 후에도 존속함을 발견 |
| 선택 1·재료 | M25·M34: 발견사항을 가격·선행조건·배상 조건에 연결 |
| 변화 2 | 매도자가 보증도 가격 조정도 거부, 매수자는 손실 한도 변경 불허 |
| 선택 2·재료 | M33·M38: 잔여 노출이 위임 한도를 넘는지 확인하고 종결 보류 |
| 첫 도달 상태 | 현재 양측 조건에서 거래 성사 불가능, 조건 변경 또는 철회 필요 |
| 첫 판정 | 목표·조건 조정 필요 |
