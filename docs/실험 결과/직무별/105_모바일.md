# 105. 모바일

유형: 고용형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 범위 내 종결 경로**

## 초기 복합 사건

오프라인 편집 중 계정이 바뀌고 앱이 강제 종료된 뒤 구버전이 재접속해 데이터 충돌·다른 계정 노출이 생김

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 오프라인 변경 후 계정 전환·앱 중단 발생 |
| 선택 1·재료 | M25·M31: 로컬 자료·동기화·계정 경계 분리 |
| 변화 2 | 모의 실기기 재개에서 충돌 정책·삭제·구버전 호환 통과 |
| 선택 2·재료 | M54·M42·M40: 계정별 복원·업데이트 인수 |
| 첫 도달 상태 | 제공된 기기 응답 아래 모바일 수정 경로 있음 |
| 첫 판정 | 범위 내 종결 경로 |
