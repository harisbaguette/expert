# 084. 퍼포먼스 마케팅

유형: 고용형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 범위 내 종결 경로**

## 초기 복합 사건

ROAS는 상승했지만 취소·반품과 기존 고객 비중이 커져 실제 추가이익은 줄고 인기상품은 품절됨

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 광고 매출 중 기존 고객·환불 비중 증가 |
| 선택 1·재료 | M52·M53: 증분 매출·실마진·재고 제약으로 재산정 |
| 변화 2 | 모의 대조군에서 특정 광고군의 증분이익이 음수 |
| 선택 2·재료 | M34·M54: 해당 예산 축소·품절군 제외·후속 실험 선택 |
| 첫 도달 상태 | 주어진 데이터에서 광고 배분 수정안 종결 경로 있음 |
| 첫 판정 | 범위 내 종결 경로 |
