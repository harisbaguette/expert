# 139. 유튜버 (정보·교육)

유형: 운영형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 범위 내 종결 경로**

## 초기 복합 사건

조회가 잘 나오는 설명이 중요한 조건을 생략해 오개념을 만들고 초보·숙련 시청자의 이해·이탈 지점이 다름

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 시청 지속은 높은데 학습 확인에서 오개념 발견 |
| 선택 1·재료 | M18·M21·M34: 생략 조건·예시·학습 순서 수정 |
| 변화 2 | 모의 학습자가 수정 설명에서 같은 과제를 올바르게 수행 |
| 선택 2·재료 | M54·M46: 이해·지연 회상·영상 설명의 연결 검토 |
| 첫 도달 상태 | 제공된 학습 반응 아래 교육 콘텐츠 개선 경로 있음 |
| 첫 판정 | 범위 내 종결 경로 |
