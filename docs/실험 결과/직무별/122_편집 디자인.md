# 122. 편집 디자인

유형: 고용형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 범위 내 종결 경로**

## 초기 복합 사건

막판 원고·표 수정으로 페이지·색인·각주가 연쇄 이동하고 PDF는 보이지만 인쇄에서 폰트·재단 문제가 발생함

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 막판 표 수정으로 페이지·색인·각주 연쇄 변경 |
| 선택 1·재료 | M25·M09: 원고 판본·문서 참조·조판 재생성 |
| 변화 2 | 모의 프리플라이트·실출력이 글꼴·재단·참조 통과 |
| 선택 2·재료 | M42·M40: 원본·인쇄본·교정 기록 대조 |
| 첫 도달 상태 | 제공된 인쇄 조건 아래 편집 디자인 인수 경로 있음 |
| 첫 판정 | 범위 내 종결 경로 |
