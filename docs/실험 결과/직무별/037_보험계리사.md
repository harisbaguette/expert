# 037. 보험계리사

유형: 위임형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 범위 내 종결 경로**

## 초기 복합 사건

장기보험의 해지율·손해율이 예측과 달라지고 재보험 변경·금리 변화까지 겹쳐 수익성과 준비금이 흔들림

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 경험데이터에서 해지 건 중복과 관측기간 혼합 발견 |
| 선택 1·재료 | M52·M53: 노출·발생률·가정의 기준을 재작성 |
| 변화 2 | 독립 계산이 새 가정의 준비금·민감도 결과를 일치하게 반환 |
| 선택 2·재료 | M43·M54: 이전 차이 원인·스트레스·허용 범위 점검 |
| 첫 도달 상태 | 주어진 가정과 데이터에서 계리 산출·검증 패키지 종결 경로 있음 |
| 첫 판정 | 범위 내 종결 경로 |
