# 071. 펀드매니저 (채권)

유형: 고용형  
검토 방식: 단계별 사건·도구 응답을 가정한 작성자 탁상 모의; 실제 에이전트 실행 아님

**최종 판정: 외부 결과·관측 대기**

## 초기 복합 사건

금리 상승과 발행사 신용 악화가 겹쳐 가격이 하락하고 유동성이 줄었는데 평가가격은 실제 매도가와 차이가 큼

## 단계별 전개

| 단계 | 내용 |
|---|---|
| 변화 1 | 평가가격에 매도 가능한 호가가 없고 신용 위험 증가 |
| 선택 1·재료 | M16·M53: 가격·현금화·금리·신용 모형을 분리 |
| 변화 2 | 위임 범위 내 축소 주문을 냈으나 시장 체결 결과 미정 |
| 선택 2·재료 | M10·M25·M33: 주문·체결·노출을 따로 추적 |
| 첫 도달 상태 | 재조정 판단은 가능, 실제 유동성·체결 결과 대기 |
| 첫 판정 | 외부 결과·관측 대기 |
