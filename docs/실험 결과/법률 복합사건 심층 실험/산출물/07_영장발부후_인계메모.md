# 영장 발부 후 인계 메모

단계 10 / 가상 시점 2026-09-11 12:10 / 기소 전 구속 상태

**외부 목표인 영장 기각은 이 분기에서 실패했다.** 이를 “안전하게 대기했으므로 사건 해결”이라고 분류하지 않는다. 종전 영장심문 의견서는 당시 제출 준비 기록으로 보존하고 현재 신청서로 재사용하지 않는다.

첫 작업은 접견과 가상 발부 이유의 구체적 확인, 기록 접근 범위·송달·다음 일정 확인이다. E23은 중요한 참고인 접촉과 미확보 전자자료를 이유로 제시했으므로, 추가 자료를 확보하지 않은 채 이전 의견만 복사해 반복하지 않는다. 접촉 중단 이행 자료, 지시 경위 원본, 남은 자료의 보존·제출 가능성, 주거·출석 자료가 새로운 판단 근거가 될 수 있는지 확인한다.

기소 전이므로 [형사소송법 제214조의2](https://www.law.go.kr/LSW/lsInfoP.do?ancYnChk=0&chrClsCd=010202&efYd=20260701&lsiSeq=281865&urlMode=lsInfoP)에 따른 구속적부심 검토를 후속 과제로 잡는다. 이 기록만으로 인용 가능성이나 즉시 신청의 최선 여부를 확정하지 않는다. 실제 신청인은 누구인지, 접근 가능한 자료·새 소명·시점별 법령과 절차를 확인해야 한다. 기소 이후 보석 경로와 자동 혼동하지 않는다.

민사 답변 준비와 주총 자문은 전부 중단하지 않는다. 개인의 유효한 위임 범위에서 계속하되 회사 처분권을 획득한 것으로 보지 않는다. 개인 현금은 3억원 지급 후 0이며 14일 뒤 매각예상액10억원은 여전히 미확정이다. 추가 지급을 실행하지 않는다.

| 인계 대상 | 전달할 것 | 전달하지 않을 것·미확인 |
|---|---|---|
| 개인 신병 담당 | E08·E21·E23, 종전 의견서, 추가 자료 목록 | 회사 비공개 자료 임의 접근권 |
| 개인 민사 담당 | 납품22·회수11·대사잔액27, 회사의 청구 유지 | 형사 이득액 확정값이나 회사 면책 권한 |
| 개인 주주권 담당 | 위임철회와 안건별 계산, 정원 확인 필요 | 실제 가결·취임 확정 |
| 회사 대리인 | 별도 허용된 수령·충당 대조 요청 | 개인 면담·방어 전략·E13의 자동 공유 |

현재 상태: 산출물 작성과 제한된 계산·전환 검사는 수행. 형사 본안·구속 적법성·민사 책임·주총의 법적 결과는 미확정. 새 전문가의 사실·법률 검토 기여가 필요하면 별도 기록한다.
