# E10 · 개인·회사 자금과 자료권한

가상 사건 기록 / 실제 개인·회사·은행·기관 자료가 아님

- 공개 단계: 0
- 문서·관측 시점: 2026-09-10 09:00

## 기록 내용

개인 가용 현금 3억원, 개인 부동산 매각 순유입 예상 10억원은 14일 뒤로 미확정. 회사 현금 42억원 중 20억원 사용 제한, 운영 최소 여유 16억원. 회사 문서 E02~E06은 이 사건 개인 방어 검토용 교부가 허용됐다고 가정하되 회사 시스템 접속권·회사의 처분권은 위임되지 않았다.

## 증명 범위와 한계

회사 돈을 개인 돈으로 합치지 않는다. 문서 검토 허용은 시스템 조회·외부 공개 허가와 다르다.
