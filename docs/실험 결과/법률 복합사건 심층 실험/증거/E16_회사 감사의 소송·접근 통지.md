# E16 · 회사 감사의 소송·접근 통지

가상 사건 기록 / 실제 개인·회사·은행·기관 자료가 아님

- 공개 단계: 5
- 문서·관측 시점: 2026-09-10 14:00

## 기록 내용

회사는 감사가 소송상 대표자로 표시된 상태로 강도윤에게 30억원을 청구하는 가상 소장을 송달했다. 회사의 12억원 개인 사용 주장은 전체 손해 일부에 포함된다. 감사는 회사 서버 접근을 허용하지 않으며 회사 대리인과 개인 대리인은 별개라고 통지한다.

## 증명 범위와 한계

E02~E06의 기존 적법 교부 이력은 삭제하지 않는다. 새 접근·재공유·사용 목적은 각각 검토. 감사의 합의 권한 전부까지 이 통지로 확정하지 않는다.
