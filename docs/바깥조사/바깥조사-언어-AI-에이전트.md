# 바깥 조사 — 언어(번역·통역·현지화·카피) 전문 AI 에이전트 (전 세계)

진행 계획 3단계 "바깥 조사 — 남이 만든 에이전트 비교" 의 아홉째 직종군임. 확인일 2026-09-11. 검색 일꾼 9명이 모은 1차 자료를 부모가 대조해 씀. 확신도는 FACT(1차 자료 직접 확인) · LIKELY(2차 자료 또는 자체 발표만) · 미확인 으로 붙임.

## 한 줄 결론

**언어는 우리가 지금까지 본 아홉 직종 중 유일하게 "AI 가 사람을 이겼다" 는 제3자 증거가 나온 곳임.** 세계 기계번역 대회 WMT25 의 사람 채점에서 **전문 번역가가 만든 번역이 15개 언어쌍 중 6개에서만 1등 무리에 남았고**, Gemini 2.5 Pro 는 14개 언어쌍에서 1등 무리에 들었음. 한 해 전 WMT24 에서는 사람이 11개 중 7개를 지켰으니 1년 만에 밀린 것임.

그런데 **그렇다고 대체가 된 것은 아님**. 이유가 법률 편과 정반대임 — 법률은 "실력이 모자라서" 막혔지만, 언어는 **실력은 붙었는데 책임을 질 사람이 법으로 정해져 있어서** 막혔음. 미국 보건복지부 규정 45 CFR §92.201 은 "중요한 문서에 기계번역을 쓰면 자격 있는 사람 번역가가 검토해야 한다" 를 법조문으로 못박아 뒀고, 번역 업계 표준 ISO 17100 은 기계번역 후편집을 아예 "번역 서비스" 정의 밖으로 빼 놨음. 스페인·독일의 선서 번역사, 미국 연방법원 인증 통역사는 사람만 될 수 있음.

**우리에게 뜻**: 언어는 "정하기·하기" 는 이미 사람 수준이고, 막힌 곳이 **끝내기(책임지고 이름 걸기)** 딱 하나임. 그리고 언어는 아홉 직종 중 유일하게 **업계 공용 채점표(MQM)** 가 이미 있어서 "잘했는지" 를 기계가 매길 수 있음 — 우리 문서가 요구하는 "사람 말고 기계가 끝을 확인" 을 가장 먼저 만들 수 있는 자리임.

## 5. 우리 정의 문서와 대조

### 5-1. "대체의 뜻" 으로 재면

| 우리 기준 | 남들 현황 | 판정 |
|---|---|---|
| 사람이 중간에 확인·고치면 아직 대체 아님 | 문서 번역 판(TMS) 전부가 **후편집(MTPE)** 을 구조에 박아 뒀음. ISO 17100 은 기계번역 후편집을 아예 규격 밖으로 뺌 | **문서 번역 = 대체 0건** |
| 같은 기준, 실시간 통역 | **Wordly·Google Meet·Teams·AirPods 는 사람 통역사 없이 그냥 돎.** 이용자 600만, 누적 10억분 | **회의 통역은 사실상 대체가 이미 일어났음** — 우리가 본 아홉 직종 중 처음 |
| 사람 부르는 다섯 경우 | 자격자 전속(선서 번역·법정 통역·공증)과 승인 조건(브랜드·법무 승인)은 업계 관행. **되돌릴 수 없음·한도 초과·판단 안 섬 을 스스로 감지하는 장치는 아무도 공개 안 함.** Phrase Auto LQA 가 "점수 낮으면 사람에게" 로 가장 가까움 | 다섯 중 둘만 관행 |
| 초보와 전문가를 가르는 5단계 | **보기·알기·정하기·하기 = 이미 사람 수준.** WMT25 에서 Gemini 2.5 Pro 가 10개 언어쌍에서 사람과 같거나 위. **끝내기만 비어 있음** — 이름 걸고 책임지는 자리에 AI 를 못 넣게 법이 막음(45 CFR §92.201, 선서 번역사, 28 USC §1827) | **언어는 "실력" 이 아니라 "책임" 에서 막힌 유일한 직종** |

| 우리 직종 | 우리 성과 지표 | 남들 성숙도 | 남들이 그 지표로 재나 | 판정 |
|---|---|---|---|---|
| 번역가 (산업·법률 문서) | MQM 98~99점, 오역 사고, 수정 요청, 납기 | 가장 높음. 로제타는 계약서 수정률 0.05% 주장 | **MQM 은 잼(업계 표준). 수정 요청·납기는 안 잼** | **가장 열려 있음** — 채점표가 이미 있어 기계가 끝을 확인할 수 있는 유일한 자리 |
| 번역가 (출판·문학) | 독자 평점, 판매 부수, 편집자 수정 요청 | **제품 없음.** WMT25 도 각주에서 "문학 번역 수준의 후편집은 안 거쳤다" 고 스스로 밝힘 | **전혀 안 잼** | 비어 있는데 성과를 재기도 어려움. 뒤로 |
| 번역가 (영상·게임 현지화) | 시청자 불만, 글자 수·타이밍 위반, 납기 | 높음(XL8·ElevenLabs·YouTube 자동더빙). 그런데 **반발이 가장 셈** (크런치롤·넷플릭스·SAG-AFTRA) | **제3자가 잰 자료 없음.** 립싱크·자막 규격 측정치 못 찾음 | 기술은 되는데 **사람들이 싫어함** — 제도 위험 |
| 통역사 (국제회의 동시통역) | 의미 일치도, 전문용어 정확성, 재지명률 | **이미 대체가 일어남** (Wordly 누적 10억분) | **재지명률로 재는 곳 없음.** IWSLT 정확도 수치도 못 구함 | 남이 이미 먹었음. 들어가려면 "잘했나" 를 재는 자리로 |
| 통역사 (비즈니스·법정) | 의미 일치도, 격식·뉘앙스, 불이익 건수, 재지명률 | 법정은 **제품 0개**. 한·일 모두 통역인이 반토막·15% 감소로 사람이 모자람 | 안 잼 | **수요는 있는데 자격자 전속** — 다섯 경우가 켜짐 |
| 카피라이터 | CTR, 전환율, A/B 승률 | 제품은 많음(Persado·Anyword·Jasper) | **성과로 재는 구조는 HubSpot Breeze 성과 기반 과금 하나뿐** (2026-04-02). Persado 수치는 전부 자사 사례, 제3자 실험 0건 | **성과 지표로 돈 받는 모델이 이미 존재함** — 우리 정의와 가장 잘 맞는 자리 |

**첫 자리로 고른다면**: 산업·법률 문서 번역 + 카피 두 곳임. 이유는 같음 — **둘 다 "잘했나" 를 사람이 아니라 숫자가 판정할 수 있음**(MQM 점수 / 전환율). 우리 대체 기준이 요구하는 "기계가 끝을 확인하고 기록을 남김" 을 다른 직종보다 먼저 세울 수 있음.

## 6. 못 확인한 것

- **IWSLT 동시통역 정확도·지연 수치** — 논문 목록(2025년 45편·2026년 40편)은 확인했으나 개별 논문 수치를 못 뽑음
- **MQM 통과선의 원문 정의** — themqm.org 403 차단. 우리 직종표의 "98~99점" 근거를 원문으로 확인 못함
- **ISO 5060·ISO 18587 원문 scope** — iso.org 403 차단, ISO 17100 만 표준 판매처 미러로 확인
- **Unbabel 의 "AI 번역이 사람을 넘었다" 1차 발표문** — widn.ai 가 unbabel.com 으로 넘어가 원문을 못 찾음. Tower LLM 논문 초록에는 그런 표현이 없음
- **Slator 2026 언어산업 시장 규모** — 유료 보고서라 접근 실패. "$31bn 산업" 이라는 2025-11-25 기사 제목만 확보
- **CIOL/ITI 영국 번역가 수입 설문** — 페이지 접근 실패
- **DeepL Agent 공식 발표문** — deepl.com/en/agent 404, 공식 블로그에 해당 글 없음. 언론 보도만
- **Persado "A/B 테스트 100만 건" 의 원자료** — 자사 홈페이지에 방법론·논문 링크 없음
- **넷플릭스의 AI 더빙·자막 공식 입장문** — 논란 보도만 찾았고 공식 정책 문서는 못 찾음
- **Keywords Studios(게임 현지화 최대 업체) 의 AI 실험 결과 보고서 원문** — 팟캐스트 제목만
- **프랑스 선서 번역사(traducteur assermenté) 법령 원문** — legifrance 403, service-public 404
- **미 연방법원 통역사 인증시험(FCICE) 합격률** — uscourts.gov 에 수치 없음
- **한국 대법원 법정 통역·번역인 인증평가의 현재 운영 규칙 원문** — law.go.kr·scourt.go.kr 이 자바스크립트 렌더링이라 원문 못 열었음. 법원조직법 제62조·공증인법 제57조는 조문 미러로 확인
- **뤼튼테크놀로지스 매출·기업가치** — 한국어·영어 검색 모두 빈 결과
- WebSearch 세션 한도가 조사 시작 전 이미 소진돼 **전 과정을 WebFetch 로만 수행**했음. 검색 범위에 구조적 공백이 있음
