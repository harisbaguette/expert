# 바깥 조사 — 금융·투자·여신·보험 전문 AI 에이전트 (전 세계)

진행 계획 3단계 "바깥 조사 — 남이 만든 에이전트 비교" 의 금융·보험 직종군임 (법률 다음 차례). 확인일 2026-09-11. 확신도는 FACT(1차 자료 직접 확인 또는 독립 출처 3개) · LIKELY(출처 2개 또는 자체 발표만) · 미확인 으로 붙임.

> 조사 도중 이 세션의 웹검색 한도(200회)가 다 떨어져서, 뒤쪽 절반은 **회사 공식 페이지 직접 열기 + 미국 증권거래위원회(SEC) 에 낸 서류 + 뉴스 RSS 목록** 으로만 캤음. 그래서 못 캔 것이 6절에 좀 많음.

## 한 줄 결론

금융·보험은 **법률보다 훨씬 앞서 있음**. 법률은 "사람 검토 0건 예외 없음" 이었는데, 여기는 **사람이 한 번도 안 보고 끝나는 일이 이미 진짜로 돌아감** — 미국 업스타트(Upstart) 는 대출 10건 중 9건을 사람 손 없이 승인·거절하고(2026-08-04 SEC 서류), 중국 핑안은 보험금 청구의 93%를 60초 안에 자동으로 판정함(2025). 다만 **돈을 굴리는 쪽(투자·펀드·트레이딩)은 성적표가 나쁨** — 한국 로보어드바이저 상품의 99%가 손실이었다는 보도가 2026-09-06 에 나왔고, 퇴직연금 로보 일임 전체 운용액이 607억 원(2026-02)에 그침. 즉 **"정답이 숫자로 채점되는 일(대출 부도율·보험 손해율)은 AI 가 이미 먹었고, 정답이 없는 일(수익률)은 아직 아무도 못 먹었음."**

### 5-1. "대체의 뜻" 으로 재면

| 우리 기준 | 남들 현황 | 판정 |
